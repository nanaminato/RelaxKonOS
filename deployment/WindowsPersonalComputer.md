# 在自己的 Windows 10/11 电脑上使用 Server + Client

Windows 10/11 的本机管理入口默认使用个人模式，也可选择系统模式。Windows Server 仅支持系统模式，继续使用原有服务、账户认证和权限规则。两种安装拥有独立的程序、数据库、安装标识和操作记录，不自动转换，同时运行需选择不同端口。

## 个人模式的身份和权限

个人安装归属于发起安装的 Windows 账户 SID，例如 nanami。该账户默认拥有本安装的 RelaxKonOS 管理员能力，无需把它加入 Windows Administrators 组。Server 以该账户的非提升令牌运行，登录后启动、注销后停止；关闭 Client 不会停止 Server。普通终端、文件和 Docker Desktop 使用当前账户的环境和权限。

安装、更新、修复、回退和卸载通过 UAC 配置独立的 LocalSystem 特权助手。部署引擎留在原用户会话；即使 UAC 使用另一管理员的凭据，所有者、数据目录和登录启动项也不会改成那个管理员的。刷新安装状态不请求 UAC。日常使用通过安装时授权的助手执行特权操作，不逐次请求 UAC，也不保存 Windows 管理员密码。

助手按所有者 SID 使用独立的服务名 `RelaxKonOSPersonalHelper-<SID>` 和管道。助手程序及配置位于 `%ProgramFiles%\RelaxKonOS-Personal\<SID>`，仅 SYSTEM 和 Windows 管理员可写，所有者可读。Server 的程序和数据分别位于 `%LocalAppData%\RelaxKonOS-Personal\program` 和同级 `data`，操作回执及诊断位于同级 `deployment`。管道使用 SID ACL、HMAC、操作编号及重放检查，不提供网络上的助手接口。

普通文件操作先按当前用户权限执行，权限不足时由助手执行，但仍受安装时审阅的文件范围限制：默认仅受管数据目录，也可明确选择白名单或全部本地磁盘。普通终端仍是当前用户；显式管理员终端使用 LocalSystem，因此不继承当前用户的网络盘和域资源凭据。允许管理员终端意味着向安装所有者及其配对设备授予本机系统级命令执行能力。

个人模式不安装 Guardian 系统服务，也不提供跨用户 Guardian。Windows 平台或具体内置应用不支持的能力仍按实际能力检测返回，不因个人安装获得管理员能力而改变。

## 安装并授权本机

1. 使用匹配架构的 Windows 桌面 Client 和 Server 发布包。打开登录页的「管理本机」，选择个人模式；不需要 OpenSSH Server 或已有服务端登录。
2. 选择官方发布、本地 ZIP 或带 SHA-256 的自定义 HTTPS 下载，审阅端口、网络、TLS 和特权文件范围。
3. 安装阶段批准 UAC。取消或助手安装失败会使部署失败，不能显示为成功；操作回执保留在个人安装的 deployment 目录。
4. 等待部署回执和独立健康检查通过。在同一台 Windows 电脑通过回环地址选择「设置此 Windows 设备」，以 Negotiate 验证当前登录账户并注册本机设备公钥，无需输入 Windows 账户密码或 Hello PIN。
5. 个人模式只允许安装所有者完成这一本机授权；其他账户即使属于 Windows Administrators 也不能替代所有者。后续使用设备密钥签名登录。本机密钥遗失后，所有者可通过同一本机身份验证入口恢复。

更新、修复、回退和卸载都绑定已核验的安装标识；卸载默认保留用户数据并删除个人助手和对应的防火墙规则。更改部署代码后需重新制作 Server ZIP，因为安装执行发布包内的版本化引擎。

## 用授权码配对网络设备

本机设备完成授权并以设备密钥登录后，可生成配对授权码。授权码有效期为 10 分钟且只能使用一次；Server 重启会使未使用的授权码失效。新设备生成自己的 P-256 私钥，用授权码登记公钥，随后通过签署两分钟有效的一次性挑战登录。私钥留在设备，服务端只保存公钥。

配对设备关联到同一个所有者账户和工作区，不创建额外 Windows 用户，也不需要所有者或管理员密码。桌面和 Android 客户端使用相同的 DER 签名协议。所有者可以列出和撤销设备；撤销后的设备不能继续使用已有访问令牌或刷新令牌，其现有 Hub 连接会断开。其他设备及密码登录会话不受该设备撤销影响。

Server 必须监听 LAN，授权码内地址必须是其他设备能够访问的地址，不能使用 `127.0.0.1` 或 `localhost`。跨设备配置 HTTPS，证书需覆盖实际主机名或 IP。安装和维护可显式添加个人防火墙规则，仅允许 Domain/Private 网络上的 LocalSubnet 来源；其他网络范围需由 Windows 管理员按实际需要配置。LAN 配置不代表公网可达。

## 系统模式

系统模式继续把 Server、Guardian 和特权助手注册为系统服务，无人登录也能运行。Windows 10/11 与 Windows Server 使用相同的系统模式权限规则。安装维护需要管理员权限；账户认证不会仅凭加入域就把普通域用户认定为管理员。

Windows 10/11 系统模式保留本机管理员通过回环 Negotiate 设置或恢复设备密钥的已有规则；普通用户不会因为个人模式的所有者规则而获得系统安装权限。Windows Server 不开放工作站设备密钥授权入口。

## 验证范围

自动检查覆盖本机账户隔离、Windows Server 拒绝个人模式、设备邀请、DER 签名、共享用户和工作区、授权码重放、设备撤销、桌面部署请求和系统模式特权授权回归。发布前仍需在 Windows 10/11 实机验收：普通用户加另一管理员 UAC、本机 Negotiate、LAN HTTPS 和 Android 配对、特权文件及 LocalSystem 终端、更新回退、注销重登、卸载保留数据，以及与系统安装共存。自动检查不替代这些实机验收。

# 静默同步与服务器实例配置

## 配置归属

工作区偏好属于用户的 Workspace，界面几何及同步策略属于登录客户端的 Device；影响所有用户的后台运行策略属于服务器实例。服务器实例不创建虚拟用户，也不占用用户注册表的 `(UserId, ScopeId)` 存储空间。

注册表界面在服务器根节点下提供“服务器实例”，地址为 `Server\Runtime`。该分支的地址使用 `Scope=Server`、`ScopeId=InstanceId`、`OwnerUserId=null`；User/Workspace/Device 地址继续使用真实用户 ID。用户注册表 API 不接受 Server 范围操作。

## 客户端同步策略

在 `HKEY_CURRENT_USER\Device\Client\Synchronization` 修改：

| 属性 | 默认值 | 候选值 / 范围 |
|---|---|---|
| `mode` | `event` | `event` 静默事件模式；`polling` 事件通知加定时检查；`manual` 手动模式 |
| `pollIntervalSeconds` | 300 | 60–3600 整数秒，仅 polling 模式启用 |

event 模式不启动周期性 REST 刷新。客户端保存后直接应用响应；服务端通知携带作用域、路径和版本号，客户端只读取受影响的文档。相同文档的重复通知合并，已应用版本忽略，持久化完成且值版本不变时不重读外观。

同一登录上下文复用已加载配置，打开额外终端标签无需重复读取全部偏好。没有对应应用观察者时，外观变更只标记缓存失效，下一次打开应用再读；桌面同步策略仍由共享连接观察。

polling 模式额外按配置间隔读取配置并恢复桌面快照。manual 模式关闭通知连接及定时检查，外部变更在打开应用或显式刷新时读取；本机保存仍立即生效。恢复 event/polling 模式时重新订阅并读取快照。

桌面与外观使用同一个设置通知连接。订阅和重新连接后读取当前版本，修复连接中断期间的变更；不再每 30 秒重复读取桌面配置。连接重试和失败的文档读取采用有上限的指数退避，成功后停止重试；重试不重放任何写入。认证到期关闭连接，连接前更新认证上下文，旧用户/设备的延迟结果不能应用到新会话。

静默模式仍保留 SignalR 必需的连接心跳及认证生命周期处理。

## 服务器运行策略

在“服务器实例”分支修改：

| 属性 | 默认值 | 范围 | 含义 |
|---|---|---|---|
| `registryFlushDelayMilliseconds` | 5000 | 100–30000 | 首次修改后启动一次合并写回窗口 |
| `notificationCoalesceMilliseconds` | 50 | 0–1000 | 合并短时间内的设置变更通知 |
| `retryDelaySeconds` | 5 | 1–300 | 写回或通知失败后的重试间隔 |
| `sessionValid` | true | true / false | 当前访问令牌通过宿主管理员验证后，在令牌有效期内免重复验证；关闭后恢复短期、按能力和目标授权 |

读取和修改使用独立接口 `GET/PUT /api/v1.0/server/runtime-settings`，要求 `ServerRuntimeConfigure` 能力和精确目标 `server/runtime-settings`。当前宿主管理员自动授权；普通账户使用现有管理员提权流程。用户注册表管理授权不能代替服务器运行管理授权。

服务器实例 ID、版本、参数及审计记录独立保存在 `data/server-runtime-settings.json`。文件原子替换并完成磁盘刷新后，运行时才采用新快照。PUT 必须携带 InstanceId 和 ExpectedRevision；实例不匹配、版本冲突、未知字段、字段类型错误（数值字段要求整数、sessionValid 要求布尔值）或越界值不能修改配置。审计记录真实操作者、修改前后参数、时间与版本，保留最近 64 条记录。初始默认配置的 UpdatedBy 为空，表示尚无用户修改。

参数修改用于随后调度的批次；已经等待中的批次仍按其启动时的延迟执行，不重启服务端或 PTY。

## 后台活动

服务器注册表只在有待写入数据时运行延迟写回；空闲时等待信号，不再每 5 秒唤醒。突发写入合并成批，写回期间的新修改保留到下一批；失败保持脏数据并延迟重试。正常关闭强制保存剩余修改；最终持久化失败报告错误，不把未保存数据标记为已保存。

设置通知服务直接观察注册表写入和持久化完成事件。无变化时等待有界信号，不再每秒扫描、读取和解析工作区配置。待通知数据按用户、作用域、实例路径合并，只发送版本元数据，不广播偏好值。订阅只能匹配当前用户的 Workspace 及 JWT 中的 Device；服务器管理字段不通过普通设置订阅广播。

## 验证

聚焦检查入口：

- 服务端：`RelaxKonOS.Server.Tests --quiet-settings-only`，验证空闲无数据库访问、100 次突发写入合并成一次批次、关闭写回、实例标识、审计、权限、范围和冲突，以及双连接通知和重新订阅。
- 客户端：`RelaxKonOS.ApplicationLayout.Tests --registry-only`，验证默认无轮询、缓存复用、按文档读取、模式切换、设备隔离，以及服务器实例专用路由和编辑对话框。

终端渲染和会话管理继续使用原有机制；本次修改只减少设置同步和注册表持久化的重复活动。

# RelaxKonOS Code Editor 设计

> **共享编辑能力已实现**：独立 Code Editor 与项目编辑器复用 `CodeEditorViewModel`、编辑面板及 `CodeEditorSessionDialogs`，保留轻量编辑应用身份。多标签使用独立撤销栈与光标状态，UTF-16/32 保存补齐 BOM。项目编辑器专有的 Git 与条件保存边界见 [实施记录](./RelaxKonOS.GitEditor.Progress.md)；下文的 Git/SCM 非目标仍适用于独立 Code Editor。

> 内置代码编辑器（`relaxkonos.codeeditor`）。它在 Client 本地渲染编辑体验，经既有 Files API 读取和保存 **RelaxKonOS.Server 宿主机** 上的代码文件；不直接访问客户端或服务端文件系统。
>
> 当前状态：已实现多文件夹工作区、多标签文本编辑、文件树分类图标与图片预览。文本文件按扩展名提供基础语法高亮，所有读写复用远程 Files API。

## 1. 目标与非目标

v1 目标是让 Code Editor 成为适合小型项目维护的远程编辑器：同一窗口可打开多个互不相同的远程文件夹，在树中浏览文件，在右侧以标签页切换多个文件，并安全保存回宿主机。

不在本次范围内：跨文件工作区内容搜索/替换、Git/SCM、终端面板、调试器、扩展市场、LSP/智能补全、编辑器分栏、文件监听和跨设备共享未保存文本。这些能力依赖独立的索引、进程或协作模型，不能为了模拟 IDE 而绕开现有 Files API。

## 2. 用户体验和信息架构

```text
菜单与文档标题
├─ 左侧活动栏（窄）
│  └─ 资源管理器：收起或展开文件夹功能区域
├─ 功能区域（可收起）
│  └─ 文件夹：添加文件夹、刷新、多个根目录及延迟加载目录树
└─ 文件区
   ├─ 编辑器标签栏：切换、关闭、未保存标记
   └─ 按文档类型显示 AvaloniaEdit、图片预览或二进制文件说明
```

### 2.1 v1 流程

1. 用户通过“添加文件夹”打开现有的远程目录选择器；可重复添加，根目录以并列方式显示，不合并或假定共同父目录。
2. 展开一个目录时才向 Files API 请求它的内容；树显示目录与全部文件，并复用文件浏览器的类型图标，避免一次加载大型树。
3. 单击文件打开或激活对应标签。首次打开时读取内容，文本按扩展名设置语法高亮，图片显示预览，二进制文件显示说明卡片。
4. 标签栏显示文件名、脏状态和关闭按钮。切换标签不丢弃编辑内容；保存只写当前标签。
5. 关闭脏标签前必须确认“放弃 / 取消”，用户可先执行保存；窗口级的“保存 / 放弃 / 取消”批量确认作为下一步完善项。

### 文件类型与预览

文件树与标签复用 `ExplorerIcon`：代码、图片、文档、压缩包、数据库等使用与文件浏览器一致的分类图标。PNG、JPEG、GIF、BMP、WebP、ICO 和 SVG 等格式通过既有 `ImageViewerDecoder` 在标签内显示图片；预览提供透明背景棋盘格、尺寸、文件大小与“1:1”开关，默认适应窗口。预览不会把原始字节解码为编辑文本，图片标签禁用文本保存、另存为、编码选择与查找。

SVG 默认显示图片，可切换“编辑 SVG 源码 / 显示图片”。源码修改保留脏状态，切回预览会重新渲染；渲染失败时保留源码编辑视图，初次打开无效 SVG 也仍可编辑修复。其他损坏或不支持预览的图片，以及 PDF、压缩包、Office 文档、音视频等二进制格式，显示分类图标、文件名、大小和格式说明，不显示乱码，也不允许文本写入。UTF BOM 会在二进制检测前识别，避免将 UTF-16 / UTF-32 文本中的零字节误判为二进制。未知格式会检查解码后的控制字符。

图片资源随标签关闭、重新加载或窗口关闭释放；标签切换保留预览与文本草稿，过期的异步读取不会覆盖较新的文档。打开文件选择器提供源码、图片与所有文件筛选。

### 2.2 左侧功能栏

活动栏的文件夹按钮用于收起或展开文件树；已打开文档入口位于标签栏末尾：

| 功能 | 图标 | 功能区域 | v1 |
|---|---|---|---|
| 资源管理器 | 文件夹 | 多根文件夹树、添加/移除根、刷新 | 已实现目标 |
| 已打开文件 | 下拉箭头 | 标签栏中的文档列表与切换入口 | 已实现 |
| 搜索 | 放大镜 | 工作区文本搜索 | 计划中 |
| 源代码管理 | 分支 | Git 状态、暂存与提交 | 计划中 |

未实现功能不显示可点击的伪入口；活动栏只呈现文件夹按钮，直到其他功能区域可用。

## 3. 数据、协议与状态

复用 `IExplorerClient.GetDirectoryAsync`、`ReadFileAsync` 与 `WriteFileAsync`；本功能不新增 Server 端文件访问能力、不新增 API 路由或数据库表。

```text
CodeEditorViewModel（窗口内真源）
├─ WorkspaceRoots[]              # 本次窗口会话的绝对远程目录
├─ OpenDocuments[]               # path 唯一；保留加载内容、编码、脏状态
├─ ActiveDocument                # 编辑器当前绑定对象
└─ IsSidebarVisible              # 文件夹树的显示状态
```

- 路径以 Server 返回的绝对路径为数据来源；同一路径只能有一个打开文档。
- 文件夹树为惰性缓存。刷新当前根或目录时仅重载该节点，不会覆盖脏文档。
- v1 的根目录和打开标签只在当前 Code Editor 窗口存活，不持久化到 Workspace；这样不会把远程路径或未保存文本写入数据库。后续若需要恢复工作区，单独引入 Workspace 级 `CodeEditorSettings`，只保存已验证根路径和打开文件路径，不保存文件内容。
- 读写大小、路径规范化、权限拒绝与文件不存在均沿用 Files API 的服务端约束；客户端只显示本地化错误状态。

## 4. 安全、权限和可靠性

- 文件夹选择、树列举、读取和写入全部走已认证的 `IExplorerClient`。Code Editor 不持有额外 token，不直连宿主路径，也不将目录树复制到本地持久化。
- 添加根目录及展开节点必须处理拒绝访问、目录被删除、网络断线与取消；失败只影响当前节点并可刷新重试。
- 覆盖保存是危险操作：当前标签有明确保存动作，Save As 仍由用户给出完整远程路径；脏状态不得因切换或树刷新而清除。
- 目录名、文件名和异常不得作为未转义 XAML 或命令参数处理；不调用 shell。

## 5. 平台支持

| 能力 | Ubuntu Server | Windows Server |
|---|---|---|
| 多根目录、列举、读取、保存 | 通过 Files API，遵循 Linux 权限 | 通过 Files API，遵循 NTFS ACL |
| 路径显示与比较 | `/`，区分大小写 | 盘符/UNC 由 Server 规范化，不区分大小写 |
| 语法高亮与标签页 | Client 本地一致 | Client 本地一致 |

Code Editor 不自行判断运行 OS；路径比较与文件可见性由 Server/Explorer 协议结果决定。任何权限不足都不自动 sudo/UAC 提权。

## 6. 实施拆分与验收

1. 将单一文档状态拆为 `OpenDocument` 集合和活动文档，保留已有编码、语法高亮与保存行为。
2. 实现多根目录的惰性树和“资源管理器 / 已打开文件”活动栏；复用目录选择器和 Files API。
3. 实现标签切换、关闭及脏状态确认，补齐三语言资源。
4. 验收 Ubuntu 与 Windows Server：添加两个不同根目录、深层展开、同一文件只打开一个标签、跨标签编辑/保存、权限拒绝、缺失文件、断线、脏标签关闭和语言切换。

后续优先级建议：工作区内文件名快速打开（不建立内容索引）、文本搜索，再考虑 Git 状态；LSP 和调试器应在具备受控语言服务/进程守护基础后单独设计。

## 文件树和标签上下文菜单

文件/文件夹右键支持新建文件与目录、重命名、删除、复制路径；目录可刷新、折叠，工作区根可从独立编辑器移除。新建文件需要连接提供排他创建能力；项目根不允许通过该菜单删除或重命名。项目树支持 Enter 打开、F2 重命名、Delete 删除。

标签右键可保存、关闭当前/其他/左侧/右侧/已保存/全部，以及复制绝对或工作区相对路径。批量关闭遇到未保存文档逐个确认，取消或保存失败停止后续关闭；文件夹重命名保留打开文档的草稿，删除失败保留标签。项目编辑器与独立编辑器使用同一实现。验证记录见 [项目编辑器实施记录](./RelaxKonOS.GitEditor.Progress.md)。

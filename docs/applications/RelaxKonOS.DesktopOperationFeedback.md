# 桌面内置应用执行反馈

执行状态使用底部单行状态栏（38 个逻辑像素），详细输出默认隐藏，通过入口向上展开。收起输出不会取消任务；取消仍使用独立按钮。长状态使用省略和悬停提示，侧栏和业务内容独立滚动。

## 覆盖范围

- Docker、证书、Web 服务：底部执行状态与按需日志。
- 内网穿透：底部状态与带时间的操作记录；连接运行日志窗口与 frps 诊断窗口保留。
- 共用安装面板：Docker、Git、内网穿透、网络代理、Web 服务、文件服务统一使用底部状态与按需阶段记录。进度是阶段内已验证的百分比。阶段记录不是底层命令逐行输出。
- 应用部署：顶部执行横幅改为底部状态与按需阶段记录，保留百分比与取消入口；历史操作诊断、运行日志标签页及部署向导保留。
- 网络代理：普通状态移到底部，认证故障的可操作提示保留；已有独立日志页保留。
- 文件服务、服务器中心：执行状态与进度收敛为底部单行。
- 资源管理器：选择摘要、传输进度、停止入口合并为单行；操作详情按需向上展开。

## 检查边界

扫描桌面 Apps 下的 XAML 与共用 InstallationPanel。安装/部署向导、专门的日志页与窗口、设置表单中的结果及恢复操作不是常驻工作区日志横幅，不强制改成隐藏面板。Android 不在此次范围内。

## 验证

桌面项目编译与 headless 布局检查覆盖默认折叠、按需展开、收起后空间恢复以及不中断任务的行为。

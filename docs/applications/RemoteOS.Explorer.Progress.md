# 文件浏览器 Windows 11 体验优化进度

更新日期：2026-09-06。当前阶段：第三轮多选拖放、批量删除与可靠粘贴已实现；三轮均通过客户端编译与自动化回归，真实桌面交互验收待完成。

## 目标与边界

让内置 RemoteExplorer 的常用操作尽量贴近 Windows 11 文件资源管理器，继续使用 RemoteOS 的窗口、主题、本地化、认证与宿主 OS 权限机制。允许增加文件 API，但需要同时落实 Protocol、Server、Client 和测试，不能仅放置不可用的 UI 入口。

本轮没有新增服务端 API。现有 drives/list/info、文件操作和上传接口足以支持本轮改动。搜索框为**当前已加载目录的名称筛选**，不递归搜索，不建立索引。现有删除仍为永久删除，并保留确认流程；尚无回收站或撤销能力。

## 第三轮完成（2026-09-06）

- [x] 多选拖放携带完整选择快照；按住 Ctrl 拖动复制，默认拖动移动。已选多项上的普通单击/Ctrl 单击延迟到释放时更新选择，开始拖动时保留原选择。

- [x] 跨窗口移动完成后刷新来源窗口（来源不忙时）和目标窗口；不自动刷新所有其他窗口。
- [x] 多选删除确认包含项目数量与最多八个名称预览，明确说明永久删除及目录内容；确认前固定选择范围，取消不发送请求。
- [x] 删除、拖放和远端粘贴共用客户端串行批处理：每项进度、成功/失败/未执行计数及可展开的路径错误详情；普通单项失败后继续，提权被拒后停止剩余项。

此轮复用现有 Copy/Move/Delete 接口，`overwrite=false`；没有新增服务端后台任务，也不提供原子事务或回滚。默认拖动始终移动，未实现按跨卷自动切换复制；Alt、Ctrl+Shift 链接拖放不支持。同目录“生成副本”与自动重名策略待实现。网络错误可能发生在服务器实际完成之后，本轮只能保留错误和待核实条目，不能保证跨断线重试幂等。

### P2：新增文件 API（候选设计，尚未冻结）

| 能力 | 建议契约 | 必须解决的行为 |
| --- | --- | --- |
| 大目录与递归搜索 | 扩展 list 分页/排序/过滤；新增 search 查询或搜索任务 | 稳定游标、目录变化一致性、结果上限、取消、权限不足、符号链接循环 |

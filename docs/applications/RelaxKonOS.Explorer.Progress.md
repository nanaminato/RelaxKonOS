# 文件浏览器 Windows 11 体验优化进度

更新日期：2026-09-07。当前阶段：第六轮共享文件操作窗口与服务端后台任务已实现；真实桌面交互及 Windows 服务端验收待完成。

## 目标与边界

让内置 RemoteExplorer 的常用操作尽量贴近 Windows 11 文件资源管理器，继续使用 RelaxKonOS 的窗口、主题、本地化、认证与宿主 OS 权限机制。允许增加文件 API，但需要同时落实 Protocol、Server、Client 和测试，不能仅放置不可用的 UI 入口。

第一至第五轮未新增服务端 API；第六轮新增 `/files/operations` 后台任务接口，设计与验证见 [文件操作中心](RelaxKonOS.Explorer.Operations.md)。搜索框为**当前已加载目录的名称筛选**，不递归搜索，不建立索引。现有删除仍为永久删除，并保留确认流程；尚无回收站或撤销能力。

### P2：新增文件 API（除后台操作基础版外，其余为候选设计）

| 能力 | 建议契约 | 必须解决的行为 |
| --- | --- | --- |
| 大目录与递归搜索 | 扩展 list 分页/排序/过滤；新增 search 查询或搜索任务 | 稳定游标、目录变化一致性、结果上限、取消、权限不足、符号链接循环 |
| 批量复制/移动/删除（基础版已实现） | POST files/operations + GET 列表/状态 + decision + cancel | 已有并发、当前文件进度、冲突、取消及保留期内幂等；后续验收 Windows/提权与完善崩溃恢复 |
| 回收站/还原 | recycle、trash/list、restore | Windows/Linux 平台能力协商、原路径冲突、永久删除区分、无回收能力时明确提示 |
| 撤销 | 基于操作结果的可撤销记录 | 不承诺不可恢复操作可撤销；覆盖、跨盘移动与失效记录的处理 |
| 文件夹更改通知 | 文件目录订阅/事件 | 断线恢复、合并事件、权限边界与刷新节流 |
| 缩略图与预览 | thumbnail/preview（限尺寸、类型） | 缓存版本、大小限制、不可信文件解析隔离 |

每项 API 必须同步修改 `Shared/RelaxKonOS.Protocol/Files`、`RelaxKonOS.Server/Endpoints/FileEndpoints.cs`、`RelaxKonOS.Server/Files`、`IExplorerClient` / `ExplorerClient`，并继续复用 JWT、现有提权机制和宿主 OS 权限。

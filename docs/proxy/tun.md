# TUN 安全性

TUN 是主机范围操作，而非普通 UI 开关。网络变更前，RelaxKonOS 会写入恢复标记、捕获管理路由方案；当平台无法建立安全的管理路径时会拒绝激活。

强制的系统绕过范围包括回环、RelaxKonOS 监听器、当前管理会话、默认网关、局域网、SSH 和 RDP。生产主机启用 TUN 前仍须完成平台验证。

启用事务只修改 Server 所拥有的 `active.yaml`：它生成受控的 Mihomo `tun` 区段、启用 TUN、保留回环和私有局域网段，并将已捕获的默认网关及 Server 观察到的当前管理连接地址排除在 TUN 路由外；随后由 Mihomo 自己通过受限服务身份装载路由与 DNS。Server 不拼接或执行路由命令。控制器重载、管理路径验证或恢复任一步失败，事务都会重新禁用 TUN；恢复标记只有在原管理路径重新验证后才删除。

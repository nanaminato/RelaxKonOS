# 代理网络恢复

启动时，RelaxKonOS 会先评估任何持久化的 TUN 恢复标记，随后才允许再次激活。“紧急禁用 TUN”会独立于运行时卸载恢复已捕获的网络状态；若恢复失败，标记会保留。

Mihomo 直连重载失去确认时，组件中心的运行时恢复面板显示原操作 ID。具备管理权限并完成宿主提权的操作员可以重试。重试只在受保护的活动文件仍匹配候选摘要时恢复原磁盘配置。原操作仍显示待恢复，因为 Mihomo 可能继续运行已加载的候选配置。TUN 的紧急禁用和系统代理的恢复继续使用各自的持久记录。

首次平台验证应在带有第二条管理连接的一次性 VM 上进行。尝试 Windows 或 Ubuntu 恢复演练前，请先查看跳过测试登记表。

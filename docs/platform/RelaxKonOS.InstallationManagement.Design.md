# 安装组件、设置与修复

更新日期：2026-10-14。服务器中心安装管理的实施规范；Android 页面细节由 Android 自有文档维护。

## 产品入口

管理安装分为详情、组件、安装设置和维护。首次安装提供 Guardian 可选项；后续在组件页补装或移除。进程守护应用的未安装状态链接到组件管理，同一个部署流程处理两个入口。

WindowsSystem、LinuxSystem 和 LinuxUser 支持 Guardian；WindowsUser 当前不支持，界面不得提供不可执行选项。发布包继续携带同版本 Guardian 文件，选择决定是否部署与启动，不决定包内文件是否存在。

## 状态与操作

安装记录保存 guardianEnabled，升级与普通修复继承已有选择。显式配置操作修改选择；未安装、停止、故障和未知必须区分。实际服务列表依据安装记录返回，能力矩阵只描述支持范围。

配置通过现有固定 SSH / 本地提权部署通道执行，必须校验安装 ID、获取独占锁并保存操作记录。配置不下载新版本；补装使用当前版本文件。移除前确认工作负载将停止，定义和日志默认保留。

普通修复恢复所选组件，不隐式补装未选 Guardian，不更改监听地址、权限和证书身份。重新生成证书是显式高级修复动作。

## 安装设置

首版支持监听端口、本机 / 局域网访问、已有证书保留或显式重新生成自签证书，以及 Guardian 选择。设置先读取宿主记录，不用 UI 默认值覆盖未知信息。文件访问策略、白名单、自动启动和受管防火墙移除需要完整事实读取与权限回滚后开放；目录迁移和安装模式转换使用专门流程。

配置提交显示当前值与目标值以及重启影响。配置变更失败应恢复原配置；不得在实际验证前发布新安装状态。网络或证书变化后重新核对连接地址和证书信任。

## 修复验收

修复方案显示发现的问题、涉及组件与重启影响。分别验证 Server 健康及所选 Guardian 的运行 / 认证 IPC；Server HTTP 健康不能代替 Guardian 健康。保留 JWT、审计身份、Guardian 定义和日志。二进制缺失时明确要求使用发布包恢复，不把重放部署声明为文件恢复成功。

## 实施检查

- 首次不选 Guardian，Server 正常运行且不启动 Guardian。
- 补装后 IPC 可用；移除停止工作负载并保留定义。
- 升级、修复及回滚保持组件选择。
- 设置读取失败禁止保存；安装 ID 变化禁止旧窗口写入。
- 网络配置失败恢复原监听配置和运行状态。
- WindowsUser 不显示 Guardian；LinuxUser 不承诺系统级开机启动。

实施进展和未完成验收必须单独记录，不将本规范视为已实现证明。

## 当前实施范围与验证

当前代码已接入首次 Guardian 选择、后续组件配置、端口和监听范围修改，以及桌面本地管理 / SSH 管理 / Android 维护入口。共享请求新增 `configure` 和可空 `guardianEnabled`：null 保留选择，false 跳过或移除。宿主快照分别返回选择和进程运行状态；进程运行状态不等同于认证 IPC 健康。

安装记录必须显式保存组件选择；缺少该字段时不猜测为已选择，也不通过旧格式解析或迁移适配继续维护。预发布旧记录需按当前安装契约重新部署；Linux 记录丢失时可从可信宿主配置恢复选择。

部署成功时对所选 Guardian 执行宿主本地 `guardian-health` 认证 IPC 检查。普通修复保持选择，并展示现有核验详情及重新应用范围；当前仍是重放服务配置，没有逐文件损坏诊断与从发布包恢复文件的独立修复计划。

受控验证包括协议序列化、Linux 参数映射、Windows 注册 / 移除分支、三种模式配置失败恢复、跳过 Guardian 的安装记录恢复、本地配置提交前状态复核、桌面视图回归、Guardian IPC 读取及 Android 维护契约测试。桌面 / Server / Android 构建已通过；Server 存在既有 ImageSharp 依赖告警。

真实 Windows / Linux 主机上的完整安装、补装、移除、重启及客户端重新连接尚未验收。文件权限编辑、自动启动策略和防火墙规则移除仍未开放；当前端口更改不自动迁移旧防火墙规则，需显式按新端口修复。Windows 个人模式不支持 Guardian。

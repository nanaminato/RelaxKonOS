## 暂不优先的方向

- 完整 SQL/Redis 数据编辑器：专业工具优势明显，优先应用维护流程。
- 完整 IDE、办公套件、绘图工具：优先外部应用入口，不重新建设整套产品。
- 自研相册、影音、知识库或密码管理器：优先部署成熟产品。
- 完整 Kubernetes 管理平台：现阶段投入大，可待用户规模和需求明确后评估。
- 只有启停和网页链接的独立原生应用：优先使用部署模板。

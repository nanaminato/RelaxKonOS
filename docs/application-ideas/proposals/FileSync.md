# APP-002 文件同步与云存储

> 状态：候选。更新：2026-11-04。建议形态：外部适配。关联：APP-008 云存储管理。

[返回方案索引](README.md) · [推荐顺序](../Priorities.md)

## 场景与价值

用户在文件管理器选择目录，直接传到另一台服务器或云存储，不需要让数据经过客户端。任务在服务端持续执行，其他设备可查看进度与结果。

流程：选择源和目标 → 预览新增、覆盖与删除 → 确认任务 → 后台执行 → 查看结果和失败项。

## 首版范围

- 单向复制、源与目标差异预览、后台进度和失败记录。
- 明确区分复制与镜像同步，镜像删除目标文件需要单独展示。
- 区分传输结束与内容核验结果。

双向同步、自动冲突合并和文件系统挂载后置。APP-008 负责远端资源入口，本提案负责传输任务，两者可共用连接定义。

## 外部工具与现有基础

评估 rclone，参考[官方文档](https://rclone.org/docs/)和[sync 删除语义](https://rclone.org/commands/rclone_sync/)。具体后端能力、校验方式和平台限制在立项时核实。复用文件管理、传输和任务领域已有能力。

## 所有权与边界

源与目标分别做权限检查；远端凭据不能透传到客户端日志。执行前重新检查计划条件，预览后发生变化时不能假定原计划仍有效。客户端断线不代表取消；服务端中断后的部分结果需要核对，不能盲目重复删除或覆盖。

## 验收方向与待决问题

验证大文件、同名文件、权限不足、网络中断、取消及部分失败。用真实目标目录确认覆盖与删除结果。

待定：首批云后端、服务器间认证、覆盖规则、符号链接处理、任务恢复粒度和带宽限制。

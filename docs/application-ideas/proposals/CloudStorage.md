# APP-008 云存储与内置文件浏览器

状态：设计提案。云连接器、文件来源契约及 Explorer 接入尚未实现。

## 安装与连接

云存储作为可选的服务端 `.rkmodule`，运行在隔离的 ModuleHost。用户可跳过安装。组件中心管理模块的安装、停止、重启和版本，连接管理负责各账户的授权和撤销。首版用一个模块交付 WebDAV 和 S3 兼容连接器，用户选择需要的连接。以后可按发布和依赖边界拆分成独立模块。

Explorer 侧栏增加「云存储」，每个已授权连接显示为一个根。模块停止或更新时，已有入口显示暂不可用，导航保留当前上下文。撤销授权后移除入口。连接包含显示名、协议、端点、根范围、所有者和访问策略。WebDAV 用限定目录作为根。S3 用桶与键前缀作为根，空目录、移动和目录删除按连接器能力呈现。

## 文件来源契约

在 Explorer 服务端增加来源目录和统一的文件操作契约。Core 发现生效的来源并核对调用者、连接和操作权限，再经 ModuleHost 认证代理转发到连接器。模块通过受约束的能力描述注册文件来源，客户端仍由内置 Explorer 渲染。宿主文件保留现有文件接口。Explorer 的导航状态使用来源 ID、连接 ID 和不透明条目引用，显示路径由来源提供。

首版支持分页列举、属性、流式下载，以及连接允许时的上传和新建目录。读写用连接器能力和权限共同决定。重命名、原子替换、删除和服务端复制分别声明。对象存储的移动若需要复制后删除，任务应记录两步结果，避免复制失败或超时后误删原对象。接受宿主路径的内置文件选择器只显示宿主来源。支持流式文件引用的调用方可显式启用云来源。

## 凭据和传输

业务访问使用各连接的云端账号或最小权限密钥。设计需实现服务端受保护的凭据存储与连接范围的交付机制。当前 ModuleHost 的私有存储和特权 `secret.reference` 不提供这项凭据交付。模块只取得完成连接所需的凭据，响应、URL、审计、模块包和日志不得携带秘密值。新连接要核对出站目标、TLS 和重定向，明确区分允许的内网 WebDAV 与默认拒绝的宿主敏感地址。连接撤销阻止新请求，并明确处理在途任务。

跨来源复制由服务端传输任务流式搬运，任务记录源、目标、进度及核验结果。首版优先只读浏览和下载，再增加上传与跨来源复制。OAuth 网盘、同步、系统级挂载和外部工具由后续阶段评估。连接器的启动和健康检查保持共享数据可由上一版读取，便于启动失败后的模块版本回退。

## 验收

- 无模块、已安装无连接、只读连接、多连接、连接撤销和模块停止分别呈现正确状态。
- WebDAV 与 S3 的分页、下载和能力差异通过真实端点核验。
- 同一连接的授权隔离、凭据轮换、异常重定向、传输中断和文件选择器的来源限制均有回归覆盖。
- 更新连接器只中断目标模块。新版无法启动时，旧版恢复后可访问原连接。

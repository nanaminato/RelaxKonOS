# 内置应用界面：分析与现代化基线

> 2026-10-04：已实现共享视觉角色与下表中的界面调整。验证记录见文末；目标平台的人工验收尚未完成。

本文负责桌面内置应用的共同界面规则与本次调整记录。各应用的功能、协议、权限与操作流程仍由 `docs/applications/` 中的专题文档定义；Android 的界面规范由 Android 文档维护。

## 设计判断

管理应用已有多页工作区，但标题、侧栏、卡片的配色和圆角各自定义，视觉层次不一致。部分数据表用外层横向滚动容器加固定高度，小窗口需要滚动整页，大窗口却无法展示更多数据。编辑器需要保留内容空间，同时让工具栏、状态栏和辅助信息更容易区分。部分页面用透明度或固定灰色显示说明，在不同配色中对比度不稳定。

采用以下共同规则：

- 背景、抬升表面、次级文字与分隔线使用语义颜色；圆角使用系统风格令牌。
- 工作区标题、导航和正文各有独立层次。标题允许换行，选中导航保持强调轨道；导航命中高度跟随 `MinimumHitTarget`。
- 表格使用清晰的表头、适度的行间距与悬停/选择反馈；保留用户调整列宽和各应用已有的排序、选择方式。
- 资源列表使用剩余空间，表格承担自己的滚动；概览和多表文档可滚动。创建与刷新在列表顶部，针对选中项的动作在列表下方。
- 查看器、编辑器与终端保留各自的内容呈现方式。图像、网页、终端颜色和语法高亮不由通用表面样式覆盖。
- 对话框与安装器的决策按钮留在可见页脚；说明与字段可滚动。

## 各应用分析与调整

| 应用 | 分析 | 本次调整 |
|---|---|---|
| Docker | 资源页表格固定为 230px，外层滚动与表格滚动重复；标题使用平台差异较大的 emoji | 容器/镜像/网络/卷使用弹性表格，创建与刷新合并到顶部，常用操作可换行，暂停/编辑/日志/统计集中到更多操作，无日志和统计时将空间归还列表；工作区使用打包图标；概览、编排和设置仍可滚动 |
| 证书管理 | 标题、列表卡片与说明层次不一致 | 共用标题、侧栏、卡片和表格角色，标题使用打包图标 |
| Web 服务管理 | 标题较厚重，页面面板独立定义外观 | 统一标题密度、图标、侧栏、面板与表格 |
| 代理管理 | 侧栏、概览卡片与资源表格各自定义样式 | 统一标题、导航、面板与表格；保留连接、日志和节点操作 |
| FRP 隧道 | 页面布局已分离，圆角和表格外观分散 | 接入共享应用背景、侧栏、内容面板与表格角色 |
| 端口转发 | 操作页已用弹性列表，但标题与外层滚动独立 | 标题改为打包图标，统一标题与侧栏；保留列表卡片和原有弹性布局 |
| 应用部署 | 多页工作区已有运行态/期望态展示 | 统一标题、侧栏与资源表格；保留任务状态、预检和部署流程 |
| 文件服务 | 支持窄窗口布局，标题与状态同等突出 | 强化标题，状态使用次级文字，资源表格接入统一样式；保留窄窗口导航 |
| 服务器中心 | 工作区完整，但头部与底部状态的外观分散 | 统一标题、侧栏、底部状态与历史表格；保留部署和主机信任流程 |
| SSH 文件浏览器 | 文件表格和操作区需保持高信息密度 | 接入资源表格样式；保留文件列宽、操作与滚动方式 |
| Git | 分支、历史、工作区面板各自定义圆角 | 统一面板、侧栏、底部状态与表格；保留 diff 和冲突解决布局 |
| 防火墙 | 横向设置操作在小窗口中容易超宽 | 设置操作支持换行，新增规则使用主按钮，删除采用危险色；表格可调整列宽 |
| 进程守护 | 提示面板硬编码小圆角，工作负载表格风格独立 | 提示使用共享面板，表格接入统一样式并允许调整列宽 |
| 事件与告警 | 列表缺少边界，固定灰色说明、摘要硬编码英语 | 增强摘要字号与列表间距，说明使用动态次级色，摘要加入中英日资源并跟随语言切换 |
| 任务管理器 | 辅助指标使用透明度，结束任务与普通主动作相同 | 指标标签使用次级色，导航圆角跟随系统风格，结束任务采用危险按钮；进程数与表头本地化 |
| 文件资源管理器 | 已有完整文件视图与弹性表格 | 统一工具栏和表格表头；保留动态行高、固定初始列宽、视图模式、拖放与选择行为 |
| 注册表 | 树/值表需要保持紧凑，菜单含硬编码英文 | 值表接入共享样式，新建键/删除键补齐中英日资源 |
| 浏览器 | 内容区已有侧栏和网页宿主 | 统一工具栏、侧栏与状态栏；网页内容继续由 WebView 呈现 |
| 代码编辑器 | 工具栏、文件侧栏和状态栏缺少统一层次 | 接入共享工具栏/侧栏/状态栏，文档标题与状态采用次级色；保留紧凑标签页与代码内容 |
| 记事本 | 文档标题和底部统计依赖透明度 | 统一工具栏与状态栏，辅助文字使用语义次级色 |
| 终端 | 内容区需保留 ANSI 呈现，状态文字重复降低透明度 | 状态文字直接使用次级色，接入应用视觉作用域；保留终端内容与已有抬升工具栏 |
| 图像查看器 | 已有缩放工具、内容背景与空态 | 工具栏、状态栏和内容边界接入共享角色；保留图片缩放和装饰背景 |
| 应用安装器 | 安装/跳过按钮在滚动内容内部，长权限清单会将其推离视口 | 决策按钮固定在页脚，来源选择可换行，权限面板统一表面 |
| 欢迎页 | 功能说明在较小窗口中可能超出卡片 | 卡片说明可滚动，副标题使用语义次级色 |
| 设置 | 已有响应式导航与页面分离 | 统一侧栏、面板表面与表格；保留搜索、窄窗口导航、草稿与保存状态 |
| 网络检查器 | 固定宽度筛选框加横向操作区容易超宽 | 筛选框使用弹性列，表头与列表使用共享资源表格角色；保留请求详情和分隔条 |

## 实现入口

`Framework/RelaxKonOS.UI/Themes/ApplicationStyles.axaml` 定义可复用视觉角色，由 `RelaxKonOSTheme.axaml` 引用：

| 角色 | 用途 |
|---|---|
| `builtin-app` | 内置应用视觉作用域与默认背景；页面局部值可覆盖默认值 |
| `app-header` / `app-title` / `app-description` | 工作区头部、标题和辅助说明 |
| `app-sidebar` | 导航与辅助侧栏 |
| `app-panel` | 无额外浮动阴影的正文表面，圆角跟随系统风格 |
| `app-toolbar` / `app-statusbar` | 顶部操作区、底部状态区 |
| `resource-table` | 表格、表头、单元格间距和默认滚动 |
| `app-list` | 事件与告警等独立列表 |

角色显式加在界面控件上，不依赖文件名或运行时遍历视觉树。局部值优先于默认样式，因此文件列表的动态行高、网络检查器的自动行高以及专用模板可以保留。Shell、外置应用与协议不增加新接口。

## 验证

2026-10-04 已通过：桌面端构建；90 组真实页面布局检查（Docker 工作区资源页 72 组、安装器 18 组）；AXAML 与语言 JSON 解析；文档链接与差异空白检查。已查看浅色容器页、深色镜像页及安装器页脚截图。

桌面构建：

```sh
dotnet build Client/RelaxKonOS.Client.Desktop/RelaxKonOS.Client.Desktop.csproj -m:1 -p:UsedAvaloniaProducts=
```

真实 Docker 资源页面布局回归：

```sh
dotnet build Tests/Client/RelaxKonOS.ApplicationLayout.Tests/RelaxKonOS.ApplicationLayout.Tests.csproj -m:1 -p:UsedAvaloniaProducts=
dotnet run --project Tests/Client/RelaxKonOS.ApplicationLayout.Tests/RelaxKonOS.ApplicationLayout.Tests.csproj --no-build --no-restore
```

测试通过真实 Docker 工作区导航打开容器、镜像、网络和卷页面，覆盖三语言、两种外观模式、三种系统风格组合，检查小窗口表格和创建按钮边界、大窗口表格增长、缺失文案，另外验证安装器的长权限清单滚动不会移动底部确认按钮，并渲染中文页面截图到测试输出目录的 `layout-qa/`。测试使用本地样例数据，不连接服务端。

仍需人工验收：Windows/Ubuntu 实际窗口、150%/200% DPI、菜单和键盘焦点、服务端加载/断线/错误/长任务、原生 WebView/终端/编辑器、其他应用的长名称与大量数据。自动布局检查不能代替这些运行和视觉验收。

## 环境与范围

2026-10-01，实体 Samsung SM-X510，ADB 指定 USB 序列号测试，避免同一平板的无线连接及 SM-S9380 干扰。先检查已有 SSH 页面并返回登录入口，随后巡检 Server 页面，再重新连接 SSH 检查全部六个主入口。观察到横屏 2304×1440 和竖屏 1440×2304。测试地址为 `https://192.168.1.9:5000`，SSH 为同宿主的 22 端口，账号为 nanami。密码不写入文档。

5000 端口提供 HTTPS：HTTP 请求提前断开，HTTPS 登录路由 GET 返回 405；设备确认自签名证书后登录成功。初次测试手动填写 HTTP 导致探测失败，不能归因于无协议地址自动发现；代码已对无协议地址优先探测 HTTPS。自签名证书指纹属于信任依据，必须保留；终端内部会话 ID 不需要展示。

首轮为页面读取、入口与基础终端操作巡检。后续 TAB-04/05 修复复验使用同一 SM-X510 的无线 ADB，修复宿主 Guardian 服务权限并重启该服务，执行一次测试脚本和临时守护任务的创建、启动、停止、删除。未安装 Docker，运行时安装及完整资源操作仍待执行；未执行网站发布、防火墙变更或宿主设置写入。

## 执行证据

Android Kotlin 编译、1,022 项 JVM 测试和 Debug APK 构建通过。SM-X510 执行 `WorkspaceNavigationTest` 六项通过：未提交草稿保留/一次提交不会因分类切换重放、360dp 与 2 倍字体下固定分类可达/各页滚动独立、Activity 保存恢复与所有者切换清理、隐藏面板不占当前视口、360dp 下全部八分类触达，以及标题返回按钮在分类栏上方、切换后仍采用当前内页的离页处理。`MobileNavigatorTest` 增加设置分类一次返回目录与其它顶级导航栈保留检查。

SM-X510 连接 Linux 测试宿主进行了只读巡检：Docker 概览/容器、Git 工作区/历史、网站实例/站点、证书概览/操作、FRP 概览/日志、Mihomo 概览/节点，以及任务管理器性能/进程切换和返回已确认。Docker、任务管理器、外观与宿主设置实页确认标题/返回按钮在分类栏上方，内页未重复显示标题。设置从外观切到宿主设置，范围标签由 Android 本机变为远端宿主，系统返回一次回到更多目录。SMB 返回概览/共享/用户分类，宿主尚未安装 Samba；网站、证书和 FRP 没有可编辑资源，因此不把入口/空状态检查记为编辑或恢复通过。

## 尚待验收

- 各应用真实资源的列表→详情→编辑→返回，确认离页草稿保护与选中资源上下文。
- 真实活动操作、断线/未知结果、取消/恢复与运维目标跳转；不重复请求，不生成新操作 ID。
- Windows SMB 无 Unix 用户能力、Linux Samba 用户能力及能力变化后的分类门控。
- 手机真机横竖屏、IME、TalkBack、英文/中文/日文与各主题；完整平板应用流程及分屏。
- 进程终止后的非敏感状态恢复，以及账户/宿主切换的迟到请求隔离。

服务器中心 SSH、端口转发和运维中心沿用既有工作区组织。文件、终端和编辑器按各自任务流验收；桌面独立应用能力差异仍归 [BuiltInParity](../plans/BuiltInParity.md)。

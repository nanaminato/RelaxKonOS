# Android 界面与流程复审要求

当前登录、首页和应用目录采用 [应用桌面与最近服务器登录](../design/ApplicationDesktop.md)。旧界面的逐页进度、历史执行日志与验收计数已清理，不能用于证明当前界面通过验收；既有行为回归测试保留，历史变更由 Git 保存。

## 复审方法

以当前生产入口重新建立清单，逐项检查主要任务、正常和错误路径、子页与对话框，再进行设备视觉与真实业务验收。源码检查、编译、隔离模型测试和模拟器测试分别记录覆盖范围，不能互相替代。

- 登录：最近服务器、无记录、直连、SSH 配置与受管安装；保存凭据、手动覆盖、取消认证、失效密钥、证书和主机密钥确认；失败后保持目标并可重试。
- 导航：首页、文件、应用、我的；应用能力门控、终端入口、详情返回、切换服务器、退出清空会话和导航。
- 布局：手机、平板、横屏、分屏、大字体、键盘、长地址及长应用名称；中文、英文、日文、浅深色、高对比度与 TalkBack。
- 领域操作：草稿离页保护、确认实例归属与一次消费、刷新及后台撤销旧确认、旧回调和迟到响应隔离、未知结果只读核实及禁止自动重放。
- 状态：未查询、加载、失败、过期、空集合与真实成功分别展示；不把连接成功当作所有服务健康，不把定义备份当作业务数据备份。

真实宿主副作用与设备矩阵按照 [验证要求](Verification.md) 执行。Git 不属于 Android 支持范围，其余功能边界见 [移动端功能精简](../design/MobileSimplification.md)。

# Android 界面与流程专项审查

按本次用户要求建立专项进度追踪，集中维护在此；当前产品规则仍以 `design/` 与 `features/` 为准。

## 审查流程与验收

每个界面依次完成：现有功能与入口清单 → 主要用户任务与状态流 → 正常及错误路径审阅 → 调整实现 → 相关回归检查 → 设备视觉与真实业务验收。修改前后核对功能，不以删功能、跳过认证或隐藏错误减少步骤。

状态为待审查、源码初审完成、审查中、已实现待验证、已验收、受阻。编译通过不等于设备验收；主入口清单还需逐页补充编辑器、子页和对话框，文件数量不等于功能覆盖率。

- 信息层级：一处主要操作，列表使用行，卡片承载独立内容；避免嵌套卡片与重复标题；按需展开说明，完整信息仍可访问。
- 流程：复用同一次操作已验证的结果；认证、保存与提权分别处理，切换身份不会复用另一身份的凭据。
- 恢复：空输入、非法参数、认证拒绝、授权取消/失效、主机密钥变化、超时/断网、重复点击、迟到响应、旋转、后台和进程回收均有下一步。提交结果未知时先核实，不盲目重放写操作。
- 布局：小屏、大字体、键盘、长地址、平板和横屏；中/英/日、浅深色、对比度、TalkBack与点击区域；重要信息不能因截断永久丢失。
- 验证：按行为风险补充回归测试，视觉和远端业务按照 [验证矩阵](Verification.md) 验收。

参考 [Material 分组列表](https://github.com/material-components/material-components-android/blob/master/docs/components/List.md)、[Material 自适应布局](https://m3.material.io/foundations/layout/canonical-examples/overview) 和 [Apple 按需展示](https://developer.apple.com/design/human-interface-guidelines/disclosure-controls)。结合现有 Android Compose、导航、安全及图标体系采用这些原则。

## 首批：服务器中心

确认的问题：管理表单的提交门控忽略协调器中已验证的会话密码；无安全锁屏设备因此再次输入。

已实现：会话凭据允许留空提交并显示复用提示，手动密码优先；认证拒绝后清除会话副本，保留保险箱记录；连接及保存授权期间禁止重复提交与切主机；取消验证恢复状态。主机列表采用组外标题与分组行，管理目标以只读地址行替代三个禁用输入框，加入键盘避让与整行保存选项。主机信任、保存、忘记密码、删除主机与工作区入口均保留。

| 验收场景 | 预期 |
| --- | --- |
| 无锁屏，添加验证成功后点管理 | 留空可连接，不重复输入，不保存明文 |
| 已有会话或保存凭据，手动输入新密码 | 优先使用新输入 |
| 会话密码已被主机拒绝 | 清除副本，允许手动更正，不自动删除保存记录 |
| 网络失败后重试 | 保留已验证副本，原因不误报成密码错误 |
| 首次或变更主机密钥 | 显式确认后续接原操作，取消可重新开始 |
| 取消解封或保存授权 | 表单恢复可操作；取消保存仍可进入已认证工作区 |
| 验证/保存期间连续提交及切主机 | 同时只有一条连接与授权流程 |
| 关闭服务器中心或进程重启 | 无安全保存时重新认证，不沿用旧会话 |
| 三语、大字体、键盘、长地址 | 操作可滚动到，内容可读，单一复选框语义 |

`ServerCenterSubmissionTest.kt` 覆盖会话复用、不可用凭据后的手动更正、可用保存凭据、忙碌状态与缺少目标。实际构建与测试结果见下方验证记录。

## 本轮发现与修复

- 登录主表单在次级入口之前显示，内容最大宽度 520dp；保存选项整行可点，忙碌期间阻止切换登录目标，设备配对页避让键盘。
- 登录记录提供可见更多操作入口，左滑仍可使用；操作对话框明确服务器与账号。
- 通用卡片标题和操作随宽度与字体分行；键值详情不截断长路径和指纹，危险确认和诊断导出文本可滚动。
- 文件操作浮层订阅登录状态，避免保留已退出的会话身份；Activity 由 Compose 的 LocalActivity 提供。
- Docker Compose 编辑器记住名称与 YAML，修复重绘后内容回到初始值；返回与取消确认放弃，预览/部署忙碌期间锁字段并避让 IME。预览/提交拒绝保留编辑并在对话框内显示原因，仅成功提交回执关闭。导入后台有界读取，严格 UTF-8，超过服务器 1 MiB 上限明确拒绝。导入响应与预览后提交重新核对账号，登录变化清空页面状态。
- 脚本编辑器统一系统返回和页面返回，未提交修改允许取消或明确放弃，身份切换清空草稿，键盘不遮住滚动操作。
- 网站应用发布显示读取失败和缺少实例/运行应用的原因及刷新入口；刷新移除失效选择。
- 服务器中心关闭取消认证并清除表单，SSH 协调器传播协程取消；忙碌期间阻止切主机。工作区内部返回仍保留原导航。
- 证书、站点/发布、代理/隧道安装、提权保存、部署、守护、宿主设置、SSH 安装/维护/终端及文本格式选项使用整行单一语义操作；外观单选消除重复点击节点。文件权限选项整行点击并换行、弹窗避让 IME。网站发布提交锁定目标与字段。
- 维护状态不再直接显示异常原文；连接、权威失败、结果未知及后置核验失败分别本地化。变更执行后无回执要求核实历史，取消维护确认清空临时提权密码，主机变化重置确认状态，忙碌门禁一致。
- SSH 认证阶段服务端断开原被归为通用握手失败并保留复用提示；现在识别结构化认证拒绝及明确的认证次数上限，清除会话密码缓存，普通协议断开不误报凭据错误。错误密码拒绝、复用提示清理及正确密码恢复 SFTP 已在实体机验证。
- FRP 配置与安装编辑器内显示失败/待核实反馈，保留草稿并暂停自动观察；安装编辑器忙碌返回与关闭按钮门禁一致。请求开始及连续读取之间核对当前会话。Profile 保存反馈/忙碌锁定、返回取消/明确放弃设备回归通过；真实配置草稿和 frps TLS 选项滚动、整行点击与返回放弃通过。
- SMB 事实读取失败或共享能力失效时保留只读草稿和共享页签，提供刷新并保留输入的恢复入口，旧事实不提供写入权限；密码确认避让键盘并锁定忙碌输入。草稿恢复只读/刷新/忙碌门禁 1 项实体机回归通过。
- Mihomo 名称/YAML/订阅编辑冻结打开时的目标与修订，避免列表读取失败触发重建并丢失草稿；编辑器内显示失败/待核实反馈，后续读取不覆盖原提交拒绝。配置和安装编辑暂停任务观察；安装忙碌返回门禁一致。名称草稿、失败反馈与返回取消设备回归通过。

- 防火墙规则字段、策略选项与关闭在提交期间锁定；失败反馈显示在编辑器内，事实读取失败保留只读规则/策略草稿，刷新不清空输入或解除待核实写入。只读草稿可见、刷新忙碌与返回门禁 1 项设备组件回归通过。
- 部署定义和新版本编辑统一系统/标题/底部关闭；字段、集合、未加入列表的输入及版本参数/归档有修改时确认放弃，忙碌与归档准备禁止关闭。定义原始差异不依赖字段有效性；2 项 JVM 与 2 项关闭保护设备组件回归通过。
- 移除两处无约束用途的 BoxWithConstraints，修正终端条件分支，12 个 Lint 错误已清零。

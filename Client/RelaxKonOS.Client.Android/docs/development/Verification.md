# Android 验证要求

本文描述设备、宿主与故障场景的检查方法和预期行为，不记录实现进度或历史执行结果。具体功能以 `features/` 为准；编译和 JVM 测试不能替代真实设备与宿主验证。

## 设备与发布

终端工作区外观设置的 `TerminalSettingsControllerTest` 检查取消读取撤销旧保存资格、取消保存显示待核实且不重放、意外异常脱敏反馈，以及新登录读取期间旧响应不能覆盖设置或提前结束忙碌。`TerminalSettingsRecoveryTest` 使用生产设置对话框，实际点击保存与刷新，验证禁用门禁及成功重读后的恢复；隔离读写函数不替代真实工作区设置 GET/PUT 和跨客户端冲突验收。

守护页面读取取消后须结束加载、显示脱敏失败和过期提示，并禁用创建及生命周期动作；通过实际刷新按钮恢复后才重新开放。编辑器读取取消保留草稿，写入取消保留未知结果门禁，不自动重放。

守护首次进入须在延迟状态读取下初始化成功，不因自动观察抢先启动而永久保留初始过期状态。详情或日志失败后，成功的后台状态读取仍保留过期门禁与原问题码；操作被拒绝的反馈也不得被轮询覆盖。关闭提示后后台读取不得重复弹出同一反馈，显式刷新成功才恢复。`GuardianViewModelTest` 检查请求顺序与门禁，`GuardianCancellationFlowTest` 检查实际页面的禁用、关闭提示及刷新恢复。

最小矩阵：一台手机竖/横屏、约 8 英寸与约 11 英寸平板；逐项覆盖中/英/日、浅/深/高对比、大字体、TalkBack、分屏、旋转、后台返回与进程回收。布局目标按具体页面检查，不以 Shell 断点计算通过替代页面分栏验收。

`ActivitySystemBarsTest` 检查主窗口系统栏在浅色、深色、高对比和跟随系统切换后的图标明暗，以及共用背景的默认内容色。生产登录页与 Shell 仍须截图核对时间、电量、导航手势和页面标题在实际背景上可读，不能只依据窗口标志判定视觉验收。

`AppThemeModeTest` 使用真实 MainActivity 检查浅色→深色→跟随系统时 AppCompat 窗口模式同步，结束后恢复原偏好。跟随系统不得沿用启动时的显式深浅覆盖。

守护观察停止的竞争回归须包含不响应取消的状态/工作负载与详情/日志回调：离页后普通读取不能锁住加载状态，返回后的新读取可完成，旧回调不能恢复旧定义、日志或修改新请求状态。`GuardianViewModelTest` 检查调度竞争；`GuardianCancellationFlowTest` 实际移除并重挂生产页面，并通过 Activity 的 RESUMED → STARTED → RESUMED 转换，验证停止观察、新读取及创建入口恢复。隔离回调不替代真实 Agent 网络、锁屏、进程回收及完整后台生命周期验收。

## 出站代理恢复

连续相同错误须分别显示：在同一界面帧内确认关闭旧提示并完成下一次立即失败的只读请求，新提示仍须可见，提交资格保持禁用，写入次数为零。`OutboundProxyEditorTest` 检查反馈标识递增，`OutboundProxyFeedbackFlowTest` 使用生产页面检查实际弹窗重新出现。

设备测试在内容建立后于主线程检查 Activity 窗口取得焦点；截取全屏图片前还须核对活动窗口属于目标应用。语义节点可见不证明窗口实际显示，启动器或冻结画面不能作为产品视觉证据。恢复设备显示后重新执行完整设备用例，不能用先前的语义通过替代。

在读取尚未完成时切换栏目，随后返回传输失败：隐藏页不得弹出反馈，返回后才显示原失败；再次隐藏须撤下反馈，返回保留未确认的原因。关闭提示仍禁止写入，显式刷新成功后恢复提交资格，全程不发送写入。

隐藏分类的回归使用生产 `WorkspaceSection` 保留表单，并按导航层规则在隐藏时传入空返回回调。系统返回须交给外层，不触发旧表单的离开确认；重新选中代理分类后仍保留未保存草稿，系统返回须恢复放弃确认，取消确认不得清空草稿或提交写入。

`OutboundProxyFeedbackFlowTest` 使用生产页面内容与隔离网关，在 360dp 宽、1.6 倍字体下检查读取取消和写入取消。写入取消须显示结果未知；先关闭反馈弹窗，再验证保存与清除均禁用，关闭提示不得恢复提交资格。显式刷新经放弃草稿确认后只读取状态，不重复写入；读取成功才恢复提交。读取取消同样撤销旧快照的提交资格，允许显式刷新恢复。错误不得展示原始异常文本。

上述设备回归不能代替真实 Ubuntu/Windows 代理写入、Docker 重启影响、完整 Shell、手机、三语主题与 TalkBack 验收。

## 主机设置恢复

在同一界面帧关闭旧连接错误并完成下一次立即失败的刷新，新错误仍须可见，旧事实保持清空、预览禁用且无写入。模型检查反馈标识递增，设备回归通过生产弹窗的实际关闭动作检查重新显示。

`HostSettingsEditorTest` 检查刷新失败/取消清除旧快照、取消写入暴露原恢复 ID 与禁止重复提交。`HostSettingsFeedbackFlowTest` 在生产页面内容、隔离网关和 360dp 宽/1.6 倍字体下，关闭反馈弹窗后实际检查刷新恢复、预览禁用和原操作查询。查询只能读取原操作，不得重放应用请求。这些回归不能替代真实宿主时区、主机名、环境变量、提权和回滚验收。

未保存编辑后点击“服务器 HTTPS”：取消放弃确认须保留草稿且不导航；再次进入确认并放弃后只触发 HTTPS 目标，不能替换为返回目标。模型回归另外检查重复确认和后台后的旧确认不执行导航。

设置栏目隐藏时，`HostSettingsFeedbackFlowTest` 须通过生产生命周期适配验证取消挂起读取、清理草稿和临时确认；重新显示后须重新读取，不执行旧跳转或重放写入。生产 Shell 另须检查横竖屏下从宿主设置进入 HTTPS 后的系统返回和页面返回均回到宿主设置；改选其他设置栏目后不得残留该子页栈。

`AboutNavigationTest` 检查许可阅读页隐藏后不消耗其他栏目的系统返回，重新选中关于时仍保留阅读状态，可见时返回关闭许可。工作区草稿回归须先确保提交按钮实际可见、点击后立即核对一次提交，再切换栏目验证不重复提交；键盘遮挡或未命中的点击不能作为生命周期失败或通过的证据。

`DiagnosticsFlowTest` 使用生产 `WorkspaceSection` 保留诊断内容，在 360dp 宽和 1.6 倍字体下检查隐藏后没有报告弹窗，其他栏目可见；返回仍显示同一份报告，关闭报告保留自检结果且不增加读取。隐藏时重新登录相同地址须清空旧报告和自检，返回后只有新登录可生成新报告。原有读取忙碌、失败重试与凭据脱敏仍须验证；真实宿主自检另行验收。

真实只读验收检查时区当前值、UTC 偏移、生效方式与读取时间；中英日键值标题不得显示格式占位符。打开完整时区列表、搜索支持的 ID 并取消，须保留原时区且不提交变更；切换主机名类别须重新读取当前与待生效名称。界面截图与真实宿主写入验收分别记录。

## 网站发布观察生命周期

网站发布恢复须分别验证远端回执与本地记录故障：写入前不能保存原请求时不得发送；收到成功或明确拒绝后，本地读取/更新/清理失败不得改报远端结果未知。`WebsitePublicationRequestsTest` 检查原键重试、参数门禁、取消保留、账号隔离与拒绝后的存储故障。`WebsitesViewModelTest` 检查断网时原请求仍可见、已知回执保留、独立本地故障反馈及刷新后旧核实对象失效。`WebsitePublicationRecoveryFlowTest` 通过实际历史行打开原操作详情，检查完整 ID 可见；本地保存失败时仍显示回执和原 ID，恢复存储后实际点击核实按钮清除门禁。隔离记录回归不替代磁盘满、进程终止或真实发布网络中断验收。


`WebsitesViewModelTest` 检查延迟结束时复核前台资格、手动查询代次和当前任务快照；旧运行中快照不能重启已终态任务的查询。`WebsitePublicationRecoveryFlowTest` 使用生产记录组件和保留栏目，检查隐藏后停止查询、重新显示恢复原 ID，以及 Activity 后台停止、前台恢复；原有相同非终态响应持续观察至终态、读取失败恢复和应用切换归属测试须保留。只读查询回归不代表实际发布、TLS 或公网可达验收。

## 脚本执行取消确认

`ScriptsViewModelTest` 检查旧确认在关闭重开、相同账号新登录并重读相同任务、切换任务及刷新后失效；同一确认只发送一次，未知取消仍保留原任务标记。确认期间停止观察，延迟结束后复核前台资格。`ScriptLifecycleFlowTest` 在完整页面验证后台撤销、切换任务后重新确认仅取消新 ID、关闭和刷新撤下旧确认，以及重复旧回调不重发；原在途后台读取恢复和空列表反馈须保留。脚本编辑器回归须继续验证草稿、参数和环境变量，隔离网关不能代替真实 Agent 执行与取消验收。

## 证书任务取消与观察

`CertificatesViewModelTest` 检查关闭重开后旧取消对象失效、同一确认最多发送一次、普通刷新重新查询已有任务且失败撤销资格，以及计时器结束时复核前台资格。既有相同运行中回执持续观察至终态仍须通过。`CertificateCancellationFlowTest` 须实际验证任务替换撤下旧确认并拒绝旧回调，新确认仅取消新 ID；确认打开期间不轮询，冻结 Compose 帧后进入后台也撤销确认。原有证书恢复、草稿、删除和签发失败场景须一并回归；隔离网关不代表真实签发、撤销或部署业务验收。

## Git 安装取消与观察

`GitWorkspaceViewModelTest` 检查任务替换、关闭重开、重复提交、相同地址新登录及离页后旧取消回调失效；查询取消和刷新异常不得保留旧安装核实资格。计时器须在延迟结束后复核原任务、请求代次、前台资格及当前确认。`GitInstallationFlowTest` 使用完整生产安装区，验证后台撤销、替换后重新确认仅发送新 ID、前后台观察，以及查询取消后按钮禁用和显式恢复。大字体截图须核对完整 ID、取消说明及按钮；隔离网关不代替真实 Git 安装、提权或取消验收。

## Mihomo 受管运行时

`ManagedRuntimeWireTest` 须覆盖完整冻结制品布局、当前 camelCase 契约、跨运行时与动作绑定、来源路径逃逸、未知/外部/待恢复所有权、修复与已保存回退目标。`InstallationRepositoryTest` 须验证计划键与台账头完全相同，响应丢失后的显式重试保持原键，其他计划不能替换未决请求。`ProxyViewModelTest` 须覆盖刷新失败撤销目录、宿主计划拒绝、依赖问题、精确目标冻结和会话变化清理。

JVM 证书握手回调夹具须保留真实 DER/签名验证，允许 PKIX 用 null 选择默认提供者；不能用绕过验证或只在特定 JDK 上运行来替代握手并发同意测试。

完整 Android 构建与设备测试须分别核对三语言、窄屏/横屏、大字体、深浅主题、未保存关闭确认、预发布选择、两种卸载语义、计划确认后提交、取消及命名恢复。宿主集成测试须使用受保护签名来源和独立生产 HTTP/Helper 通道验证实际安装、跨版本更新、修复、回退与卸载；无来源时的拒绝测试不能代替成功生命周期验收。

## Mihomo 任务与诊断观察

`ProxyViewModelTest` 检查原安装确认随任务替换、关闭重开及相同地址新登录失效；新确认只向原 ID 发送一次。前台同轮须查询两类活动任务，延迟结束后须复核前台资格和请求代次。刷新取消不得保留旧可写事实。诊断停止后的迟到结果不能覆盖新日志，也不能清除新请求的忙碌状态；读取失败保留前台自动重试，离页后不得继续查询。`ProxyTaskFlowTest` 在完整生产页面验证安装确认后台撤销、任务替换及实际按钮发送、两类任务前后台观察，以及日志失败后自动恢复和离页停止。窄屏大字体截图须核对完整原 ID、说明和按钮；不将隔离网关结果视为真实代理、安装取消或宿主网络变更验收。

## Nginx 任务取消与观察

`NginxViewModelTest` 检查安装任务替换、关闭后重开、重复提交、相同地址新登录、读取失败撤销资格，以及计时器结束时复核前台资格与读取代次。并列任务中一个读取成功不得清除另一个读取错误。`NginxTaskFlowTest` 使用完整生产页面，检查旧确认随任务替换撤下、实际确认按钮只发送新 ID 一次、冻结 Compose 帧时后台撤销两类任务确认、无确认框时后台停止查询并在前台恢复，以及读取失败后显式恢复原任务。窄屏大字体确认须可读且按钮可达；隔离网关不能证明真实 Nginx 安装或维护任务已取消。

## FRP 安装取消与观察

`TunnelReadRecoveryTest` 须检查关闭并重新打开同一安装确认后旧对象仍不能提交，新确认最多发送一次且目标为原任务 ID。安装取消确认打开期间，即使选中活动连接，安装和连接自动查询均须暂停且确认保持可见；暂停并恢复 Activity 后旧确认撤销，投递旧回调不得发送取消。原有读取失败、显式恢复、前后台观察与任务终态停止场景须一并回归。隔离网关不能代替真实 FRP 安装或取消验收。

## SMB 操作确认

安装取消确认须绑定原登录和原任务快照，切换任务后旧确认撤下；直接投递原回调不得取消新任务，新确认只消费一次。模型同时检查安装观察间隔结束时复核前台资格和原任务，旧计时器不查询新选择。完整页面的任务替换测试须实际提交新确认并核对发送的原 ID。

`SmbViewModelTest` 检查原登录、刷新或关闭后旧确认不能提交，重新打开相同操作也拒绝旧回调，确认最多消费一次；拒绝和完成均须清空传入密码数组。`SmbCancellationFlowTest` 在完整账户页面输入两遍密码，冻结 Compose 帧后暂停/恢复 Activity，旧确认零发送且密码数组清空；重新打开字段须为空，重新输入并确认只发送一次且保留未知标记。`SmbConfirmationDialogTest` 和 `SmbRetainedShareEditorTest` 保持密码确认与只读草稿的键盘、滚动和取消检查。隔离网关不代替真实 Samba 密码、共享写入或服务启停验收。

## Docker 资源操作确认

`DockerWorkspaceRestorationTest` 使用生产完整工作区检查保存/恢复界面状态后仍选中用户栏目，并检查新入口栏目及 Stack 参数仍切换到新目标。配置变化时任务管理器也须保留用户选中的性能/进程栏目；新入口请求改变时应用新栏目。恢复栏目不等于恢复网络事实或授权，数据读取和登录归属检查继续执行。

`DockerResourceViewModelTest` 检查原登录与相同资源重登、刷新或关闭后旧回调、确认一次性消费，以及切换强制选项和切换目标时撤销旧确认。`DockerResourceCancellationFlowTest` 使用生产页面在隐藏及暂停后直接投递旧确认验证零发送，保留卷草稿后重新实际确认只发送一次，未知标记保留且旧确认不得重放。隔离网关不替代真实容器生命周期与资源删除验收。

任务恢复弹窗须在软键盘打开时仍能滚动到操作 ID 输入与查询按钮；无效 ID 禁止查询，关闭重开不得沿用上次手动输入。输入有效 ID 后仅查询该任务，不提交或取消任务。小屏、横屏和大字体下另须检查说明与按钮可达。

`CertificatesViewModelTest` 须检查一次持续观察经过多次完全相同的运行响应后取得终态，且读取失败、草稿编辑和操作替换仍停止旧观察。`CertificateCancellationFlowTest` 在生产页面连续返回相同运行状态，须仍只读查询原操作至终态，不产生提交或取消请求；测试保持观察协程的计时推进，不能将冻结计时造成的超时判为漏轮询。

`CertificateCancellationFlowTest` 通过生产证书页面内容与隔离网关提交自签名表单，在写入抛出取消后检查未知结果提示、异常脱敏、原请求记录和草稿锁定。关闭反馈后域名输入仍禁用，原域名保留。这不能替代真实签发、精确目标授权、服务器换证及原任务恢复验收。

同一页面回归还须检查已返回有效任务回执后的清单刷新异常：原表单关闭，读取失败与未知提交分别提示，原操作 ID 可从操作页访问，写入次数保持一次。模型分别覆盖刷新异常、取消及传输失败；后续读取失败不得撤销已取得的任务回执，也不得留下可以再次创建的已提交表单。

证书详情已有删除入口时，清单刷新异常须撤下旧详情与修改入口；关闭失败提示不能恢复旧动作，调用原确认回调也不能发送写请求。通过实际刷新按钮成功重读后才恢复详情和删除入口，全程不执行删除。单独详情及部署信息的取消/异常也须撤下对应旧事实。手工查询其他任务保留未提交草稿；关联原创建请求的成功恢复则关闭锁定草稿，即使随后清单刷新异常。

证书创建确认须绑定原登录与完整草稿：模型检查确认后编辑草稿、以及重新登录后重建相同草稿的旧回调均不发送请求；新确认可提交。设备页面检查修改草稿撤下原提交确认，重新确认只发送一次隔离网关请求。确认期间后台读取须禁用确认按钮，不丢弃用户确认。

原请求重试须检查原登录、当前页面待核实记录及持久记录三者仍匹配；同账号重新登录后旧确认不发送请求，新确认复用原键；持久记录已核实完成而页面尚未刷新时也拒绝旧确认。

证书确认须绑定原登录：模型检查新登录尚未被页面收集，以及新登录已重新读取同一证书的两种时序，旧确认均不得写入。设备页面打开删除确认后，以同服务器同账号重新登录，旧确认须消失；重新读取相同证书后旧回调仍被拒绝，只有新页面的实际确认可发送一次隔离网关请求。

任务取消确认打开后切换当前操作，确认旧弹窗不得取消新任务；重新确认当前任务只发送一次取消请求。查询失败后自动观察与取消须暂停，显式原 ID 查询成功才恢复。模型还检查旧查询计时器不能读取新任务，以及打开/关闭草稿时的查询暂停与恢复；前台、后台及重新进入的实际生命周期另行验收。

## 文件上传与跨端一致性

文件传输验证覆盖大文件、取消、恢复和跨客户端一致性。

### 大文件与恢复

| 场景 | 通过标准 |
| --- | --- |
| 3 GB 视频（本地存储，可寻址源） | 后台运行、锁屏后完成，通知进度与界面一致 |
| Server 小文件单次上传与流式下载 | 离页、旋转、重建 Activity、后台及锁屏后继续，通知和页面进度一致；旧通知取消不停止新任务，退出登录/切服务器停止原任务；下载取消不发布残缺文件 |
| 上传服务启动失败/系统超时/移除任务 | 分块上传停止网络但保留已建立会话的日志和缓存，可由用户继续；通知与页面提供停止入口，权限拒绝仍可在页面取消 |
| 3 GB 文件（云盘源，不可寻址） | 先“准备中”落盘，再上传；成功后缓存被删除 |
| 传到 40% 切 Wi-Fi → LTE | 自动续传，偏移不归零 |
| 传到 40% 强杀应用，重进 | 显示“可继续 40%”，继续后从权威偏移前进 |
| 传到 40% 点取消 | 通知消失、目标目录无残留、缓存被删除、服务端会话在 TTL 后消失 |
| 受保护目录 + 1 GB 文件 | 弹一次管理员授权，随后完成（验证 12 MiB 天花板消失） |
| 1 GB 文件传两遍（第二遍同名） | 覆盖语义与桌面端/单发一致 |
| 分片连续超时（弱网模拟） | 分片降级后仍能完成，界面不出现“假进度” |

### 跨端一致性

同一文件分别由 Android/桌面上传，最终大小与原文件哈希一致；偏移只以服务端结果为准。设备上的流式分派与 BitmapFactory 解码不能由 JVM stub 检查替代。

## 脚本请求取消

`ScriptsViewModelTest` 检查列表读取取消结束加载并可显式恢复；提交取消清除临时授权密码，保留草稿和已尝试标记，禁止重复提交；核实取消不丢失标记，成功查询原任务后关闭创建草稿。取消任务请求取消后保留未知结果，查询终态才清除。任务详情取消后旧取消动作禁用，成功重读才恢复。`ScriptEditorNavigationTest` 验证编辑器未知结果门禁、忙碌返回及草稿放弃流程；真实宿主执行与故障恢复另行验收。

脚本观察回归须覆盖切换任务后切回原 ID，旧计时器不得读取新选择；停止前台观察期间取消进行中的读取，不产生失败反馈，重新观察可获得任务终态。实际应用前后台切换、旋转及进程回收另行验证。

`ScriptLifecycleFlowTest` 使用生产脚本页面与隔离网关，在实体 Activity 查询进行中切到 CREATED，等待超过查询间隔且读取次数不得增加、不显示失败；恢复 RESUMED 后取得当前任务终态，提交与取消次数均为零。该检查不替代真实宿主网络、旋转及进程回收验收。

脚本详情失败后刷新列表：列表成功但详情仍失败时，旧详情与取消入口不得恢复；成功重新取得原任务详情才恢复取消资格。检查刷新期间旧选择响应不覆盖新选择。

## 维护待核实记录的存储验证要求

- `MaintenancePendingJournalTest` 核对实际文件重新打开、主机与原引用隔离、错误版本/损坏/截断/尾随数据拒绝、写失败保留原记录，以及容量满时不淘汰未核实条目。
- `ServerMaintenanceViewModelTest` 核对销毁旧模型后从同一记录恢复门禁、读取记录失败不进入执行器、发送前记录失败零变更，以及核实后的清理失败不解锁。
- `ServerMaintenanceRecoveryFlowTest` 使用独立 `noBackupFilesDir` 测试目录和实际原子文件替换，检查新记录/新模型实例仍显示原 ID 并禁用变更，匹配终态后再次建立模型确认记录已清理，变更计数保持一次。清理只删除本用例生成的记录、临时文件与空测试目录。
- 完整进程回收验收需从生产入口制造受控未知结果，确认记录已提交后结束进程，重新认证并核对原主机与主机密钥，验证普通检查不解锁、只读核实不重放、匹配原回执且本机清理成功后才恢复变更。模型或 Activity 重建结果不能替代此项。

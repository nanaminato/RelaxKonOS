# 移动端功能精简

Android 面向已有远端主机的日常查看与应急管理。优先保留状态、日志、告警、文件、终端和明确目标的少量操作。需要长文本、跨资源决策、多步骤配置或反复对照差异的工作流优先在桌面完成。

频率判断来自使用场景分析，没有用户使用统计，不作为实测结论。低频但有应急价值的操作不因频率低而直接移除。

## 当前边界

Android 不提供 Git 应用：仓库注册、工作区、分支、暂存/提交、Fetch/Pull/Push、历史、冲突编辑，以及 Git 运行时安装、任务观察、取消和恢复均不在支持范围内。

Android 不提供“Git 构建 → 镜像 → 应用发布”：不创建或观察 Git 构建、不配置构建凭据、不解析远端引用，也不把构建记录交给应用部署。应用目录、帮助、导航和运维中心均不提供对应入口。

文件文本编辑器继续提供条件保存、差异比较、新建和另存；普通 Image 部署与已有应用管理保留。终端仍可由用户自行执行命令。以上范围仅针对 Android 客户端，不删除桌面或服务器 Git 能力，不卸载远端 Git，不删除仓库、构建记录、镜像或已部署应用。

## 其他精简建议（尚未执行）

下表是待评估建议，不代表当前功能已经移除，也不构成交付承诺。

| 应用或工作流 | 建议 | 判断依据与应保留的能力 |
| --- | --- | --- |
| 独立脚本执行 | 移除自由填写命令的执行表单 | 路径、参数、目录、环境、身份和超时输入繁多，与终端重叠；保留任务结果查询 |
| Squid 网关 | 保留配置、账号与软件包管理 | 手机支持访问模式、账号和安装／卸载；日志分析仍不提供 |
| Docker | 精简完整容器创建、网络/卷创建、Compose YAML 编写及复杂编排 | 保留容器状态、日志、用量、启停重启和已有 Compose 项目管理 |
| 应用部署 | 精简七步自定义向导、完整定义编辑、复杂卷与秘密配置 | 保留已有应用状态、日志、启停、版本管理；简单模板安装可保留 |
| 网站 / Nginx | 精简从零实例配置、复杂站点创建与完整发布向导 | 保留站点状态、访问入口、日志及服务启停重载 |
| Guardian | 精简完整工作负载创建与编辑 | 保留健康状态、日志及启停重启 |
| FRP | 精简 frps 服务端完整配置及复杂 profile 编辑 | 保留已有隧道状态与启停，简单端口映射可保留 |
| SMB | 精简复杂用户和权限管理 | 保留共享状态、路径和服务启停；简单新增共享另行评估 |
| 证书 | 精简复杂签发参数、手工导入和部署配置 | 保留到期提醒、详情和已有配置下的续期 |

终端、文件、任务管理器、告警与任务恢复保留。防火墙保留临时规则等应急能力；Mihomo 保留节点切换、订阅更新和连接查询；sing-box 代理服务端提供入站编辑、运行时版本计划、事务恢复、凭据撤销、订阅签发与连接信息导出。

## 变更要求

每次移除同步清理 Android 目录、路由、帮助、领域 API 调用、任务发现与恢复、资源、测试及文档。保留其他客户端和服务器的当前契约；不增加旧入口、路由别名或兼容适配。移除客户端功能不会取消已受理的远端任务，原任务与未知结果应使用桌面或宿主管理工具核实，不能从手机入口消失推断任务终态。

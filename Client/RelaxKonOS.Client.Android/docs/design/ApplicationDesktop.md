# 应用桌面与最近服务器登录

## 登录

冷启动默认选中最后一次成功登录的服务器与账号，依据连接档案的最近使用时间。直连、已保存 SSH 隧道和受管安装均参与选择，不自动跳到另一台服务器。选择本身不读取密码、不建立网络连接、不弹设备认证。

没有记录时直接展开地址、账号、密码与 SSH 设置。有记录时显示服务器和账号摘要，连接设置按需展开。可用保存密码通过独立状态行说明；点击登录才解封并认证。“使用其他密码”展开空密码输入，手动输入仍优先；缺少、不可用或失效的凭据直接显示输入与原因，不回填密码或伪造掩码。

受管安装先进入服务器中心核实本次隧道，不将安装 ID 当作 URL。缺失的 SSH 配置显示原因，不回退到其他主机。已配对设备保留独立设备密钥登录入口。服务器选择、帮助、配对和服务器中心始终可达。

认证、TLS 证书、SSH 主机密钥、保存授权及错误恢复沿用 [登录凭据规则](LoginCredentials.Design.md)。当前没有冷启动自动登录或持久刷新令牌；默认选择不代表自动授权。

## 登录后

主导航为首页、文件、应用、我的；文件入口按能力显示。终端从首页或应用目录进入，输入法打开时收起底栏。手机用底栏，平板继续使用导航轨或侧栏，各主目的地保留独立返回栈，退出清空全部导航。

首页为服务器名、账号和切换入口 → 紧凑连接与指标摘要 → 应用图标网格 → 最多三条本会话近期成功操作。连接状态仅指当前登录连接，不代表全部服务健康。CPU、内存与首个文件系统取真实读取结果；失败、加载与过期明确展示，不填示例指标、健康结论或告警数量。完整指标从任务管理器进入，任务与告警从对应应用进入。

应用目录与首页共用当前能力、服务器实测模块目录、名称、图标、顺序和打开目标。已观测模块提供的应用保持可发现：模块禁用而缺失业务能力时，入口定位绑定原连接和登录的模块详情，不自动启用、安装或提交。休眠但有效启用的模块仍走原业务入口。目录读取失败不推测模块身份，不把不支持与禁用混为一谈。目录支持本地名称/描述搜索。图标与标题组成一个点击目标，辅助说明用于无障碍与搜索；标题完整换行，大字体减少列数。手机通常四列，平板按可用宽度增加列数，不显示宽大的描述卡片。

我的保留账号、服务器连接、安全、外观、诊断、帮助与登出入口。文件、终端及各管理应用的业务流程保留；未执行的功能精简建议不因本次视觉变更成为已删除能力。

## 验证边界

旧界面专项验收记录不能证明此布局已经验收。登录、能力过滤、搜索、返回栈、键盘、大字体、主题、三语、辅助功能、平板与真实宿主交互均按 [复审要求](../development/UiReview.md) 和 [验证要求](../development/Verification.md) 检查。

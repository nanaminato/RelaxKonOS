# 服务端模块管理交互与支持边界

> 本文规定 Android 服务端模块管理的交互约束。当前客户端没有此管理页、启停写入、驻留策略或模块包操作；本文中的界面规则不构成已交付能力或发布时间承诺。服务端事实与协议由[跨端模块管理设计](../../../../docs/architecture/RelaxKonOS.ServerModuleManagement.Design.md)拥有。

## 入口与对象

管理入口归内置组件中心的“服务端模块”分区，与“宿主软件”分开。模块控制 RelaxKonOS 服务端功能；Docker Engine、Nginx、Mihomo 等软件使用原领域生命周期。Android 应用权限和系统包设置仍由“我的 → 应用”及 Android 系统拥有，不能把手机卸载按钮用于远端模块。

缺少模块的业务入口定位模块详情，缺少软件的入口定位宿主软件；跳转携带稳定 serviceId 和 moduleId，仅定位，不自动提交。没有服务端管理能力时显示不支持原因；当前客户端不提供占位写入按钮。

## 列表与详情

手机采用模块列表 → 详情 → 计划预览的单栈导航；平板使用列表/详情双栏，选中项绑定当前服务器。两种布局复用相同事实和操作状态，返回先关闭确认/预览，再回到列表和组件中心。列表筛选和滚动可在当前登录上下文保留，切换服务器或账户清空。

顶部显示目标服务器、有效启用数和当前加载数，模块行分别显示启用与休眠，不把休眠显示成停用。详情显示期望/生效差异、待重启、版本、依赖、阻止原因、策略、租约数、最近使用和唤醒耗时。加载失败、未知、恢复阻止、权限不足和平台不支持使用独立文案；未知状态不能生成可提交快照。

操作由服务器 allowedActions 控制并在提交时复核授权。多选变更展示完整依赖集合；依赖的额外变更必须进入同一预览。尝试释放有活动工作时展示阻止原因，不设计通过滑动或长按直接强制终止。

## 确认、进度与恢复

计划预览显示 Server 身份、目标模块/版本、依赖变化、数据保留、停机/重启影响和有效期限；底部确认按钮固定，内容有界滚动。大字体允许事实行和按钮换行，不压缩目标身份或仅用颜色区分状态。文本、原因参数和时间按当前语言展示，ID 和摘要可复制；支持中、英、日及 TalkBack。

提交只发送原 planId。授权失败沿用统一授权交互，不在页面保存密码；授权成功仍须由 Server 检查计划和修订。修订冲突/计划过期要求重新读取并预览，不自动生成新计划提交。

提交前在设备私有且不备份的存储中保存 serviceId/account、planId、目标 moduleId、幂等引用与 unresolved 标记，不保存令牌、密码或包载荷。结果未知时查询原操作；离页、取消等待、后台和进程回收不能删除恢复引用或自动重发变更。服务端尚未支持按原计划恢复 operationId 时，不开放提交入口。

重启断线显示等待重连，重新认证后核对原 Server、operationId、有效集合及实际版本。新连接或新账户不能接收旧会话回执；未获得权威结果不能显示成功。操作结束后刷新失败属于读取失败，不能覆盖已有成功回执。

## 生命周期与验证约束

仅当前可见且 RESUMED 的页面读取和轮询，离页/后台取消观察请求并撤销未提交确认；已提交操作由服务端继续。恢复前台重新读取事实和原操作，状态查询不得唤醒业务模块。服务器/账户切换立即撤销旧提交资格；持久恢复引用按身份隔离。

验证需覆盖手机/平板、字体放大、TalkBack、三语言、返回与旋转、后台/进程回收、切换登录、过期计划、断线回执丢失、重启重连与未知结果。协议专项必须覆盖管理查询不唤醒、无权限不加载及休眠不隐藏应用。这些是交付要求，不表示测试已经执行。

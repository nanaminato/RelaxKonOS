# AD05：Android 网站发布与网络配置计划

> 状态：待开始移动端发布编排。优先级：P0 基础、后续扩展。工作量：中到大。
> 总入口：[无电脑部署路线图](./RelaxKonOS.Mobile.Deployment.Roadmap.md)。

## 1. 目标与前置

已部署应用可以从手机配置站点、反向代理和证书，并获得可验证的访问地址。入口优先放在应用详情的“配置访问”，辅以“管理 → 站点”；站点与应用的关联只保留一份权威定义。

首版前置：应用已就绪、宿主有受支持的 Web Server/证书能力，用户掌握域名 DNS 配置权限或已有可用域名。没有公网或 DNS 控制权时明确展示限制。User Mode 不隐式升级成宿主站点管理员。

## 2. 现有基础与范围划分

复用 [Web Server 设计](../../../docs/applications/RelaxKonOS.WebServerManager.Design.md)、[证书管理](../../../docs/applications/RelaxKonOS.CertificateManager.md) 及 ApplicationDeployment 的代理集成；Android 不自行生成并覆盖宿主全部 Nginx 配置。

| 阶段 | 支持范围 |
| --- | --- |
| R1 基本发布 | 应用/上游选择、域名输入、DNS 指引与检查、受支持证书申请/绑定、代理配置检查、访问验证 |
| 后续增强 | 防火墙所需规则的明确操作、DNS 服务商授权集成、既有 FRP 隧道的手机配置 |

R1 使用已支持的服务端证书挑战方式，不承诺任意域名、网络与证书机构组合均可自动完成。内网发布依据 [FRP 设计](../../../docs/applications/RelaxKonOS.FRP_Integration.Design.md) 扩展，不与首版公网路径混为一谈。

## 3. 手机流程

1. 选择已就绪应用和目标端口，读取当前站点关联及可能的冲突。
2. 输入域名，展示需要添加的 DNS 记录及检查结果；没有 DNS API 时允许用户通过手机浏览器完成配置后回来重查。
3. 检查端口可达性和证书挑战条件，申请或选择证书。
4. 显示将创建/修改的站点、证书及访问地址；授权后执行服务端配置校验与应用。
5. 分别展示“上游就绪 / DNS / TLS / HTTP”检查结果，并提供复制、分享和打开地址。

健康检查须注明观察位置和时间。宿主 loopback 可达不代表公网可达；手机当前网络访问成功也不代表全球 DNS 已传播。无法证明的范围显示“尚未验证”，不能全部标为发布成功。

## 4. 编排与失败恢复

- Android 表单只收集意图。站点冲突、证书权限、配置测试和重载由服务端执行。
- 核对当前共享 API 对跨领域操作的持久化支持；需要时补共享发布操作及关联记录，防止手机关闭后留下不可解释的半完成状态。
- 每一步记录实际结果。证书申请失败、站点校验失败、重载失败与访问检查失败分别展示，不用“部署失败”覆盖已运行的应用。
- 回退只处理本次变更涉及的资源，保留旧站点与证书引用信息；回退失败与原始错误分别报告。
- 删除应用、取消公开访问、删除站点和吊销证书是不同动作。不能因关闭站点自动吊销仍被其他站点使用的证书。
- 不自动放开全部端口；必要网络改动展示具体范围并走现有授权模型。

## 5. 实施阶段

| ID | 工作 | 完成条件 |
| --- | --- | --- |
| AD05-M1 | 能力预检、应用/站点/证书关联与只读诊断 | 清楚区分运行、配置和网络可达状态 |
| AD05-M2 | 域名与 DNS 指引、证书申请/选择、受控代理配置 | 手机完成基本 HTTPS 发布 |
| AD05-M3 | 发布操作恢复、访问验证与针对性诊断 | 断线与失败后可定位已完成和未完成步骤 |
| AD05-M4 | 按实际需求扩展 DNS 授权、防火墙、FRP | 内网和公网流程分别验收，凭据独立管理 |

R1 要求 M1–M3，依赖 [AD02](./RelaxKonOS.Mobile.ApplicationDeployment.Plan.md) 与 [AD08](./RelaxKonOS.Mobile.OperationsRecovery.Plan.md) 的基础部分。

## 6. 验收清单

| ID | 场景 | 预期 |
| --- | --- | --- |
| AD05-T1 | 已就绪应用、可控域名与可达宿主 | 手机完成 HTTPS 发布并实际打开 |
| AD05-T2 | DNS 错误/未传播、端口不通、挑战失败 | 展示具体失败与重查入口，不误报应用停止 |
| AD05-T3 | 已占用域名、共享证书、外部站点 | 不覆盖非本次资源，不误删共享依赖 |
| AD05-T4 | 配置测试/重载失败、手机断网 | 可核实原任务，旧配置保留或明确报告恢复失败 |
| AD05-T5 | 内外网观测结果不同 | 显示观察位置和时间，不把局部可达当全网可达 |
| AD05-T6 | User Mode 或缺少管理权限 | 不提交宿主修改，提供可行连接方式说明 |

证据写入 [Mobile Progress](./RelaxKonOS.Mobile.Progress.md)，涉及真实域名的日志须移除凭据和无关账户信息。

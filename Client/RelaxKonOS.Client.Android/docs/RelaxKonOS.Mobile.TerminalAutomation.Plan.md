# AD07：Android 终端、脚本与进程守护计划

> 状态：M1–M4 已编码并通过 Android JVM 验证，待真机和真实 SSH、PTY、Linux/Windows Agent 及权限矩阵验收。优先级：P2。
> 总入口：[无电脑部署路线图](./RelaxKonOS.Mobile.Deployment.Roadmap.md)。

## 1. 目标与能力分层

手机可以排查模板和向导无法覆盖的问题，运行远端脚本，并将持续任务交由远端守护。已有 Android 进程列表与结束进程功能，不等于终端或守护工作负载管理已经实现。

| 能力 | 用途与入口 |
| --- | --- |
| Server 终端 | 既有“终端”顶级目的地；通过当前终端契约建立/附加 PTY 会话 |
| 安装前 SSH 终端 | 服务器中心的高级排障入口，复用宿主信任与独立 SSH 凭据 |
| 一次性脚本任务 | 明确工作目录、参数、环境、超时和执行身份的远端任务 |
| 受守护工作负载 | “管理 → 进程守护”，管理启动、重启策略、健康和日志 |

服务端终端与 SSH 终端清楚显示宿主和身份，不共用错误的凭据域；一次性任务与持续守护也不能只用同一个“执行命令”按钮表达。

## 2. 复用基础与缺口

复用 [终端协议与行为](../../../docs/applications/RelaxKonOS.Terminal.md)、[进程守护设计](../../../docs/applications/RelaxKonOS.ProcessGuardian.md) 和服务端相关 Hub/Endpoints。

Android 已接入 Java SignalR 客户端和有界 VT 文本屏幕，支持基本光标控制、UTF-8 跨帧输入、扩展键、字号与尺寸同步；完整 VT 程序、中文 IME、软键盘和旋转仍须真机 PoC 后才能承诺桌面同等级交互。服务端原先没有一次性脚本任务契约，现由 Guardian Agent 执行并持久保存结果；Agent 不可用时任务不会降级到手机或 Server 进程执行。

Server 终端将固定行列的活动屏幕与滚动历史分开维护：绝对光标地址始终相对活动屏幕；支持显示区清除 `J` 的 0/1/2/3 模式、行清除、光标保存/恢复、垂直定位、滚动区域、正反向滚动和行/字符插入删除。清屏不隐式移动光标；LF 保留列位置，CR 回到行首；右边界等下一可打印字符再换行。键盘、字号或旋转触发 resize 时合并连续布局变化，等待至少 200ms 的稳定期，只同步最终行列数；等待期间按原先同步的尺寸解析输出，避免旧尺寸重绘被误认为新尺寸屏幕滚动。尺寸调用与输入/会话操作串行，返回原尺寸时不调用 resize，断连/会话切换取消待处理的旧请求；附加期间的尺寸变化在附加完成后合并同步。实际应用新尺寸时先裁掉未使用的底部行，只把为保留光标而移出的顶部行加入历史，按新列数裁剪活动屏幕并发布更新后的文本。光标定位和空白画面重绘不生成尾部空白输出行。此模型仍为文本呈现，复杂全屏程序、颜色及 CJK 单元格宽度尚未达到完整终端模拟器能力。

## 3. 手机交互

终端提供 Ctrl、Alt、Tab、Esc、方向键、会话条、复制粘贴、字体调整和尺寸同步。会话条是**单行横向滚动**的胶囊（当天只显示本地时间、跨天补日期，后缀短会话 ID），当前会话用配色加文字双重标示；每个胶囊自带关闭，另有一个「关闭其它会话」批量清理后台 PTY。会话条不随会话数增高，终端始终占有剩余全屏。多行粘贴先展示内容与目标，避免输入与立即执行混淆。旋转、键盘显隐或字体改变后同步 PTY 尺寸。

Server 终端页不显示重复的大标题，身份和长地址单行省略；字号减小/增大按钮放在「新建会话」同行右侧，字号跨旋转保留。「关闭其它会话」进入会话操作菜单；逐个或批量关闭前展示具体目标确认。关闭当前会话后自动附加剩余的第一个存活会话。首次进入拉取列表后自动附加第一个存活会话；列表为空时给出选择/新建提示，只有明确点击新建才启动 shell。会话创建与切换串行执行，期间禁用输入和会话操作，避免重复创建与跨会话写入；进程退出只禁用该会话输入，不把仍正常的 Hub 标成断连。

Server 终端通过 IME 边距避开软键盘，尊重外层 Shell 已消耗的边距，避免平板重复留空。手机终端输入时隐藏底部导航，键盘收起后恢复。输入区在剩余内容之前测量，保留至少 56dp 的自然高度；身份、操作和会话管理归入可压缩的主体，不能把输入文字和光标挤没。软键盘展开或可用高度不足 `400dp × 系统字体缩放` 时，上方改为单行用户/当前会话摘要，收起管理控件，输入只显示一行且保留完整草稿；不足 `200dp × 系统字体缩放` 时暂时收起扩展键。键盘收起、空间恢复后自动还原完整控件。软键盘只改变布局和 PTY 尺寸，不触发发送，也不清空草稿。

建立连接前，access token 剩余有效期不足 30 秒时先刷新；协商明确返回 401 时沿用一次刷新、一次重试规则，REST 与 Hub 并发过期共用一次刷新，明确拒绝刷新才清登录状态。传输掉线自动恢复，连续连接失败按 1/2/5 秒间隔重试，耗尽后保留手动重连；403 或刷新后的 401 直接报错。恢复保留原选中会话，找不到时提示会话丢失，不附加另一个 shell，不重发命令。进入后台或离页只 detach，回到前台重新附加；过时连接的输出/退出回调不修改新连接状态。输出阅读支持复制和水平滚动，查看历史时暂停自动追随，并提供「最新输出」返回底部。PTY 尺寸计算扣除内边距并计入系统字体缩放，文本行高与行数估算一致。

切换页面默认 detach，不关闭远端会话；关闭会话和发送中断分别表达。重新连接先查询并调用 `AttachExisting` 附加已有会话；该调用找不到会话时只报错，不会创建新 shell。关闭任一会话走服务端的 `CloseSession(sessionId)`（服务端校验会话归属当前用户），因此非当前会话也能直接关掉，不必先附加再关闭。

脚本表单采用“脚本/程序路径 + 参数数组 + 工作目录 + 环境变量 + 超时”，显示实际执行身份和权限范围。远端必须检验输入，不把拼接 shell 字符串当结构化参数实现。用户明确选择的交互式终端仍按远端 shell 语义工作。

守护详情显示期望状态、真实进程状态、最近退出原因、重启次数和日志。创建表单提供重启策略与健康检查，并说明当前宿主模式支持的生命周期。

## 4. 权限与持续性

- User Mode 仅操作当前账号允许的文件和进程，不因有 SSH 或终端就获得宿主管理员权限。
- System Mode 的受控操作沿用当前授权与 run-as 检查，不能缓存管理员授权作为长期通行证。
- 远端会话存活、工作负载存活和宿主重启后恢复是不同保证。界面依据真实宿主能力说明，不承诺所有环境永久常驻。
- SSH 连接断开可能影响交互式 shell 中的进程；需要持续运行的任务必须明确转为受管远端任务，不能宣称所有 SSH 命令都可断线续跑。
- 日志有界；脚本输出可能包含用户敏感内容，导出前给出目标和内容范围，凭据不进入命令历史模板或恢复记录。

## 5. 实施阶段

| ID | 工作 | 完成条件 |
| --- | --- | --- |
| AD07-M1 | 终端渲染/IME PoC、当前 Hub 契约接入 | 手机输入、中文组合、扩展键与输出渲染可用 |
| AD07-M2 | 会话创建/附加/分离、尺寸同步、断线处理 | 页面切换不杀会话，重连不重跑命令 |
| AD07-M3 | 远端脚本任务与守护列表/详情/配置 | 任务有持久结果，守护由远端执行 |
| AD07-M4 | 服务器中心 SSH 排障、关联跳转与完整设备矩阵 | 未安装或 Server 故障时可在正确身份下诊断 |

AD01 首次安装不能依赖用户手动敲终端命令，AD07 是高级能力和排障补充。

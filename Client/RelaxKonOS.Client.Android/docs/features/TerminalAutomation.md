# Android 终端、脚本与进程守护

脚本任务列表使用可点击卡片，集中显示可执行文件、创建时间和任务状态；选中任务的取消、退出结果与输出置于独立详情卡片。

> 当前功能说明，对应 AD07；实现与验证见 [当前状态](../status/Progress.md)。BP13 当前终端行为见下文，BP14 当前守护行为见 [进程守护](Guardian.md)；验证范围和未关闭检查单独维护。

## 1. 目标与能力分层

手机可以排查模板和向导无法覆盖的问题，运行远端脚本，并将持续任务交由远端守护。终端、一次性脚本和持续守护使用独立任务与生命周期。

| 能力 | 用途与入口 |
| --- | --- |
| Server 终端 | 既有“终端”顶级目的地；通过当前终端契约建立/附加 PTY 会话 |
| 安装前 SSH 终端 | 服务器中心的高级排障入口，复用宿主信任与独立 SSH 凭据 |
| 一次性脚本任务 | 明确工作目录、参数、环境、超时和执行身份的远端任务 |
| 受守护工作负载 | “管理 → 进程守护”，管理启动、重启策略、健康和日志 |

服务端终端与 SSH 终端清楚显示宿主和身份，不共用错误的凭据域；一次性任务与持续守护也不能只用同一个“执行命令”按钮表达。

## 2. 协议与执行边界

复用 [终端协议与行为](../../../../docs/applications/RelaxKonOS.Terminal.md)、[进程守护设计](../../../../docs/applications/RelaxKonOS.ProcessGuardian.md) 和服务端相关 Hub/Endpoints。

Android 已接入 Java SignalR 客户端和有界 VT 字符单元屏幕，支持 UTF-8 跨帧输入、光标/颜色/备用屏幕、扩展键、工作区外观设置与尺寸同步；完整 VT 程序、中文 IME、软键盘和旋转设备检查统一见 [验收清单](../status/Verification.md)。服务端原先没有一次性脚本任务契约，现由 Guardian Agent 执行并持久保存结果；Agent 不可用时任务不会降级到手机或 Server 进程执行。

进入 Server 终端时身份、会话、工具、扩展键和输入区立即显示，仅输出视口先绘制加载提示，再初始化渲染器与历史文本；平板会话侧栏不参与等待。输出视口及 WebView 容器裁剪子组件绘制，避免越过视口覆盖页面组件。离页会取消尚未执行的渲染初始化。SignalR 客户端与 TLS 构造在 IO 调度器执行，连接、重试和附加会话期间仅输出视口显示等待状态，失败后恢复重试入口。连接等待期间不重建旧历史，xterm.js 模式不生成未使用的原生字形布局；WebView 在打包页面加载完成且 Chromium 首帧可绘制后才撤下加载提示。加载状态不覆盖 Shell 导航、不发送命令，也不改变 PTY 生命周期；操作是否可用仍由连接及会话状态决定。

Server 终端将固定行列的活动屏幕与滚动历史分开维护：绝对光标地址始终相对活动屏幕；支持显示区清除 `J` 的 0/1/2/3 模式、行清除、光标保存/恢复、垂直定位、滚动区域、正反向滚动和行/字符插入删除。清屏不隐式移动光标；LF 保留列位置，CR 回到行首；右边界等下一可打印字符再换行。键盘、字号或旋转触发 resize 时合并连续布局变化，等待至少 200ms 的稳定期，只同步最终行列数；等待期间按原先同步的尺寸解析输出，避免旧尺寸重绘被误认为新尺寸屏幕滚动。尺寸调用与输入/会话操作串行，返回原尺寸时不调用 resize，断连/会话切换取消待处理的旧请求；附加期间的尺寸变化在附加完成后合并同步。实际应用新尺寸时先裁掉未使用的底部行，只把为保留光标而移出的顶部行加入历史，按新列数裁剪活动屏幕并发布更新后的文本。光标定位和空白画面重绘不生成尾部空白输出行。输出由字符单元、样式区间与光标位置组成，复制输出使用保留的纯文本。SGR 支持基本/亮色、256 色、RGB（分号与冒号格式）、粗体/弱化/斜体/下划线/删除线、反色和隐藏及各自重置；带背景的擦除保持单元格背景。支持可见光标、DEC 线框字符、原点模式、插入模式、应用方向键、括号粘贴及主/备用屏幕切换；备用屏幕滚动不进入主屏历史，返回后恢复主屏光标与属性。状态/光标/主设备属性查询只生成有界终端响应，不把未知 OSC/DCS 内容显示或写入本机剪贴板。

CJK/全角与常见 emoji 占两个字符单元；组合标记/选择符不单独推进列，ZWJ emoji 和区域旗帜保持同一字形。覆盖、擦除、字符增删和缩小列数同时处理宽字符后半格，避免遗留半个字。渲染将宽字形与组合字形放入固定宽度的 inline 占位区，宽度来自当前等宽字体真实 Latin 单元测量，保留小数字符推进量，避免整数舍入累积与 Android 后备 CJK 字体推进量不同而错位；替代文本保持原 Unicode 内容供父文本选择、复制和搜索。光标按字形单元边界绘制。单个组合字形最多 64 个 UTF-16 单位，活动屏幕最多 300×100、历史最多 800 行，发布文本最多 80,000 个 UTF-16 单位，设备查询每输出批次最多 16 个响应。

这是有明确支持范围的 VT 屏幕，不承诺全部终端扩展：没有六像素/内联图像、OSC 剪贴板写入、任意动态调色板或所有 Unicode 宽度扩展；真实 shell/全屏程序和设备字体的效果见独立验收记录。

## 3. 手机交互

SSH xterm.js 区域支持单指上下拖动与松手后的惯性滚动，拖动按实际字符行高累计小距离移动；父容器不抢占终端手势。查看历史时保持当前位置，新输出不强制跳回底部；右下方显示带三语无障碍标签的「回到最新输出」按钮，点击后回到提示符。轻触与长按不作为滑动，单指拖动不触发终端输入。

SSH 工作区新增「设置」，可调整主题、语言、高对比度及终端类型，与 Server 外观设置共用持久配置。终端仅保留两种：原生终端（原 Server 的 Compose 可选中文本屏幕）与 xterm.js；默认 xterm.js。选择同时作用于 SSH 与 Server，切换渲染器不会新建或关闭 PTY，不重放用户命令。SSH 会话持续维护原始 VT 与原生屏幕；Server 将跨帧 UTF-8 解码后的 VT 与原生屏幕一起发布，附加其它会话时同步清空两种输出。

xterm.js 模式使用 APK 内置 xterm.js 6.0.0 / addon-fit 0.11.0，通过本地 WebView 呈现，不访问 CDN。SSH PTY 类型为 `xterm-256color`，原始 VT 支持颜色、光标定位、清屏和重绘。addon-fit 测量字符尺寸，布局稳定 200ms 后同步实际行列数；输入经 Compose 编辑区和扩展键发送，自动终端查询响应回传当前会话。WebView 仅允许打包资源，禁止导航和远端网络加载。原始输出只保存在进程内存，用于渲染器重建时恢复屏幕，不写日志或磁盘；SSH 和 Server 原始输出累计量未设上限，长时间高输出的内存与重放开销仍需优化。原生模式采用有界 VT 字符单元屏幕，支持复制、水平滚动、暂停追随及返回最新输出。Server 原生模式保留颜色、CJK 字形、查找和工作区外观；xterm.js 模式的查询由 WebView 应答，控制器不重复发送原生解析器的回复。

SSH 工作区遵循 Server Shell 的窗口断点：小于 600dp 使用四项工作区底部导航，终端键盘展开时隐藏底栏；600–839dp 使用带无障碍名称的紧凑侧栏，840dp 起显示侧栏文字。平板键盘展开时保留侧栏，内容独立分配剩余宽度，外层统一消费安全区，终端按剩余视口调整 PTY。主导航为文件、终端、部署、管理；管理内通过顶部标签切换系统、设置与本地转发，默认显示系统。返回键先回管理的系统子页，再退出工作区；系统页仍为工作区唯一主机切换入口。

终端提供 Ctrl、Alt、Tab、Esc、方向键、Home/End、翻页/插入/删除/退格、F1–F12、会话列表、搜索/复制/确认式粘贴、字体调整和尺寸同步。可用宽度至少 840dp 且剩余高度至少 `200dp × 系统字体缩放` 时采用 240dp 会话侧栏与当前终端双栏；终端和输入占剩余宽度。条件不满足时回到单会话主体与横向会话条，IME/大字体不会强制保留侧栏。会话条是**单行横向滚动**的胶囊（当天只显示本地时间、跨天补日期，后缀短会话 ID），当前会话用配色加文字双重标示；每个胶囊自带关闭，另有一个「关闭其它会话」批量清理后台 PTY。会话条不随会话数增高，终端始终占有剩余全屏。剪贴板粘贴总是先显示原目标会话 ID、内容预览与实际字符数，再显式发送；多行或含 CR/ESC/NUL 的输入草稿也先确认。确认目标是当时的具体会话，切换会话即撤销未确认粘贴；剪贴板粘贴不会清掉原未发送草稿。在远端启用括号粘贴时，剪贴板内容使用当前 VT 开始/结束标记，草稿“发送命令”仍沿用用户明确选择的输入语义。草稿最多 16,384 个 UTF-16 单位，不截断代理对，只在内存中按最多 32 个会话保留；旋转/IME 变化复用 ViewModel，注销或换登录身份全部清空，不写磁盘、不在恢复时发送。旋转、键盘显隐或字体改变后同步 PTY 尺寸。

Server 终端页不显示重复的大标题，身份和长地址单行省略；字号减小/增大按钮放在「新建会话」同行右侧，字号跨旋转保留。「关闭其它会话」进入会话操作菜单；逐个或批量关闭前展示具体目标确认；批量关闭只消费确认时捕获的 ID 清单，后来出现的会话不会被追加为关闭目标。关闭当前会话后自动附加剩余的第一个存活会话。首次进入拉取列表后自动附加第一个存活会话；列表为空时给出选择/新建提示，只有明确点击新建才启动 shell。会话创建与切换串行执行，期间禁用输入和会话操作，避免重复创建与跨会话写入；进程退出只禁用该会话输入，不把仍正常的 Hub 标成断连。

Server 与 SSH 终端共用 IME 自适应布局，通过 IME 边距避开软键盘，尊重外层 Shell 已消耗的边距，避免平板重复留空。终端输入时隐藏底部导航，键盘收起后恢复。输入区在剩余内容之前测量，保留至少 56dp 的自然高度；身份、操作和会话管理归入可压缩的主体，不能把输入文字和光标挤没。软键盘展开或可用高度不足 `400dp × 系统字体缩放` 时，上方改为单行身份摘要，收起管理控件，输入只显示一行且保留完整草稿；SSH 同时保留返回入口并收起隐藏输入开关，已经选择的隐藏状态不变。不足 `200dp × 系统字体缩放` 时暂时收起扩展键。键盘收起、空间恢复后自动还原完整控件。软键盘只改变布局和 PTY 尺寸，不触发发送，也不清空草稿。

SSH PTY 的尺寸请求与输入写入共用互斥锁，均在 IO 线程执行；JSch 的 `setPtySize` 会同步发送网络数据，不允许在 Compose 主线程调用。尺寸计算扣除输出区内边距并计入系统字体缩放。

SSH 终端由应用容器统一持有，生命周期覆盖应用进程。切换到部署/文件/系统/设置、返回服务器中心、切换宿主及旋转不会关闭或重建 shell；后台输出继续读入原始 VT 缓冲与有界原生屏幕。每个会话拥有独立 SSH 传输、PTY、输出、草稿、隐藏输入状态和字号，同一宿主可新建多个终端，不同宿主的连接可以同时保留。每个宿主分别记住选中会话；顶部单行会话条或键盘展开时的会话菜单提供切换、新建与结束操作。明确结束须确认，关闭一个连接不影响其它连接；断网/远端退出只更新对应会话，不自动重放输入。SSH 每 30 秒发送保活请求，连续 3 次未响应后允许传输报告失败；保活不保证进程被系统回收后继续连接。

SSH 会话列表、选中状态、草稿、命令和输出只保留在进程内存，不持久保存；最多同时保留 100 个会话。应用进程重启或被系统回收后，从空会话列表开始，不展示旧连接、不恢复原 shell、不重放命令；重新进入宿主终端按正常连接流程打开新 shell。进程仍存活时的页面切换继续沿用原连接，只有明确结束、远端退出或传输失败才结束对应 shell。网络断线后的手动重连仍遵守宿主密钥固定与已核验凭据规则，但会启动新 shell。SSH 进程断线后的远端任务持续性需另用远端任务/会话管理。宿主资料和用户明确保存的 SSH 凭据继续由各自的存储管理，应用重启清空会话不会删除它们。

建立连接前，access token 剩余有效期不足 30 秒时先刷新；协商明确返回 401 时沿用一次刷新、一次重试规则，REST 与 Hub 并发过期共用一次刷新，明确拒绝刷新才清登录状态。传输掉线自动恢复，连续连接失败按 1/2/5 秒间隔重试，耗尽后保留手动重连；403 或刷新后的 401 直接报错。恢复保留原选中会话，找不到时提示会话丢失，不附加另一个 shell，不重发命令。进入后台或离页只 detach，回到前台重新附加；过时连接的输出/退出回调不修改新连接状态。输出阅读支持复制和水平滚动，查看历史时暂停自动追随，并提供「最新输出」返回底部。PTY 尺寸计算扣除内边距并计入系统字体缩放，文本行高与行数估算一致。

输出工具支持本地字面查找（忽略大小写、最多 5,000 个匹配）、前后跳转和高亮，跳转同步横纵滚动；查找历史会暂停自动跟随，不发送 shell 命令。系统选区支持复制；“复制输出”复制当前保留纯文本；“清除本地显示”清除本机屏幕与滚动历史，保留协议光标，不发送 `clear` 或重连。Ctrl+Shift+F/C/V 分别打开查找、复制输出、打开粘贴确认；输入框为空时物理键盘发送 VT 扩展键，草稿存在时保留 Android 编辑行为。方向/Home/End 和 F1–F12 采用当前应用方向键模式与 xterm Shift/Alt/Ctrl 参数；软扩展键的 Ctrl/Alt 为一次性修饰，已接受的发送后复位。

外观设置直接使用当前 `/api/v1.0/workspaces/{id}/terminal-settings` GET/PUT，登录 `workspace.id` 是必需的当前字段。六个字段为 fontFamily、fontSize（有限 8–40，保留小数）、colorScheme、backgroundColor、foregroundColor、cursorColor；四个预设与桌面一致，三个 RGB 颜色可分别编辑。Android 没有安装桌面指定字体时使用系统等宽字体，但保存/读取保留原字体名，供桌面使用。A−/A+ 是本页调整；设置保存后按已核实的工作区值显示。读取不可用时默认外观仍可使用，未核实当前值时禁用保存。保存前重新读取（401 刷新后的发送也重新读取），若已变更则拒绝覆盖；成功回执还要回读一致才报告已保存。当前 Server 契约没有原子 CAS，预读不能保证并发最后写入竞争完全消失；无响应或回执不一致只显示未核实，要求刷新，不自动重发。请求和迟到回执绑定当前登录对象，不污染另一身份。

切换页面默认 detach，不关闭远端会话；关闭会话和发送中断分别表达。重新连接先查询并调用 `AttachExisting` 附加已有会话；该调用找不到会话时只报错，不会创建新 shell。关闭任一会话走服务端的 `CloseSession(sessionId)`（服务端校验会话归属当前用户），因此非当前会话也能直接关掉，不必先附加再关闭。

脚本表单采用“脚本/程序路径 + 参数数组 + 工作目录 + 环境变量 + 超时”，显示实际执行身份和权限范围。远端必须检验输入，不把拼接 shell 字符串当结构化参数实现。用户明确选择的交互式终端仍按远端 shell 语义工作。

守护的完整参数/健康/停止策略编辑、身份审批、保存回执/读回、状态观察和有界 SignalR 日志见 [进程守护](Guardian.md)。

## 4. 权限与持续性

- User Mode 仅操作当前账号允许的文件和进程，不因有 SSH 或终端就获得宿主管理员权限。
- System Mode 的受控操作沿用当前授权与 run-as 检查，不能缓存管理员授权作为长期通行证。
- 远端会话存活、工作负载存活和宿主重启后恢复是不同保证。界面依据真实宿主能力说明，不承诺所有环境永久常驻。
- SSH 连接断开可能影响交互式 shell 中的进程；需要持续运行的任务必须明确转为受管远端任务，不能宣称所有 SSH 命令都可断线续跑。
- 日志有界；脚本输出可能包含用户敏感内容，导出前给出目标和内容范围，凭据不进入命令历史模板或恢复记录。

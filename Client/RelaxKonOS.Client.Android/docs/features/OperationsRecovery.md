# Android 任务、告警与恢复


## 1. 任务索引与权威状态

“管理 → 任务与恢复”扫描应用部署、网站发布、Compose、Git 构建、Guardian 脚本、备份、Nginx Web 操作、证书生命周期、Mihomo 和统一运行时安装记录，按原领域/操作 ID 查询。安装前回执在 SSH 工作区查询，不伪造 API 登录。

本机 `noBackupFilesDir` 索引只保留稳定服务器/账号、领域、资源 ID、操作 ID 和观察时间；安装记录按 SSH 目标、用户与固定主机密钥隔离。不保存凭据、请求体、日志或远端状态；历史扫描补录响应丢失/进程回收遗漏的 ID，切会话清理旧显示结果。

| 观测情况 | 展示与行为 |
| --- | --- |
| 远端运行/完成 | 使用领域阶段与权威结果 |
| 传输失联 | 结果待核实，重连查询原记录 |
| 404/记录过期 | 原记录缺失，不当作成功或自动重提 |
| 远端中断 | 展示实际状态和领域允许的动作 |

取消只提交请求并查询终态，应用部署/Compose/运行时安装重复取消使用稳定幂等键。“在本机隐藏”保留墓碑避免再次扫描出现，不删远端资源。Nginx Web 操作按已知 ID 恢复，支持取消和返回网站页；首次响应完全丢失时没有集合/按请求键恢复接口，保留待核实，详见 [Nginx 管理](Nginx.md)。证书任务同样按原 ID 观察、取消与返回独立证书页；完全丢失响应的请求摘要另列待核实，恢复限制见 [证书管理](Certificates.md)。领域深链按原 ID 查询，不要求任务仍在近期列表。

通用站点保存/删除是同步 API，没有操作 ID。运维中心另列账号隔离的待核实站点提交，并返回网站页读取当前事实。其本机标记只保存目标、动作、版本和请求摘要；不伪造任务或把站点当前存在解释为原请求成功。确认采用新读取的事实只清除本机标记，详见 [站点管理](WebSites.md)。

FRP 的 profile/隧道/Token/删除/应用/停止，以及宿主 frps 保存/启停/重启同样没有领域 operation ID。运维中心按身份另列待核实动作并返回隧道页；标记不保存 Token、正文或秘密摘要，读取对应领域当前事实后须明确确认才清除，见 [FRP 客户端与运行时](Tunnels.md)。

公共运行时安装任务使用登录后的 Installations API，与 SSH 工作区的首次安装回执分别观察。安装支持活动发现、按原 ID 恢复、阶段进度、确认取消和离页停止观察；完全丢失响应的提交保留待核实提示。当前来源、提权、幂等与契约限制见 [公共运行时安装](Installations.md)。

Mihomo 按原 ID 查询并核对任务 kind 与索引归属，显示本地化状态、阶段和问题类别；当前 Proxy API 没有取消端点，不显示取消按钮。同步写入与完全丢失响应的队列请求保留独立待核实标记，并返回代理页核实/按原键显式恢复。Nginx 完全丢失响应的提交同样独立展示并返回网站页。详细边界见 [Mihomo 管理器](Proxy.md) 和 [Nginx 管理](Nginx.md)。

BP17-M1 补齐第一批入口：已实现的 Nginx、FRP、Mihomo、SMB、Docker、Git 安装记录和未知提交可返回对应管理页；其他服务表单随后续领域交付。任务目标与告警修复入口按当前 capability 门控，缺少能力不显示按钮。备份跳转要求部署能力；告警只接受共享枚举的固定部署、证书、Guardian、Docker、FRP 目标，不执行服务端 URI/命令。详情及确认响应核对原告警 ID。切标签/离页停止告警观察并清除旧显示，任务离页停止轮询；再次进入查询持久原 ID，不重发副作用。

BP07-M1 的同步防火墙变更另列待核实项，按当前能力返回 [宿主防火墙](Firewall.md)。该契约没有任务 ID/取消/重放键，运维中心不伪造领域任务；采用当前事实只能结束本机标记。

## 2. 安装回执与诊断

SSH 查询要求显式选择 Linux/Windows 并重新验证会话，只暂存 APK 固定启动器，读取持久操作 ID/回执，不调用 `--run`；输出上限 1 MiB，超限不解析。记录缺失与连接/解析失败分别显示。

JSON 诊断报告注明核验时间、有界截断和未取得信息，可通过系统文件选择器保存。报告不含账号、凭据或请求正文；脚本输出可能含用户秘密，导出前提醒，不自动上传。临时 `RecentOperationJournal` 不替代持久恢复索引或审计。

## 3. 告警与前台通知

`server.event-alerts` 存在时，在“任务与恢复 → 告警”提供告警和事件时间线。汇总读取未处理、已确认、未确认严重告警数量及服务端更新时间；列表显示最后实际核对时间，读取失败保留已读取列表并明确报错。告警支持状态/等级筛选，事件支持等级/来源/精确类型筛选；每次 50 条、合并最多 500 条、按 ID 去重。筛选变化丢弃旧游标，分页失败保留原页与重试游标，重复游标停止继续读取。首批页面每 15 秒观察；载入后续页面后停止自动替换列表，由用户明确刷新回首批。切标签、离页或进入后台立即停止读取并清除旧显示，换登录不接收原会话迟到结果。

详情读取完整告警首次/最近时间、次数、最近事件、确认时间/安全操作人引用、解决原因，以及服务端返回的关联事件和动作历史。事件保留等级、来源、结果、问题码、资源安全引用、关联 ID、操作 ID 和已脱敏证据；只展示服务端提供的有界历史，不声称覆盖全部保留事件。修复入口沿用 capability 门控的固定原生目标；未知或未接入目标不显示按钮，不执行 URI 或命令。

已读取详情可以明确确认告警、按当前目录允许的来源手工解决、以原因抑制 10/30/60 分钟或解除抑制。确认对话框显示当前状态与次数，原因/备注上限 512 字符；手工解决和抑制必须有原因，严重告警抑制仍由服务端额外权限决定。提交前和认证重试时重新读取并核对整个告警基线，成功回执核对原 ID/类型/预期状态，再完整读回核实。该同步契约没有版本 CAS、幂等键或取消接口，客户端前置复核不能排除服务端执行前的外部竞争；最终状态转换由服务端原子检查。

回执丢失、服务端 5xx、提交后取消或回读不一致不自动重发。本会话阻止同一告警继续写入；明确读取核实，只有当前状态为原动作预期状态才解除该门禁，状态仍未出现时保持待核实。普通轮询不解除门禁。此门禁只存在当前登录内，不宣称 Android 进程回收后的持久恢复，也不把读取到预期状态当作原请求的审计证明。告警动作仅修改状态，不修复底层故障。

通知策略按服务器/事件类别保存，默认关闭，仅 App 前台轮询当前账号首批告警。首轮建立静默基线，重复次数不重发，恢复/确认/抑制撤销通知，严重性升级/新告警受 15 分钟冷却和每次最多三条限制。

通知只含固定通用文案，不带地址、账号、问题码或日志。拒绝权限不影响应用内查询；当前没有 App 结束后的可靠推送。共享事件语义见 [事件告警](../../../../docs/applications/RelaxKonOS.EventAlertCenter.md)。

## 4. 定义备份与只读预检

`server.backup-recovery` 门控下，应用详情可创建定义备份、读取加密清单并预检。创建请求只在本机保留账号/服务器范围幂等键；HTTP 结果未知时先查询同一请求，用户选择重试才复用该键，不产生第二个创建副作用。

Android 不保存恢复密钥、明文或备份对象。服务端加密、校验、配额、每应用保留和启动残留清理由 [共享备份契约](../../../../docs/applications/RelaxKonOS.BackupRecovery.Contract.md) 拥有。服务端的无卷/无秘密定义可恢复为新停机实例，但 Android 尚无恢复提交界面；卷/数据库一致性适配器和跨安装秘密重绑定也未交付。

预检失败直接显示阻止条件，不提供降级恢复。定义备份验证成功不等于业务数据可恢复，版本回滚不撤销数据迁移。未关闭恢复、通知和系统选择器检查见 [验证要求](../development/Verification.md)。

BP08-M1 同步聚合 SMB 未知写入标记及公共安装原记录，返回 [SMB 文件服务](Smb.md) 核实。同步 SMB 回执 ID 只关联审计，没有任务查询/取消/重放 API；不加入领域任务索引，也不自动重放。已知安装 ID 可优先恢复；入口和记录按当前 capability、宿主/账户门控。

BP09-M1 同步聚合引擎/镜像源未知写入与 Docker 公共安装记录，返回 [引擎与镜像源](DockerEngine.md) 核实；同步写入不伪造任务/取消/幂等键，安装继续使用原 ID/键。入口按当前 capability 和宿主/账户隔离。

BP09-M2 聚合独立 Docker 资源的无正文未知标记，按 capability 和 serviceId/账户返回 [Docker 资源](DockerResources.md) 核对并明确采纳当前事实；没有伪造任务 ID/取消/重放入口。

BP10 聚合 Git 同步未知操作标记，按 capability 和 serviceId/账户返回 [Git 工作区](Git.md) 读取并明确采纳当前事实；标记没有服务器任务 ID、取消或重放接口。Git 公共安装仍按原 ID/请求键恢复。

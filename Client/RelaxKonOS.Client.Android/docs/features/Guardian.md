# Android 进程守护

## 配置与身份

Guardian IPC 权限拒绝与服务不可用分别提示。权限拒绝引导用户修复服务器安装并刷新；不要求在 Android 输入服务组、套接字路径或修改宿主权限。脚本页保留服务器返回的问题码，刷新成功后清除旧错误。Linux 服务账户与 IPC 权限的共享规则见上方进程守护设计链接。

手机提供名称、可执行路径、逐项参数、工作目录、RunAs、开机启用、停止超时、重启上限和完整健康检查。每个参数是一个独立值，保留空值、空格和内部换行；可增删与编辑，不以逐行拆分重建整个数组。当前编辑界限为 128 个参数、单项 16,384 UTF-16 单元、合计 262,144 单元，不接受 NUL。

停止超时为 1–300 秒，重启上限为 0–100。健康检查可关闭，或选择进程、HTTP/HTTPS、TCP；检查间隔 1–3600 秒、超时 1–60 秒、失败阈值 1–100。进程检查不需要目标，HTTP/TCP 需要相应绝对地址，TCP 必须有有效端口，URL 不接受 user-info。原有非默认数值及健康类型大小写均保留。

编辑状态由 ViewModel 在内存中保存，旋转不重建参数数组；离开未保存配置需要确认。进程回收或退出登录清除本地草稿。手机显示已保存的稳定宿主身份，不能自行生成 UID/SID。Windows 账户比较忽略大小写，Linux 保留大小写；改为其他登录账户需本次管理员审批，不按平台猜测管理员账户。Server 复用统一管理员认证器和资格检查。审批针对已捕获的完整定义，不记住密码，不写入草稿或本地持久记录；发送、拒绝或取消后清除密码字符数组，退出表单清除密码输入。

桌面编辑也以原完整定义为基础保存：保留未暴露的停止超时、重启策略、健康检查和稳定身份；未修改参数文本时保留原数组，修改文本时保留空行及空格。改变账户时不复用原稳定身份。Server 始终重新授权 RunAs，Agent 验证实际身份和路径。

## 保存与未知结果

保存前按原 ID 读取定义：新建要求 ID 不存在，编辑要求完整定义仍与打开表单时一致；认证刷新后的重试也重新核对。冲突只提示读取当前配置，读取替换未保存草稿时需确认。当前契约没有原子 CAS，这一预检不能消除读取与提交之间的全部并发窗口。

成功保存回执携带 Agent 此次实际保存的完整定义，包含 Server 绑定的规范账户名/身份，以及 Agent 规范化的绝对可执行路径。手机再读取同一 ID，逐字段与本次回执比较后才关闭表单。缺少定义、不可读或读回不同均视为结果未知，不自动重发。未知状态暂停后续修改；用户可明确读取远端配置或刷新状态核实。

主页面和编辑器在普通错误与结果未知同时存在时优先显示结果未知及读取核实提示，避免用户把没有回执的操作理解为确定失败。

守护读取和写入的意外异常转换为不含异常原文的传输失败；读取保留草稿，写入进入结果待核实状态并禁止重放。取消仍传播，身份归属在异常转换后也重新核对；审批密码无论成功、失败或取消均清理。

启动、停止、重启和删除确认显示原工作负载名称与 ID，发送时使用这一 ID。登录切换取消旧请求，旧归属和迟到返回不能修改新账户界面。读取和修改分别串行，网络失败不会重放工作负载动作。

## 脚本任务读取

任务详情只接受与当前选择 ID 相符的成功回执。切换任务取消原读取并使旧响应失效；读取失败保留同一任务已有详情和错误提示，不用另一任务的回执替换。前台轮询间隔 2 秒，每次等读取完成后才开始下一次间隔，读取失败停止轮询，手动刷新或重新选择可恢复读取。任务进入终态后停止轮询。

提交及取消占用忙碌状态，取消后读取任务详情期间也禁止重复提交或取消。失败提交不自动刷新覆盖失败回执；提交/取消传输失败提示结果未知，先刷新任务列表并核对执行状态，再决定后续操作。登录归属变化清理选择和请求；旧任务响应不能回写新会话。审批字符数组在拒绝重复提交、发送结束和发送前取消时均清理。

脚本编辑器在提交时保持打开，忙碌期间锁定字段、路径浏览、运行和返回。成功回执的任务 ID 必须等于本次提交的 `Idempotency-Key` 才关闭编辑器；拒绝或传输失败保留本次输入并在表单内显示反馈，审批密码输入发送后清空。缺少或不匹配任务 ID 的成功回执按结果未知处理，禁止立即再次运行。用户可通过返回及明确放弃离开草稿，待核实请求仍保留，新建及取消均禁止；刷新空列表不代表确认原请求未执行。

手机在发送前记住待核实任务 ID 与提交/取消类型，不保留审批凭据。表单内“核实请求”和主页面刷新仅通过 `GET /guardian/scripts/{id}` 核实原 ID，不重发写请求。提交核实只接受成功且 ID 匹配的任务，随后显示任务并关闭原草稿；取消核实需读到取消中、已取消或其他终态，仍在排队/运行不解除限制。找不到、读取失败或 ID 不匹配保留原待核实请求。Server 的 5xx 与 Agent 超时/不可用回执也不能证明写入未发生。待核实记录目前仅在 ViewModel 内存中保持，进程回收后的请求 ID 恢复仍待完善。

脚本编辑器打开状态及可执行路径、参数、目录、环境文本、超时、运行身份和审批账号保存在 ViewModel 的内存草稿中，包含无效原始输入；配置变化后继续使用同一草稿，页面初始化不能重读任务清除草稿错误。存在草稿时暂停任务轮询及任务选择。成功回执直接关闭草稿，明确放弃清除草稿，登录归属变化清除草稿和请求；进程回收不恢复草稿。审批密码仅存在当前表单，配置变化不恢复密码，不保存到草稿或 SavedState。

## 状态、布局与日志

页面前台时每 3 秒串行读取 Agent 状态与工作负载，展示期望/实际状态、健康状态、PID、退出码、问题、重启及健康失败次数。启动/停止中、失败、退避、重启耗尽、健康异常分别显示当前事实；未知状态不推断为成功。读取失败保留已有详情并标明可能过期，暂停修改动作。进入后台、离页或编辑表单时停止观察；返回后恢复只读观察。

手机使用列表与详情切换，返回键可回列表。宽度至少 840 dp 且可用内容高度至少 240 dp 时，并排显示 280 dp 列表及详情；动作和健康选择可横向滚动，编辑正文可滚动，保存按钮位于 IME 上方。

日志使用桌面同一 `/hubs/guardian-logs` 的 `Subscribe` 与 `OnLogSnapshot` 契约，每份快照替换已有日志，重连不重复追加。订阅只属于当前登录与原 ID；切换、后台、离页和取消连接会关闭原连接。连接最多进行 4 次尝试，间隔 0/1/2/5 秒；401 只做一次认证刷新与重试，明确拒绝停止尝试。失败可手动刷新日志重新连接，不发送任何生命周期动作。

可选择复制日志文本；显示最近最多 200 条，消息合计最多 65,536 UTF-16 单元，单条最多 8192，截断不拆开代理对并显示范围提示。Server 的工作负载、日志和审计读取失败返回显式问题，不能返回成功空列表；Hub 初次读取失败不保留订阅，后续读取失败保留上一份快照，不发送伪造空快照。真实进程生命周期、跨账户审批、Hub 网络互通及设备视觉验证独立追踪。

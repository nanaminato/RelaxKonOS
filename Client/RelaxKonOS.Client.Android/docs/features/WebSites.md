# Android 通用站点管理


“管理 → 网站”的站点页直接使用实例页选中的 Nginx，读取实际站点列表并提供创建、编辑与删除。站点页不发现或选择实例，未选择时提示返回实例页选择。入口要求 `server.web-server`，写入另需当前会话允许宿主提权及目标实例配置写能力；证书清单由 `server.certificates` 门控。读取失败显示未取得，不能当作空列表。编辑器滚动并避让 IME。

## 编辑字段与确认

编辑器保留站点名、多域名/端口绑定、远端静态根目录、SPA fallback、反向代理路由、每路由缓冲开关、HTTPS、HTTP 跳转、IPv6、受管证书 ID 或宿主证书/私钥路径。远端路径用已有路径选择器；手机不读取或缓存宿主私钥。证书选择器保留明确 ID，显示状态、SAN、有效期与指纹；缺失、到期、尚未生效、撤销/不可用状态、域名不覆盖和清单未核实分别提示，保存前重新读取。SAN 覆盖全部绑定才可保存，通配符仅匹配一层 DNS 名称。宿主文件模式标识有效期/SAN 未核实。元数据匹配不证明实际 HTTPS 或客户端信任，独立生命周期与部署见 [证书管理](Certificates.md)。

静态目录可显式申请 Nginx 读取权限，确认说明宿主权限与配置影响。表单先校验必要内容、端口、路由和证书选项，再由 Server 权威校验域名、路由、文件与权限。Server 在版本检查后、配置/权限副作用之前校验证书状态、有效期与全部绑定的 SAN 覆盖；不可用和不覆盖返回稳定问题码，不清除原草稿。创建使用稳定站点 ID，保存前显示目标与影响，删除独立确认停用影响。关闭未保存草稿、以服务器最新定义替换草稿分别确认；草稿仅在内存，切换登录或注销清除。

## 并发修改与同步结果

站点 API 当前同步返回站点或删除结果，没有操作 ID，也不支持幂等键。Android 编辑与删除传原始 `updatedAt` 字符串作为 `expectedUpdatedAt`，保留服务端时间精度；创建传空版本。共享契约与补偿规则由 [Web Server 设计](../../../../docs/applications/RelaxKonOS.WebServerManager.Design.md) 维护。

服务器发现版本变化或站点已存在时拒绝覆盖。界面保留草稿并提供重新读取最新定义，替换草稿须确认，不自动改版本再次写入。配置校验/应用失败显示本地化问题，不能当作成功；没有操作 ID 就不显示长任务进度或取消按钮。

## 断线与事实核实

提交前将账号/宿主、目标站点、动作、原版本及请求 SHA-256 摘要原子写入 `web-site-mutations.bin`。写入失败停止提交；不持久保存完整表单、根目录、证书路径、私钥或授权回答。结果未知时锁定原草稿并保留标记，刷新、离页和重新打开不会自动重发。

用户可显式核实当前列表：分别显示未取得、站点不存在、定义与原草稿一致、定义已不同。定义一致不证明丢失的请求成功，也不证明额外读取权限已授予。只有原版本仍匹配时才允许显式重试原请求；新建后已存在、删除后不存在或版本变化均要求核实。

“采用当前事实”先重新读取成功，再清除本机待核实标记；它不改变远端站点，不宣称原请求成功。进程重启后完整草稿不恢复，可从网站页或运维中心查看标记、核实并确认当前事实。所有响应按当前会话归属检查，旧会话结果不得覆盖新登录。

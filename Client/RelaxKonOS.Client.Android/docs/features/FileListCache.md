# 文件列表缓存

Server 文件页和 SSH 文件页的操作菜单分别提供“缓存文件列表”，默认关闭，开关保存在设备本地，两种连接独立选择。开启后重新进入已浏览的目录时先显示内存列表并后台核实；缓存提示保留到新结果确认。手动刷新绕过缓存。

缓存仅包含文件列表元数据，不包含文件内容、密码或提权授权。每个文件页面的读取上下文最多保留 64 个目录、合计 50,000 项，有效期 5 分钟；超大目录不保存。访问不会延长写入时间，按最近使用淘汰旧目录。

Server 页在认证会话变化时清空缓存；SSH 页在主机或 Workspace 代次变化时清空。文件操作、未知写入结果及显式刷新会使快照失效；旧会话或旧导航的异步结果不能回填当前列表。Server 拒绝读取权限时撤下缓存；网络失败保留已有列表并显示失败/过期提示。缓存不参与任何文件修改的授权判定，SSH 仍使用当前连接的受信主机和凭据。

开关可跨进程保存，目录快照不会持久化到磁盘。真实设备验收需要覆盖慢连接、断线、切换账户和主机、连续目录导航、修改后的重读，以及开启/关闭选项；JVM 缓存策略检查不替代宿主端到端验证。

# 服务访问入口

部署详情、Nginx 站点和运行中的用户 SSH 本地转发提供地址预览与“通过外部应用打开”。仅生成 HTTP/HTTPS 地址，使用系统 ACTION_VIEW/BROWSABLE 选择器；不包含 API Authorization、Cookie、账号或密码，不创建 WebView、原生桥接或证书例外。外部应用自行处理登录与正常 HTTPS 验证；证书错误须修复证书、域名或访问路径，客户端不提供忽略验证按钮。没有可用处理程序或原会话/对象已改变时显示安全失败。

| 来源 | 当前地址规则 |
| --- | --- |
| 站点 | 使用实际 bindings，跳过通配、默认、无效或 loopback 域名；HTTPS 按当前 Nginx 契约监听 443；仅未启用 HTTP 重定向时提供实际 HTTP 绑定。上游 URI 不作公开访问地址。 |
| 部署 | 仅运行中的 Web 工作负载；直接登录使用稳定 serviceId 的服务器主机与实际发布端口，不导出 API 基路径/端口。受管登录的手机 API 隧道与远端 loopback 发布端口不被猜成业务地址。 |
| 关联站点 | 在 RESUMED 生命周期读取最多 20 个可读 Web Server，按 siteId 查找实际站点；可手动刷新，显示读取时间，失败保留明确不可查询提示。不根据部署域名猜测 TLS。 |
| 用户转发 | 仅运行中的记录，手机 127.0.0.1、实际分配端口及用户确认的协议/路径/查询。停止或旧宿主记录不能打开。HTTPS loopback 仍须外部应用认可对应证书。 |

地址候选不证明公网端口、DNS、防火墙或应用健康已经可达。无法生成直接部署地址时提供服务器中心入口和远端发布端口说明，由用户选择/验证 SSH 宿主并创建转发。不会自动连接 SSH 或修改端口、DNS、TLS。切到外部浏览器时，用户转发由现有 connectedDevice 前台服务持有；其停止/断线和进程退出规则见 [服务器中心](ServerCenter.md)。

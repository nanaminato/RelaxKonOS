# Android SMB 文件服务

## 入口与当前事实

管理目录在当前宿主提供 `server.file-services` 时显示 SMB。页面读取 capability、状态、连接信息，以及支持的共享/用户集合；观察者可以查看，写入要求当前会话具备 privilegedOperations。服务状态与 TCP 445 监听分别展示，不以其中一个推断另一个。

仅 Running/Stopped 且对应 capability 可用时查询集合。未查询使用未知事实，成功的空集合才显示没有共享/用户。任何读取失败都撤下可写事实。正在编辑且未确认成功的共享草稿仍以只读表单保留，旧事实仅提供表单结构，不能据此写入；“刷新并保留草稿”重新读取主机事实而不清空输入，仍须通过当前事实与待核实标记门禁才能保存。Windows 不查询 Linux 用户路由，也不提供 Windows 账户密码设置。

## 共享与账户

共享、账户与服务变更确认绑定原登录、完整事实快照和操作，每次确认只能消费一次。刷新、暂停、离页或关闭后撤销确认；旧回调不能在新登录下提交相同事实，也不能消费重新打开的确认。拒绝旧确认时立即清空传入密码数组，发送完成或取消后也清理。暂停撤下密码确认框并清除其输入，未提交共享草稿保留，返回后重新确认。

同步变更入口同时核对页面前台资格及捕获的交互代次；暂停即撤销旧代次，恢复后旧启停、共享保存、删除和账户动作仍不能创建新确认。按钮按代次重建，共享表单字段与高级设置不因保存按钮重建而重置。

安装取消确认绑定原登录和已核验的原任务，任务切换、刷新、暂停或关闭使旧确认失效；重复回调不能取消新任务或重复提交。确认期间暂停自动安装读取，等待结束时重新检查原任务和前台资格，旧计时器不能读取后来切换的任务。

### 界面与操作层级

概览使用服务状态卡片，将运行状态、服务活动与 445 监听分别显示为文字状态标签，检查时间直接可见，生命周期操作位于状态卡片内。版本和平台说明使用可展开的“高级设置与诊断”；健康问题始终保留。共享/账户数量仅根据已读取集合展示为文字，分类切换统一使用顶部页签；观察者显示仅可查看说明。

“操作记录”是独立页签，不依赖共享/账户集合或当前事实读取成功。组件中心发起的安装进度、取消、按 ID 恢复、待核实变更及最近一次变更回执集中在此页，不混入概览、共享和账户页；本应用不再提交安装或重试安装。其他页面在存在待核实操作时仅显示简短跳转提示，写入锁定规则保留。当前展示来自页面状态与恢复标记，不承诺完整持久历史；未提供的卸载能力不会生成记录或入口。

“从其他设备连接”卡片分别标注 Windows 与 SMB 地址，支持复制和文本选择，并解释同一网络、文件管理器及服务器账户的使用方法。地址不代表网络可达。共享列表卡片同时展示名称、目录、启用、读写和访客状态，选中项加粗主题色边框，外部/漂移说明保留。详情和账户操作放在各自卡片内，编辑为主按钮、删除为危险色按钮；共享编辑按基本设置、账户权限和高级设置分卡。状态标签和操作按钮自动换行，不依赖颜色识别状态。

共享编辑先选择服务器文件夹，再通过只读/读写选项和效果说明决定访问方式；访客开关说明无需凭据的影响，关闭时说明账户与文件夹权限的共同约束。账户权限始终可见，空列表不宣称任何人可访问；Samba 空主体输入可通过已报告的 eligible 账户快捷填入，Windows 仍要求真实 SID。描述和共享启用开关收纳到高级设置，折叠不改变草稿；禁用状态仍在编辑与详情中显示。复选项整行可点击，最小高度 48 dp。页签切换与返回、刷新同样触发草稿放弃确认，按钮明确为“放弃修改”。三语资源同步。

共享列表保留 Server 的 opaque ID，包括 Unicode Windows 共享名；路由编码为一个段。手机依次显示列表/详情/编辑，可用宽度达到 600 dp 时分栏。外部共享和受管漂移共享只能查看。

编辑保留名称、绝对路径、描述、只读、启用、访客和完整权限列表。目录字段使用现有远端 Directory 选择器；服务器负责实际目录存在、权限和链接校验。Windows 权限使用 SID，Samba 权限使用主机主体；Windows 的自动访客 SID 由 guestAllowed 生成，不重复作为用户权限提交。校验拒绝控制字符、配置注入、重复主体和无效访客写权限。

保存确认展示目录、启用/读写、访客和权限；目录位于建议共享根以外时显示暴露范围提醒，仍允许显式确认。删除只移除受管共享入口，保留目录文件。离页、返回、刷新和切换列表/标签均保护未保存草稿。

每次打开共享编辑器都有独立的编辑身份。字段变更、保存、关闭和只读草稿刷新核对当前编辑身份与前台代次，旧编辑器的回调不能恢复已丢弃的草稿或影响后来打开的草稿。保存同时核对当前草稿快照；放弃确认持有原草稿与原导航，每次决定只消费一次，旧取消、放弃或外部关闭不能消费新决定。暂停撤下放弃确认但保留草稿，返回后使用当前按钮继续。

Samba 用户页面仅针对 Server 报告的 eligible Unix 账户提供启用/禁用与密码设置。密码需两次匹配、12–1024 字符且无控制字符；密码只用于本次请求，不持久保存或回读。可变密码数组在完成、失败及等待锁时取消均清零。界面秘密仅属于当前确认表单；确认、取消、返回、离页或确认目标变化后清理，重新打开需要重新输入。确认表单可滚动并避让键盘，忙碌期间不编辑密码。

## 写入与结果未知

共享、生命周期和凭据写入授权固定为 `smbManage` / `smb:managed`。确认后重新读取完整事实，提权或认证重试后再次比较，变化时拒绝继续写入。客户端比较不构成 Server 的原子 CAS，也不能替代多客户端并发验收。

同步 SMB API 没有幂等键、任务查询、取消或重放接口。提交前持久保存当前宿主/账户的未知标记，只有动作、opaque 目标和本地标记 ID；不保存共享正文、目录或密码。本地 ID 不作为网络幂等键发送。网络丢失、写入失败或回执后事实读取失败均保留标记，禁止新的写入。

当前页面请求被取消时也撤下旧事实和安装任务的已核实状态，并显示未核实提示；已建立的变更标记继续保留。显式刷新只恢复读取，不重放变更，旧会话或旧代次的取消不能覆盖当前页面。

成功回执中的 operationId 仅关联审计。运维中心展示待核实入口，不伪造远端任务。普通刷新不清除未知标记；用户可显式“读取并接受主机当前状态”，成功读取受支持、可管理事实后解除标记，这不证明原写入成功，也不会重复原写入。页面直接展示本次核实返回的事实或失败，不追加一次读取来覆盖本次结论；核实失败撤下可写事实并保留原标记，不能以随后另一次读取成功掩盖核实失败。

采用入口绑定原登录、前台交互代次和当前展示的标记实例。暂停、离页、新登录或刷新后旧动作不能发起采用或覆盖当前事实；应使用当前按钮重新明确采用。采用读取被取消后，即使底层响应迟到成功，也不清理原标记，重新进入后仍须明确采用。

宿主同步回执、一次后置事实核验和本地恢复记录分别处理。仓库返回该次核验结果供页面使用，不再追加第二次读取；成功回执先保留并关闭已提交草稿。后置读取失败明确显示“宿主已接受变更、当前事实未核实”，仍保留原标记和回执 ID，禁止再次写入。回执保存或标记清理失败另行提示，不将已知宿主回执改为未知；恢复时仍只读取并采用当前事实，不重放原变更。密码数组在成功、失败、等待取消和本地持久化故障后均须清除。

发起新的变更时撤下上一笔回执，避免下一笔结果未知时仍以旧成功回执表示当前结果。显式读取再次立即失败时使用新的反馈事件，关闭旧提示不会压住本次失败。

## Samba 安装

Samba 安装只在组件中心进行：服务器报告可安装且未安装时，由组件中心复用 [公共运行时安装](Installations.md) 的 `SmbInstallationRequest(confirmed)` / Install 提交，应用内不再提供安装按钮、安装确认或安装重试。应用仍然观察同一安装台账中已发起的操作：已知 ID 优先按 ID 恢复，完全丢失 ID 时可由用户在“操作记录”显式识别原请求；活动任务在页面可见时观察，取消按服务返回的 cancellable 与当前事实确认；离页仅停止观察。

恢复响应必须属于 Smb / Install，不能将其他服务任务当作本领域结果。当前宿主/账户变化或退出会停止观察并清除页面事实；未知记录保留到重新核实。

安装终态与当前共享事实分别核实。已知 SMB / Install 任务终态先保留为已核实结果，再刷新共享事实；共享读取失败或当前协程仍有效时的读取取消，不将已知任务改成未知。页面显示专属事实刷新提示并撤下可写共享事实，记录页仍显示原 ID、终态及任务原因，显式刷新只恢复读取，不重新安装或取消任务。共享事实读取成功也不清除原任务失败原因，安装问题码使用公共安装文案。

- [Smb.kt](../../app/src/main/java/app/relaxkonos/mobile/core/net/Smb.kt)、[SmbValidation.kt](../../app/src/main/java/app/relaxkonos/mobile/core/net/SmbValidation.kt)：当前 typed 格式、路由和校验。
- [SmbRepository.kt](../../app/src/main/java/app/relaxkonos/mobile/data/SmbRepository.kt)、[SmbMutationJournal.kt](../../app/src/main/java/app/relaxkonos/mobile/data/SmbMutationJournal.kt)：读取、提权、复核和未知标记。
- [SmbScreen.kt](../../app/src/main/java/app/relaxkonos/mobile/ui/manage/smb/SmbScreen.kt)、[SmbViewModel.kt](../../app/src/main/java/app/relaxkonos/mobile/ui/manage/smb/SmbViewModel.kt)：页面、依赖入口、安装恢复与观察。

每次打开变更确认都使用独立的对象身份，即使同一账户、相同事实和相同动作在两次重绘之间直接替换，也不会沿用旧密码输入。旧提交和关闭回调只作用于原确认，不得清空或关闭新确认的输入；安装取消确认的关闭同样绑定原对象。用户关闭与生命周期撤销使用独立入口，暂停、离页和新请求仍可直接撤销当前确认。

安装提交不在本应用发生，因此没有安装确认身份可供复用；应用只保留对已有台账任务的原 ID 恢复表单，恢复表单同样冻结原登录与读取代次，暂停、离页、刷新或关闭都会撤销旧表单，旧提交不能作用于重新打开的表单。

安装观察以每次读取的反馈代次重新安排等待；服务器快速返回相同运行快照时仍持续观察，不依赖忙碌状态必须被重绘。Activity 暂停和恢复同步改变观察代次，旧等待即使未触发重绘也失效；后台不开始新的安装读取，恢复前台后重新等待完整间隔。已开始的只读请求仍可完成，观察不会重放安装、取消或共享变更。

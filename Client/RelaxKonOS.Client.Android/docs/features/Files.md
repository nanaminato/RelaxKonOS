# Android 文件与图片

文件入口管理当前 RelaxKonOS Server 的宿主文件。手机通过 Server 文件 API 操作远端路径；本地内容选择与下载由 Android 提供。文本编辑见 [共用编辑器](TextEditor.md)，上传和续传见 [文件传输](FileTransfers.md)，SSH/SFTP 文件属于服务器中心的独立连接。

## 浏览与选择

- 普通文件和 SSH/SFTP 浏览页采用紧凑间距，默认收起名称搜索。点击“搜索名称”展开；有筛选内容时保持输入框可见，点击“关闭”清空筛选并收起，避免隐藏筛选造成误判。
- 普通文件页的“操作”菜单集中新建文本文件、新建目录、上传、历史导航、转到目录、排序、隐藏项目和多选；点击路径也可转到目录。上级与刷新始终可见。
- SSH/SFTP 页的“操作”菜单集中上传文件/目录、新建目录、排序、多选及前进；路径可展开地址编辑。文件列表独立滚动并按需创建行，多选和剪贴板操作在使用时显示。

- 手机使用列表与详情导航，平板使用列表与详情双栏。目录点击进入；行菜单的“文件详情”可查看目录、文件和驱动器属性。进入详情可以预览、编辑或下载同一文件。
- 属性读取失败在详情内显示错误和重试入口；不匹配的属性回执也视为读取失败。读取错误不会覆盖文件写操作的结果未知提示，切换项目或会话时清理旧属性反馈。
- 详情页的复制、移动与删除操作按可用宽度换行，保持完整按钮文案；目录打开在文件变更或批量操作期间禁用，避免显示可点但导航被后台忽略。
- 目录及属性读取区分服务端路径无效、路径不存在和存储设备不可用回执，分别提供修改路径、返回上级/刷新及检查服务器设备后刷新的提示；认证、提权和传输错误保持各自反馈。
- 提供上级、后退、前进、刷新及转到目录。转到目录可输入远端路径或使用宿主目录选择器；空路径列出宿主根位置。历史最多保留 100 个位置，不持久化。
- 文件列表的系统返回在子目录回到上一级，根位置交给外层导航；文件变更或批量操作期间拦截返回，与上级按钮使用相同忙碌门禁。手机文件详情仍先返回列表，独立对话框处理自身关闭。
- 多选模式下系统返回先退出多选并清空勾选，保留当前目录；下一次返回再导航上级或交给外层。文件变更和批量操作期间仍优先拦截返回。
- 共用远端文件/目录选择器采用图标列表，目录优先并按名称排序，支持名称筛选、上级导航和刷新；进入目录会重置筛选与滚动位置。顶部显示当前完整路径（长路径最多显示两行），目录确认按钮固定在底部，仅在目录成功加载后启用。系统返回先回到上级，根位置返回关闭选择器。
- 选择器读取异常提供失败与刷新反馈，不选择尚未成功加载的目录；记忆目录读取失败回到根位置。请求代次隔离过期读取，导航或刷新后的迟到结果不更新当前页面。
- 目录选择器绑定打开时的会话，原会话归属失效后主动关闭，不把旧目录列表或选择结果交给另一会话。
- 点击选择器顶部的路径行可打开完整路径对话框，长路径正文可滚动，关闭后继续原选择流程。
- 名称筛选、宿主 `isHidden` 标志开关和名称/修改时间/大小/扩展名排序在本机完成。目录在升降序下均优先，排序不会清除选择。隐藏项目按宿主字段判断，不能仅从名称推断。
- 成功读取目录后，名称筛选无匹配显示“没有匹配搜索的文件或目录”，与未筛选时的空目录提示区分；加载期间仍显示加载状态。
- 目录读取失败显示刷新重试提示；同一目录刷新失败时保留已有列表并标明内容可能过期。目录加载期间或读取失败后暂停写操作，成功刷新后恢复。
- 多选模式最多选择 500 项。“选择可见项目”以当前筛选为范围；被筛选隐藏的已有选择仍计入总数。刷新保留仍存在的路径选择，导航清空当前多选。
- 驱动器和根路径不参与改名、删除和远端剪贴板写操作。单项改名保留原始名称空格，成功后详情、多选和远端剪贴板跟随新路径。

## 文件操作与远端剪贴板

提供创建目录、单项改名、单项复制/移动/删除及多选复制/剪切/删除。复制或剪切形成当前账户的内存剪贴板；进入目标目录后粘贴，需要确认具体项目和目标目录。剪贴板不写入 Android 系统剪贴板，不保存到磁盘，也不用于本地内容上传。

新建目录、改名、单项复制/移动及转到目录对话框避让软键盘，长路径与输入所在正文可滚动，确认与取消留在固定操作区。

新建目录和改名请求期间保留表单并冻结输入、取消和返回；明确拒绝在表单内显示错误并保留名称，供用户修正或取消。成功或结果未知关闭表单；结果未知先核对远端实际路径，不自动重发。

复制/移动沿用当前 API 的 `overwrite=false`。多选粘贴保留每个原名称，不覆盖同名目标；拒绝把目录放进自身或其后代。单项复制/移动对话框仅在绝对目标路径有效且不等于源路径时启用确认；目录的自身及后代目标也会禁用确认。目录不可写时，已打开的新建、改名、复制/移动和删除对话框禁用确认，仍可取消。重复选择和已选目录包含的后代在执行前归并，Windows 路径按驱动器、分隔符与大小写归一比较。

批量请求逐项串行执行，报告分别列出成功、未完成、结果未知和未执行。只有确认成功的移动项才从剪切剪贴板移除。4xx 返回表示请求没有完成；目录操作仍可能在报错前已复制或删除一部分内容，不承诺事务或自动回滚。超时、传输失败、畸形回执和 5xx 标为结果未知并停止余项；授权被拒绝或用户取消授权也停止余项，避免重复弹窗。401 令牌刷新和用户显式授权后的单次重试沿用当前授权契约。

单项操作直接抛出未预期异常时，保留此前已确认成功项，将当前项标为结果未知并停止余项；不展示异常原文，不自动重试。协程取消继续传播，账号归属变化不会发布旧批量结果。

批量结果正文可滚动，关闭和刷新按钮始终位于正文之外。系统返回不隐藏报告，需显式点击关闭；刷新只重新读取目录，保留报告，不重新提交该批操作。

“停止”等待当前请求返回，再跳过余项，不能取消已经发生的远端文件操作。批量期间禁用目录导航及其他写入，结果报告不会自动重试；请检查源和目标后决定下一步。批量队列/报告在 ViewModel 内存中保留，旋转继续使用同一状态；进程被回收后不自动重建或提交队列，需重新读取宿主实际状态。需要跨进程续传的上传继续使用已有分块日志，而非这一批量队列。

创建、改名和单次小文件上传的响应未知也给出事实检查提示。创建和改名请求抛出的非取消异常同样按结果未知处理，不自动重发，也不显示异常中的私有数据。下载逐步落盘，取消或失败丢弃未提交的本机目标；上传继续使用 SAF、分块/续传及应用级协调器，不把远端路径当作本机文件。Server 上传和下载均支持离页与后台继续，并提供可收起进度卡和通知取消；当前边界见 [文件传输](FileTransfers.md)。

只有存在失败或结果未知的项目时，结果报告才显示可能部分完成、需核对路径的提示；全部成功的报告仅展示已完成结果，不附加失败恢复警告。

## 属性与权限

详情展示路径、种类、大小、创建/修改/访问时间、属性和权限描述。Windows 权限描述同样可读；只有宿主声明 `server.posix.permissions` 且回执含 `unixMode` 时提供 POSIX 编辑。

编辑支持 3/4 位八进制 `0000–7777` 和所有者/组/其他用户的读写执行复选框。复选框保持 setuid/setgid/sticky 位，首位八进制数字可明确修改特殊位。默认只作用于当前项目；目录可勾选“递归修改所有后代”，通过 `recursive` 字段将同一模式应用至目录及所有后代，跳过符号链接。

先修改后代再修改父目录；失败可能留下部分修改，不保证回滚。使用 `PUT /api/v1.0/files/permissions` 和该路径的 `write` 授权；回执的路径及实际模式匹配后才显示保存成功。明确拒绝在权限表单内显示错误并保留八进制输入和递归选项，用户可修正或取消；传输失败、异常、5xx 或不匹配的成功回执提示结果未知并退出编辑，重新读取实际属性，不自动重发。权限没有版本/CAS 契约，外部并发更改可能覆盖。

自动属性读取不弹管理员提示；拒绝时显示显式授权入口。属性读取、预览、下载和写入绑定原始会话，选中其他项目或切换账户后的旧响应不能覆盖当前详情，授权弹窗期间的账户切换也不能把旧路径和凭据发给新会话。

## 图片查看

选中可解码图片后自动请求缩略图及有界原图预览，已有授权规则不变。全屏查看提供：

- 双指缩放、平移、缩小/放大、适配重置、90° 旋转；缩放为适配比例的 25%–800%，不是原始图片像素的 1:1 承诺。
- 根据旋转后的长宽计算适配比例和平移边界，防止图片被拖出画布；旋转重新适配，窗口尺寸改变保留缩放并重新限制偏移。
- 在当前目录的可见图片顺序中上一张/下一张切换。切换后重置变换，加载、失败及显式授权仍留在查看器内；没有上一张/下一张时禁用按钮。

旋转只影响显示，不修改宿主图片。状态由 ViewModel 持有，手机横竖屏和列表/详情布局改变不会重新开始同一图片的网络传输。平台解码沿用 EXIF 方向纠正及最多 400 万像素的降采样预算，因此大图放大时可能看到预览像素；不加载无限原图到内存。

预览缓存按宿主与账户、远端路径、大小及修改时间区分，已确认缓存容量为 64 MiB。每次传输使用独立暂存文件，成功且实际长度/回执长度/已知元数据一致后才发布；未确认的完整长度文件也不能命中。取消或迟到请求清理自己的暂存，不删除较新的缓存；下一次缓存初始化/整理清除进程遗留暂存。已知超过 64 MiB 的图片提示下载原文件，未知大小也在写入时限制 64 MiB。

桌面窗口的树形导航、拖放、本机剪贴板导入、系统进程打开方式不复制为 Android 控件。手机采用明确的远端目录选择、SAF 上传、文件/图片/编辑器入口及本机下载，不能将桌面关联程序当作宿主或 Android 应用运行。

功能说明见 [功能目录](../README.md)，自动化状态和设备/真实宿主检查见 [验证要求](../development/Verification.md)。

## 文件选择位置记忆

本机上传的 SAF 选择器和共用 `RemotePathPicker` 已接入设备本地使用记忆。确认后保存、取消不覆盖、显式路径优先、账户/用途/工作区隔离和远程无权限回退规则见 [设置中的使用记忆](Settings.md#使用记忆)。这些默认值不恢复旧授权、不记住密码，也不自动提权。

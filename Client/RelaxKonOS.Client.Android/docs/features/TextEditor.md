# 文件与 Git 共用编辑器

> 当前行为对应 BP11。实现和验证分别见 [Progress](../status/Progress.md) 与 [Verification](../status/Verification.md)。

文件详情的“打开文本编辑器”、文件列表的“新建文本文件”和 Git 的文件入口使用同一全屏编辑器。文件可新建及另存到完整服务器路径；已有目标不会被覆盖。Git 入口编辑已存在的工作树文件，继续拒绝仓库外路径、`.git` 和符号链接；保存、提交、推送与构建分别执行。

支持最多 256 KiB 的严格 Unicode 文本：UTF-8 可带或不带 BOM，UTF-16 LE/BE、UTF-32 LE/BE 必须带 BOM，读取时按 BOM 明确检测。无 BOM 时只按 UTF-8 解码，不猜测旧代码页。大小按编码后的字节计算；二进制控制字符、非法 Unicode 和超限内容拒绝读取或保存。

保留原有内容和换行。LF、CRLF、CR 可显式转换；混合换行在未转换时保留。输入新换行和替换文本会沿用单一原始格式。提供区分大小写的查找、循环查找下一处、全部替换、基础字符串/注释/关键词着色和最多 120 行的差异显示。正文填满页面剩余空间并在编辑框内滚动；“文件格式”弹窗按需显示编码、BOM、换行转换和大小限制。“查找替换”和“查看差异”分别使用可滚动弹窗；查找下一处后关闭弹窗，在正文显示选区。新建文件显示目标路径，已有文件仅在“另存为”弹窗中输入路径。操作按钮保留在底部并避让 IME。

已有文件保存携带精确字节 SHA-256，基线变化拒绝写入。冲突回读后展示服务器内容与草稿的比较；用户显式选择丢弃草稿或采用新版本作为基线继续编辑。保存响应丢失或回执不匹配时禁止再次保存，刷新回读核实；不能把读取失败当作保存成功。另存为的未知结果核实对应目标路径。

编辑期间全屏模态阻止底层导航。返回或关闭遇到未保存内容及未核实保存时要求显式放弃；放弃不会撤销已发生的服务器写入。ViewModel 在 Activity 配置重建期间保留草稿；草稿只在内存，进程退出不恢复。注销和切换身份清除内容、取消请求，旧响应不能覆盖新会话。保存过程中不能编辑或关闭。

读取和条件保存走普通有效宿主身份，Helper 使用 `FileReadText` 的固定 256 KiB 边界；不降级成无条件写入，不使用 root/临时提权兜底保存受保护文件。需要保护路径写入时，当前服务端明确拒绝；这不是已通过的提权编辑能力。共享协议说明见 [Git 契约](../../../../docs/applications/RelaxKonOS.GitClient.md#共享文本编辑契约)。

设备旋转、IME、平板、大字体、真实 Helper 身份与文件系统并发检查独立保留在 Verification，编译及 JVM 测试不替代这些验收。

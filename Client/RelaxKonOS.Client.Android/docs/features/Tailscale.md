# Tailscale 宿主管理

应用桌面、应用搜索及功能目录按 `server.tailscale` 能力显示 Tailscale。页面管理所选远端服务器上的 Tailscale，不在 Android 上运行 VPN 或接管系统 VPN 服务。

页面自动读取宿主状态，可手动刷新，显示版本、原生连接状态、本机节点、其他设备的名称、DNS 名称、地址、在线状态与出口节点标记。设备详情受服务端当前 `HostNetworkChange` / `host/tailscale` 授权限制；受限时显示说明，不主动提权。

未安装、平台不支持、查询失败分别呈现。未安装仅指服务端支持的固定安装位置未发现 CLI，不证明宿主不存在其他布局。读取失败撤下旧事实，不将未知状态显示为未安装。切换服务器、账户或登录会话清除旧观察；离页取消等待，迟到响应不能写入新会话。

## 连接与配置

页面分为设备、连接与配置、首次登录、操作记录。连接页由用户明确选择读取控制状态／授权，使用统一 `hostNetworkChange` / `host/tailscale` 提权入口；只有服务器要求授权时才询问管理员凭据。已登录的宿主支持连接、断开和编辑接收 DNS／路由两个布尔设置，不接受原生命令、路径或登录密钥。

变更先由服务器生成带修订和期限的计划。客户端核对计划身份，成功保存原 operationId 引用后显示风险确认；确认列出服务器、动作和 DNS／路由接收前后值，提示可能断开当前远程连接且没有自动回滚。配置未变、取消确认、过期、离页、后台或会话切换均不能使用旧确认提交。原生变更已被服务端受理后，关闭页面只停止等待，不撤销宿主动作。

请求等待期间只要进入过后台，其确认资格就失效；回到前台不恢复旧资格。控制或首次登录计划即使随后成功返回，也只保留原操作引用，不自动重新弹出确认。用户可以重新发起计划并明确确认。

## 原操作与未知结果

应用私有、不参与系统备份的目录保存操作身份引用及提交／关账未决标记，不保存凭据、授权、配置或操作结果。引用按宿主、账户和工作区隔离，重新登录同一账户可重开。文件发布前同步内容，使用排他文件锁及原子重命名，发布后同步目录；损坏、争用或保存失败时拒绝提交无引用的新变更。每个账户保留至多 30 项，全设备至多 256 项；未决引用不因保留上限被淘汰。

执行响应丢失后，未决标记阻止新变更。操作记录只读取原 operationId 的服务端回执，不重放执行；读取其他历史不会解除该标记。宿主状态不能代替原成功证明。原结果未知时可经授权核对当前宿主观察，再明确确认接受观察并关账；关账不回滚、不重放，也不把原结果改成成功。关账响应丢失同样通过读取原回执核对。

## 首次登录与浏览器交接

首次登录页打开时只读取本地引用，不自动发起登录或提权。用户发起后由服务器生成短期计划，成功耐久保存引用并明确确认风险后才执行。已签发挑战只表示发起请求产生了认证挑战，不代表用户认证完成；原任务为 completed 也只能来自原生命令的完成证据，不根据以后观察到的 Running 改判。

用户另行点击“打开官方登录页”时，客户端经当前会话和新鲜授权获取短期挑战，复核原任务 ID、期限以及精确的 `https://login.tailscale.com/a/` ASCII 令牌来源，然后通过 Android 的浏览器／系统网页应用交接打开。链接不进入 ViewModel 状态、引用文件、剪贴板、普通操作回执或应用日志。浏览器交接请求成功不代表认证完成；用户回到应用后应刷新设备状态，再核对原登录操作。

登录意图及挑战交付绑定原服务器、账户和服务端登录会话。重新登录后，同一账户可从本地引用读取旧登录操作并经新鲜授权核对关账，但不能执行旧计划或领取旧链接；其他账户不能读取这些回执。登录引用使用独立的 `tailscale-login-operations.bin`，位于应用不参与系统备份的私有目录，按宿主、账户、工作区隔离，沿用每类每账户 30 项、全设备 256 项的上限及未决引用保护，不与普通控制记录混用。

issued、unknown 和 approval-required 的原登录任务均可读取稳定观察，再明确确认接受状态并关账。取消等待、离页、后台、进程结束或关账都不承诺撤销服务器端已签发的上游认证挑战。关账不重放登录、不回滚，也不生成原登录成功证明。响应丢失只读取原 ID，不自动重复发起。挑战过期、来源不符、会话切换或应用进入后台时不交接浏览器；缺少浏览器时保留原任务，交由用户再次核对。

浏览器请求等待期间进入后台后，即使在挑战返回前已回到前台，旧点击也不能打开网页。再次交接必须由用户重新点击并重新读取短期挑战，不复用前一次被中断的交接手势。

当前不提供运行时安装维护，也不在 Android 上建立本机 VPN。共享契约及宿主实现边界见 [Tailscale 设计](../../../../docs/applications/RelaxKonOS.Tailscale.Design.md)。

验证要求：检查能力隐藏、设备授权过滤、空列表、双栈地址、查询失败、请求中切换账户/宿主与离页；检查确认撤回、过期和后台切换、持久引用失败、原回执身份不符、断线重开、未知结果和关账回执恢复；检查原会话专属挑战、新会话同账户只读／关账、非官方链接拒绝、无浏览器、后台与离页时晚到挑战不打开；检查手机和平板、大字体、三语言、深浅主题和 TalkBack。模拟 HTTP 与单元测试不代表真实 Tailscale daemon 或设备交互验收。

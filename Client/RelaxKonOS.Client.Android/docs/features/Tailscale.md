# Tailscale 宿主管理

应用桌面、应用搜索及功能目录按 `server.tailscale` 能力显示 Tailscale。页面管理所选远端服务器上的 Tailscale，不在 Android 上运行 VPN 或接管系统 VPN 服务。

页面自动读取宿主状态，可手动刷新，显示版本、原生连接状态、本机节点、账户与网络名称、其他设备的名称、DNS 名称、地址、所有者、操作系统、标签、在线状态、最后在线、密钥到期和出口节点标记。设备、账户、网络、所有者、标签与出口节点身份受服务端当前 `HostNetworkChange` / `host/tailscale` 授权限制；受限时显示“授权查看账户与设备”，只在用户明确点击后经统一提权入口请求授权，不在打开页面时自动提权。

未安装、平台不支持、查询失败分别呈现。未安装仅指服务端支持的固定安装位置未发现 CLI，不证明宿主不存在其他布局。读取失败撤下旧事实，不将未知状态显示为未安装。切换服务器、账户或登录会话清除旧观察；离页取消等待，迟到响应不能写入新会话。

## 连接与配置

页面分为设备、连接与配置、首次登录、操作记录。进入连接页即读取连接快照（观察本身不再要求提权），可手动刷新；只有服务器明确要求授权时才询问管理员凭据。已登录的宿主支持连接、断开、编辑完整偏好和退出登录。偏好闭集为：接收 DNS、接收子网路由、允许传入连接（`shields-up` 反向）、出口节点、出口节点本地网络访问、无人值守（仅 Windows 宿主）、自动安装更新、将此设备作为出口节点提供。出口节点可从“无”、官方自动选择（`auto:any`）或当前 daemon 报告 `ExitNodeOption` 的节点中选择；具体节点身份仍要求设备授权。不接受原生命令、路径或登录密钥。

变更先由服务器生成带修订和期限的计划。客户端核对计划身份、配置或完整偏好，成功保存原 operationId 引用后显示风险确认；确认列出服务器、动作和变更前后值，提示可能断开当前远程连接且没有自动回滚。配置或偏好未变、取消确认、过期、离页、后台或会话切换均不能使用旧确认提交。原生变更已被服务端受理后，关闭页面只停止等待，不撤销宿主动作。提交完成后重新读取控制状态与设备状态，不需要用户再次点击读取。

## 退出登录

控制页的“退出登录”是闭集动作：固定执行 `tailscale logout`，必须经新鲜授权、明确确认和原操作台账，界面单独说明会断开局网连接、需要重新浏览器授权，并可能中断当前远程访问。Helper 只有回读到 `Authenticated=false`、`Connected=false` 才发布完成回执；退出后控制观察为只读（`CanControl=false`），连接卡显示“需要登录 Tailscale”，任何变更需先在“首次登录”重新授权。未解析的退出登录意图可从登录前/后的稳定观察核对关账，不重放命令，也不把后来状态反推为原操作成功。Android 不提供多账户档案切换；切换账户的路径是退出登录后重新登录，也不提供重置为默认值或常驻系统通知。

请求等待期间只要进入过后台，其确认资格就失效；回到前台不恢复旧资格。控制或首次登录计划即使随后成功返回，也只保留原操作引用，不自动重新弹出确认。用户可以重新发起计划并明确确认。

## 原操作与未知结果

应用私有、不参与系统备份的目录保存操作身份引用及提交／关账未决标记，不保存凭据、授权、配置或操作结果。引用按宿主、账户和工作区隔离，重新登录同一账户可重开。文件发布前同步内容，使用排他文件锁及原子重命名，发布后同步目录；损坏、争用或保存失败时拒绝提交无引用的新变更。每个账户保留至多 30 项，全设备至多 256 项；未决引用不因保留上限被淘汰。

执行响应丢失后，未决标记阻止新变更。操作记录只读取原 operationId 的服务端回执，不重放执行；读取其他历史不会解除该标记。宿主状态不能代替原成功证明。原结果未知时可经授权核对当前宿主观察，再明确确认接受观察并关账；关账不回滚、不重放，也不把原结果改成成功。关账响应丢失同样通过读取原回执核对。

已标记提交未决的原操作即使读取为 Prepared，也不能解除门禁：这不能排除先前的执行请求仍在传输或排队。客户端本地报告计划过期同样不替代服务端原拒绝回执；继续读取原 ID，取得已受理状态／终态后按其证据处理。关账未决只由原关账证据解除，未闭合的普通操作观察不能代替该证据。

## 首次登录与浏览器交接

首次登录页打开时读取宿主状态并只读取本地引用，不自动发起登录或提权。只有宿主处于 `NeedsLogin` 时“发起登录”才可用；已登录并连接、已登录但断开、等待设备批准或正在启动分别显示对应说明，已登录时提示如需更换账户应先在宿主退出 Tailscale。状态读取失败或尚未取得观察时按钮保持禁用，并允许手动刷新后重试。服务端返回的 `tailscale.login.not_available`、`state_changed`、`unavailable`、`outcome_unknown` 及恢复回执错误会显示具体原因，不再统一显示为“无法核实本次操作”。

用户发起后由服务器生成短期计划，成功耐久保存引用并明确确认风险后才执行。已签发挑战只表示发起请求产生了认证挑战，不代表用户认证完成；原任务为 completed 也只能来自原生命令的完成证据，不根据以后观察到的 Running 改判。

用户另行点击“打开官方登录页”时，客户端经当前会话和新鲜授权获取短期挑战，复核原任务 ID、期限以及精确的 `https://login.tailscale.com/a/` ASCII 令牌来源，然后通过 Android 的浏览器／系统网页应用交接打开。链接不进入 ViewModel 状态、引用文件、剪贴板、普通操作回执或应用日志。浏览器交接请求成功不代表认证完成；用户回到应用后应刷新设备状态，再核对原登录操作。

登录意图及挑战交付绑定原服务器、账户和服务端登录会话。重新登录后，同一账户可从本地引用读取旧登录操作并经新鲜授权核对关账，但不能执行旧计划或领取旧链接；其他账户不能读取这些回执。登录引用使用独立的 `tailscale-login-operations.bin`，位于应用不参与系统备份的私有目录，按宿主、账户、工作区隔离，沿用每类每账户 30 项、全设备 256 项的上限及未决引用保护，不与普通控制记录混用。

issued、unknown 和 approval-required 的原登录任务均可读取稳定观察，再明确确认接受状态并关账。取消等待、离页、后台、进程结束或关账都不承诺撤销服务器端已签发的上游认证挑战。关账不重放登录、不回滚，也不生成原登录成功证明。响应丢失只读取原 ID，不自动重复发起。挑战过期、来源不符、会话切换或应用进入后台时不交接浏览器；缺少浏览器时保留原任务，交由用户再次核对。

浏览器请求等待期间进入后台后，即使在挑战返回前已回到前台，旧点击也不能打开网页。再次交接必须由用户重新点击并重新读取短期挑战，不复用前一次被中断的交接手势。

运行时安装、更新和保留数据卸载由[组件中心](ComponentCenter.md)提供，目标是所连接的 Linux 服务器或 Windows 11 用户模式宿主。Android 只承担控制端，不在手机安装 Tailscale 或建立本机 VPN。应用内“组件”入口读取宿主状态并进入组件中心。共享契约及宿主实现边界见 [Tailscale 设计](../../../../docs/applications/RelaxKonOS.Tailscale.Design.md)。

验证要求：检查能力隐藏、设备授权过滤与显式授权、空列表、双栈地址、账户/所有者/系统/标签/最后在线/密钥到期字段、查询失败、请求中切换账户/宿主与离页；检查完整偏好计划、出口节点候选限制、偏好未变不预览、确认撤回、过期和后台切换、持久引用失败、原回执身份不符、断线重开、未知结果和关账回执恢复；检查退出登录确认、登录后只读快照、重新登录前拒绝变更及未知退出登录的核对关账；检查原会话专属挑战、新会话同账户只读／关账、非官方链接拒绝、无浏览器、后台与离页时晚到挑战不打开；检查手机和平板、大字体、三语言、深浅主题和 TalkBack。当前 Tailscale 专项单元测试覆盖 wire、计划与完整偏好、退出登录、设备字段、操作引用、登录可用状态和 ViewModel 计划/后台失效，共 87 项通过。模拟 HTTP 与单元测试不代表真实 Tailscale daemon 或设备交互验收。

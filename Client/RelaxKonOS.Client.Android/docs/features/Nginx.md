# Android Nginx 管理

发现、接管和生命周期操作集中于实例页；**Nginx 的安装与卸载只在组件中心进行**，应用内不再提供安装入口、版本/文件选择、安装确认或卸载按钮。站点页直接使用实例页选中的 Nginx，不显示实例列表或发现入口；未选择时提示先去实例页选择。手机从实例详情返回列表仍保留选择。Debian/Ubuntu 系的受管安装由组件中心发起，其在 APT 操作前检查所有权标记目录写权限；部署脚本授予服务组对 `webserver` 父目录的穿越权限。

实例列表使用可点击卡片，集中显示版本、路径与受管/集成身份。网站工作区保留“操作记录”页：组件中心发起的 Nginx 安装任务、本应用的维护任务、恢复/重试、站点提交核实和发布结果/历史集中于此；实例和站点页不重复显示记录详情，有待处理任务时提供跳转入口。取得任务 ID 后进入记录页并展示真实状态与阶段；收到 ID 仅表示任务已接受。

“管理 → 网站”提供 Nginx 管理、既有站点诊断及应用 HTTPS 发布。入口按 `server.web-server` 门控；接管与生命周期按钮要求当前登录会话允许宿主提权。手机从实例列表进入详情，平板在可用宽度达到 600 dp 时显示实例与详情两栏。

## 安装来源

Nginx 的安装、版本选择与文件选择由[组件中心](ComponentCenter.md)负责：

- Debian/Ubuntu 系（Ubuntu、Debian，以及只报出「Linux」的受支持宿主）由组件中心冻结宿主 APT 候选并提交同一安装台账；已有系统 Nginx 优先在应用中接管，不提供重复安装入口。
- Windows 由组件中心提供服务器固定归档版本，也可从服务器已有 ZIP 或手机选择的 ZIP 建立操作者绑定的文件引用；版本以操作者填写为准，实际布局由服务器校验。
- 安装仍复用公共安装 Repository、会话提权、原幂等键与任务索引。应用内只观察安装任务：展示原操作 ID、真实状态、当前阶段与服务端百分比，支持当前契约允许的取消；页面只在可见期间轮询，离页停止观察，服务器任务继续运行。
- 组件的未安装状态在进入应用时由统一入口检查提示；修复、回退、更新与卸载边界以组件中心当前能力为准。

## 发现、接管与实例动作

发现调用当前 `/webservers/discover`，分别读取受管实例和未接管候选。候选显示版本、可执行文件及配置路径；接管前说明备份、受管 include、配置校验和可能的 reload 影响。请求使用 `confirmed=true`、稳定幂等键及候选目标的 `nginxConfigurationWrite` 授权。

实例详情显示管理模式、宿主路径、运行状态和配置检查结果；状态查询失败显示未知，不显示已停止。动作按当前实例的 `canStart/canStop/canRestart/canReload` 展示，不给外部接管实例伪造完整启停能力。启停/重启/重载使用 `nginxLifecycle`；ACME HTTP-01 使用配置写授权，明确说明不自动开放防火墙或证明公网可达。

受管 Nginx 的卸载由[组件中心](ComponentCenter.md)发起，经同一安装台账确认停机与删除影响；应用内不再显示卸载按钮。Windows 受管实例与 Debian/Ubuntu 系已接管、使用 `/usr/sbin/nginx` 和 `/etc/nginx/nginx.conf` 的 APT 系统安装都可从组件中心卸载，后者会清除系统包及其包配置。

外部自定义安装不授予卸载能力。安装和实例维护任务运行期间禁用接管与生命周期操作，页面与 ViewModel 同时校验，避免安装中提前接管。存在待核实的实例/安装任务时禁用生命周期操作，完成后在轮询协程内刷新实例和站点事实；重新进入页面也恢复最近已知的安装任务。切换回实例页会重新查询已缓存的 Web 操作 ID，使用服务端终态替换旧的排队/运行中状态；已知安装恢复记录也同步核实并解除本地待处理状态。

前台持续观察已核实的活动任务；后台、隐藏的网站发布栏目、编辑器及确认框打开期间暂停自动查询。延迟结束后再次核对原登录、读取代次和前台资格。读取失败保留原任务 ID，但撤下取消入口并显示未核实，等待显式刷新；同轮其他任务读取成功不能清除该失败。禁用控制时在实例详情直接显示原因，区分刷新、安装进行中、实例操作进行中、待核实请求和状态读取失败。

## 操作与恢复

Web 操作与安装操作使用各自的状态机。Web 操作展示原 ID、终态/运行中、稳定问题码对应的本地化说明及服务端提供的配置快照 ID；可按 ID 查询，并提交确认式取消。运维中心保存 Web 操作引用、查询实际记录、取消及返回网站入口，不能把网站发布操作当实例生命周期操作。

取消确认显示完整原任务 ID，绑定原登录与已核实任务快照。关闭、手动读取、切栏目、切实例或暂停页面均撤销确认；重新打开同一任务不会使旧回调重新有效。每个确认只能消费一次，提交使用原 ID，不能随当前任务变化转向另一任务。安装任务还须满足服务端可取消标记。

`webserver-requests.bin` 只保留当前宿主/账号、目标 ID、动作、原请求键、是否尝试和已取得的操作 ID。写入失败停止提交；收到 ID 后先写恢复证据，再写操作索引。网络失败不自动重放；用户重试前查询宿主实际状态，再复用原键。切换会话（包括相同资料重新登录）、注销后清理页面表单和显示结果，旧响应不能覆盖新会话。

接管重试先按原请求键、目标、动作及账号查找服务端操作，再检查候选；候选因成功接管或受管安装而消失时，原键仍能恢复真实任务，不再次执行配置变更。首次提交明确返回 404 时解除本地待处理请求；此前网络结果未知的重试返回 404 仍保留恢复证据，不能将当前实例事实当作原请求成功。已知 ID 可恢复；未知 ID 使用原键显式重试。

若仍无法取得原 ID，但实例已经受管且当前配置检查通过，记录页提供“接受当前实例状态”：用户确认服务端操作已结束后，再刷新核实实例与配置，结束该条本地受管请求的待核实记录。这不会标记原请求成功，也不会取消服务端任务；活动/未知安装状态期间不可使用。取消结果仍须结合实例状态与配置检查确认，不把取消任务解释为副作用已回滚。

源码入口：`WebServerManagement.kt`、`WebPublishing.kt`、Gateway/API、`WebServerRepository.kt`、`WebServerRequestJournal.kt`、`NginxViewModel.kt`、`NginxManager.kt`、OperationIndex/OperationCenter。

## Windows 宿主安装来源

Windows 宿主上的 Nginx 安装、版本选择与文件选择由[组件中心](ComponentCenter.md)负责；本应用不提供安装表单或卸载按钮。应用保留实例发现、接管与生命周期操作，以及对组件中心已发起安装任务的观察与取消。

## 本地诊断

网站页的“Nginx 诊断日志”可查看和复制当前进程最近 200 条诊断，Android Logcat 标签为 `RelaxKonNginx`。记录单调时间、线程、刷新结果、忙碌导致跳过、会话取消、异常类型、安装/维护响应及本地待核实请求（动作、目标、是否尝试、操作 ID），用于对比异步响应和记录清理顺序。日志不包含密码、令牌、原请求键或完整响应，重启应用后清空。复现后点击发现实例，再复制日志以定位禁用原因。

刷新成功后，若旧接管意图没有操作 ID，而目标实例已受管/集成且当前配置有效，并已核实安装与维护任务均非活动状态、无待核实安装，则结束这条已被当前受管事实取代的本地意图。不会为它绑定其他任务 ID、标记成功或重放变更，诊断记录为 `web.intent.superseded originalOutcome=unknown`。网络失败、活动任务、无效配置、目标不匹配、生命周期请求和已有操作 ID 的请求均不走此清理规则。

Nginx 操作与安装任务的自动观察在每次请求后使用新的界面请求代次安排下一轮等待。快速返回相同运行快照时也持续读取，不依赖忙碌状态必须被重绘；暂停、取消确认、编辑器或错误门禁仍按当前页面规则停止观察。自动观察只读取既有任务，不重放写入或取消。

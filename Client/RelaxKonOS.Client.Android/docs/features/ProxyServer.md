# 代理服务端（sing-box）

管理页的「代理服务端」控制已连接服务器上由 RelaxKonOS 托管的 sing-box 运行时。入口要求登录描述符声明 `server.proxy-server`；写入与敏感导出还要求该账号具备特权操作。它与客户端的「出站代理」（Mihomo）和「Squid HTTP 网关」是三个互不替代的应用。

## 页面

概览显示运行状态、内核版本、草稿/已发布/上一版修订、已应用标记、开机启动、统计可用性、恢复提示与最近问题码。运行时区按服务器能力提供安装、升级到清单中尚未安装的已验证版本、启动、停止、重启、开机启用/禁用、卸载（保留或删除数据），以及校验、发布、回滚和恢复。发布替换渲染后的配置并重启正在运行的服务，校验本身不改动主机。

入站服务为只读列表：名称、协议、监听地址与端口、对外地址与端口、启用状态。手机不提供入站增删改，因为监听地址、对外端点、服务器名称、REALITY 握手目标与证书引用必须在同一张表单里一起决定，桌面才提供该表单。

访问凭据分两层：代理使用者（principal）用于归属，设备凭据是 VLESS 的 UUID 或 Trojan/Hysteria2 的密码。一个凭据可以授权多个入站，但仅当这些入站要求相同的秘密形状；到期时间按 `YYYY-MM-DD` 读取为 UTC 零点，留空表示不过期。保存凭据不会断开现有连接，发布才会；轮换会立即作废旧值。

连接与导出选择已应用服务上的凭据，按支持的格式导出 VLESS/Trojan/Hysteria2 URI、sing-box JSON 或 Mihomo YAML；只支持单入站的格式会给出不可用原因。导出内容包含秘密，只显示在屏幕上，由用户主动复制到剪贴板，不写入本地存储。切换凭据、离开当前分区、页面退出或应用进入后台时，清除导出内容与格式选择；旧格式请求不能覆盖新凭据，迟到的秘密响应不能重新展示。显式清除在请求进行中同样生效。

订阅按格式签发链接，token 只在签发响应中出现一次，服务器只保存哈希；已签发列表可撤销，删除凭据会同时撤销它的全部订阅。公开下载路由匿名访问，不携带管理登录。签发结果的显示资格随清除、分区/会话切换和进入后台撤销，已经提交的签发仍可能完成；页面不会自动再次签发。丢失的一次性 token 无法读回，应在核对订阅列表后显式撤销并按需重新签发。

记录页显示本次会话的操作，并允许按操作 ID 读回中断前已受理的操作。

## 操作与会话

所有变更使用唯一 `Idempotency-Key`，202 表示已排队，随后按操作 ID 轮询到终态；离开屏幕停止轮询，已提交的服务器操作继续执行，页面重新进入后刷新即可看到结果。传输失败显示「结果未知」，不自动更换幂等键重发。

会话切换清空表单、导出内容、已签发 token、操作状态与已观测事实，旧结果不会写入新会话。

## 边界与验证要求

统计与流量日志在当前构建为「不支持」，界面显示该结论而不显示数字或零值；手机不做本地 VPN/TUN，不生成二维码，不改入站定义，不签发证书，也不管理宿主机防火墙。

订阅链接本身就是凭据：token 只显示一次，截屏、日志与工单中都不应出现。验证应覆盖受管运行时上的安装与升级、发布与回滚、凭据轮换后的连接中断、到期凭据在发布前被拒、订阅撤销后匿名下载失败、观察者无写入入口、断网后不重复变更，以及三语与窄屏/平板布局。实现与文档不代表这些真机验证已执行。

# 代理服务端（sing-box）

管理页的「代理服务端」控制已连接服务器上由 RelaxKonOS 托管的 sing-box 运行时。入口要求登录描述符声明 `server.proxy-server`；写入与敏感导出还要求该账号具备特权操作。它与客户端的「出站代理」（Mihomo）和「Squid HTTP 网关」是三个互不替代的应用。

## 页面

概览显示运行状态、内核版本、草稿/已发布/上一版修订、已应用标记、开机启动、统计可用性、恢复提示与最近问题码。概览提供启动、停止、重启、开机启用/禁用，以及校验、发布、配置回滚和恢复；独立运行时页提供签名版本目录与冻结计划。发布替换渲染后的配置并重启正在运行的服务，校验本身不改动主机。

入站服务可新增、编辑、删除：名称、五种协议预设、监听 IP 与端口、对外地址与端口、服务器名称、证书 ID、REALITY 握手目标与端口、WebSocket 路径、启用状态在同一张可滚动表单里编辑。证书与 REALITY 字段按协议显示，非适用字段归一为当前共享模型默认值。退出有修改的入站表单先确认丢弃；删除先确认；仍被凭据引用的入站禁止删除，更改协议秘密类型前也须先移除相关授权。每次保存携带打开编辑时的 expectedRevision 和完整入站列表，服务器拒绝冲突，刷新不会替换正在编辑的表单。保存仅改草稿，校验与发布另行执行。可独立编辑 HTTPS 订阅基地址，留空关闭托管；不签发新证书。

访问凭据分两层：代理使用者（principal）用于归属，设备凭据是 VLESS 的 UUID 或 Trojan/Hysteria2 的密码。一个凭据可以授权多个入站，但仅当这些入站要求相同的秘密形状；到期时间按 `YYYY-MM-DD` 读取为 UTC 零点，留空表示不过期。保存凭据不会断开现有连接，发布才会；轮换会立即作废旧值。

连接与导出选择已应用服务上的凭据，按支持的格式导出 VLESS/Trojan/Hysteria2 URI、sing-box JSON 或 Mihomo YAML；只支持单入站的格式会给出不可用原因。导出内容包含秘密，只显示在屏幕上，由用户主动复制到剪贴板，不写入本地存储。单行且少于 2000 字符、可编码的 URI 同时在本地生成二维码；二维码随导出内容一起清除，不经过外部二维码服务。切换凭据、离开当前分区、页面退出或应用进入后台时，清除导出内容与格式选择；旧格式请求不能覆盖新凭据，迟到的秘密响应不能重新展示。显式清除在请求进行中同样生效。

订阅按格式签发链接，token 只在签发响应中出现一次，服务器只保存哈希；已签发列表可撤销，删除凭据会同时撤销它的全部订阅。公开下载路由匿名访问，不携带管理登录。签发结果的显示资格随清除、分区/会话切换和进入后台撤销，已经提交的签发仍可能完成；页面不会自动再次签发。丢失的一次性 token 无法读回，应在核对订阅列表后显式撤销并按需重新签发。

记录页显示本次会话的操作，并允许按操作 ID 读回中断前已受理的操作。

## 运行时版本与恢复

运行时页读取 `managed-runtimes/sing-box/installation`、宿主发布源、签名目录和恢复状态。默认只显示稳定版；显式勾选后查询预发布。来源显示发布者、地址、指纹和信任状态；禁用或未确认来源、失效目录、配置不支持的版本不能用于新计划。手机仅使用已由宿主确认的来源，不提供任意 URL 或公钥输入。

未安装时提供安装；受管安装提供更新、同版本修复、已储存版本回滚和卸载（默认保留数据，删除数据单独选定）。外部安装、未知状态、查询失败或待恢复时阻止新计划，不自动接管。先预览宿主依赖和阻止原因，再确认包含精确 releaseId、状态／目录／信任修订及数据选项的冻结计划；提交完整不可变制品和原计划键至公共 Installations 台账，并复用宿主提权。目录刷新不会自动安装，修复不会标为更新。

结果不确定时锁住选择，同一页面内重试保留原计划、正文和幂等键。进程重建后可发现活动任务、按公共操作记录恢复，或显式核对当前事实后停止追踪未确认请求；不凭缺失响应推断成功，也不生成新键重试旧动作。运行中任务显示阶段与阶段进度，仅在服务器报告可取消且查询已确认时提供取消。取消结果以主任务终态为准。

待恢复事务显示操作 ID，提供重试与确认后的紧急停止；只有服务器已观测服务停止且无服务查询问题，并报告恢复失败时，才提供单独确认的事务关账。切换会话清空运行时选择，离开运行时页停止查询，服务器任务继续执行。签名来源准入、版本能力、撤销与补偿规则遵循共享受管运行时设计；Android 构建通过不代表真实跨版本和中断恢复验收已完成。

## 操作与会话

所有变更使用唯一 `Idempotency-Key`，202 表示已排队，随后按操作 ID 轮询到终态；离开屏幕停止轮询，已提交的服务器操作继续执行，页面重新进入后刷新即可看到结果。传输失败显示「结果未知」，不自动更换幂等键重发。

会话切换清空表单、导出内容、已签发 token、操作状态与已观测事实，旧结果不会写入新会话。

## 边界与验证要求

统计与流量日志在当前构建为「不支持」，界面显示该结论而不显示数字或零值；手机不做本地 VPN/TUN，不签发证书，也不管理宿主机防火墙。

订阅链接本身就是凭据：token 只显示一次，截屏、日志与工单中都不应出现。验证应覆盖入站五种预设与修订冲突、删除确认、二维码解码和秘密清除、受管运行时上的安装与升级、同版本修复、回滚、保留／删除数据卸载、目录失效及外部实例保护、发布与回滚、凭据轮换后的连接中断、到期凭据在发布前被拒、订阅撤销后匿名下载失败、观察者无写入入口、断网后不重复变更，以及三语与窄屏/平板布局。实现与文档不代表这些真机验证已执行。

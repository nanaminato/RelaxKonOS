# 应用内功能导航

Android 管理应用统一按“标题与返回按钮 → 分类栏 → 页面内容”排列，分类栏可横向滚动并固定在内容上方。Docker、任务管理器和设置由外层工作区显示标题，内页保留动作工具栏；标题的返回按钮使用当前内页的详情返回或未保存草稿离页处理，不重复显示内页标题。长列表和日志只滚动内容；手机使用单栏，现有宽屏列表/详情布局继续按可用空间展开。三种语言使用相同分类结构。

| 应用 / 追踪 | 当前分类 |
| --- | --- |
| Docker / PN-01 | 概览、容器、Compose、镜像、镜像源、宿主代理、网络、卷 |
| Mihomo / PN-02 | 概览、配置与订阅、节点、连接、日志、设置 |
| FRP / PN-03 | 概览、配置与隧道、运行时、日志、frps |
| Git / PN-04 | 工作区、分支、历史、冲突、构建 |
| Web 服务器 / PN-05 | 实例、站点、应用发布 |
| SMB / PN-06 | 概览、共享、用户；共享/用户按宿主能力显示 |
| 证书 / PN-07 | 概览、证书列表与详情、操作与恢复 |
| 应用部署详情 / PN-08 | 概览、版本、操作、日志、备份 |
| 任务管理器 / PN-09 | 性能、进程；按服务器能力显示 |
| 设置 / PN-10 | 外观、应用、连接、账户安全、宿主设置、服务器信息、宿主代理、诊断、帮助、关于 |

分类切换保留已访问面板的组合状态，包括未提交表单、当前资源、仓库或 FRP 配置。每个分类保留独立滚动位置；依赖 `rememberSaveable` 的状态可在 Activity 重建后恢复，普通内存草稿仍遵守原有生命周期，不承诺进程终止后恢复敏感字段。服务器或账户变化重建面板，领域 ViewModel 继续校验当前登录归属。

切换分类只改变展示，不提交操作，也不重新生成请求键或操作 ID。原有提权、危险动作确认、未知结果核实和编辑离页保护继续生效。安装、待核实请求和错误保留共同上下文；证书提供跨分类的操作入口，部署各分类显示当前活动操作。Docker 资源跳转到所属 Compose，保留所属工作负载；从恢复入口打开 Git 构建、网站应用发布或证书操作时进入相应分类。

隐藏面板不参与布局和无障碍内容。页面级返回处理仅在当前分类启用。任务管理器离开性能或进程分类时停止对应前台观察；切换设置分类替换当前设置页，不堆叠分类访问历史。手机从设置分类返回更多目录，平板继续使用目录与详情布局。设置顶部显示 Android 本机、远端宿主或 Android 与服务器连接范围；账户安全标识本机凭据管理，连接管理和诊断同时涉及两端，具体边界见各功能说明。

页面组织不代表新增领域能力；Git 独立远端管理、完整数据恢复等缺口仍按原功能计划追踪。执行证据与未关闭检查见 [页面对照](../status/PhoneNavigationParity.md) 和 [Verification](../status/Verification.md)。

# 应用内功能导航

已有顶部分类导航的管理页不再在内容区重复放置普通分类入口。Docker 概览/镜像源/记录页不重复引用宿主代理，资源页不固定放置操作记录按钮；SMB 与 FRP 的概览数量为纯状态展示，证书概览不重复放置列表/操作分类按钮。需要处理的未知结果/任务提示、资源所属 Compose 项目或应用详情等具体上下文入口仍保留。

Android 管理应用统一按“标题与返回按钮 → 分类导航 → 页面内容”排列。工作区可用宽度达到 `1000dp × max(1, fontScale)` 时，分类放在可独立滚动的 220dp 侧栏；更窄的工作区使用固定在内容上方的横向滚动标签。判断使用内容区域宽度，适用于分屏与自由窗口；大字体优先保留内容宽度。Docker、任务管理器和设置由外层工作区显示标题，内页保留动作工具栏；标题的返回按钮使用当前内页的详情返回或未保存草稿离页处理，不重复显示内页标题。长列表和日志只滚动内容；手机使用单栏，现有宽屏列表/详情布局继续按可用空间展开。三种语言使用相同分类结构。

分类切换保留已访问面板的组合状态，包括未提交表单、当前资源、仓库或 FRP 配置。每个分类保留独立滚动位置；依赖 `rememberSaveable` 的状态可在 Activity 重建后恢复，普通内存草稿仍遵守原有生命周期，不承诺进程终止后恢复敏感字段。服务器或账户变化重建面板，领域 ViewModel 继续校验当前登录归属。

切换分类先释放原表单的输入焦点、收起输入法，再改变展示，不提交操作，也不重新生成请求键或操作 ID。原有提权、危险动作确认、未知结果核实和编辑离页保护继续生效。安装、待核实请求和错误保留共同上下文；证书提供跨分类的操作入口，部署各分类显示当前活动操作。Docker 资源跳转到所属 Compose，保留所属工作负载；从恢复入口打开 Git 构建、网站应用发布或证书操作时进入相应分类。

隐藏面板不参与布局和无障碍内容。页面级返回处理仅在当前分类启用。任务管理器离开性能或进程分类时停止对应前台观察；切换设置分类替换当前设置页，不堆叠分类访问历史。手机从设置分类返回更多目录，平板继续使用目录与详情布局。设置顶部显示 Android 本机、远端宿主或 Android 与服务器连接范围；账户安全标识本机凭据管理，连接管理和诊断同时涉及两端，具体边界见各功能说明。

页面组织不代表新增领域能力；Git 独立远端管理、完整数据恢复等缺口仍按原功能计划追踪。执行证据与未关闭检查见 [页面对照](../status/PhoneNavigationParity.md) 和 [Verification](../status/Verification.md)。

## 应用目录与公共交互

管理入口使用可搜索的自适应应用卡片网格。搜索匹配当前语言的名称与说明，只在本地过滤服务器能力允许的应用，不发送请求或执行操作。网格最小列宽为 `240dp × max(1, fontScale)`；手机通常一列，宽屏自动增加列数。标题与搜索留在网格上方，卡片随列表滚动。

页面与分组标题提供 TalkBack heading 语义。公共列表行至少 56dp 高，名称最多两行，并向辅助技术暴露选择状态。指标进度提供范围语义，并将非有限读数按零展示，避免无效布局参数。界面 StateFlow 统一使用 lifecycle-runtime-compose 在 STARTED 期间观察；这只控制 UI 收集，不代表后台 SSH、传输或领域任务停止。

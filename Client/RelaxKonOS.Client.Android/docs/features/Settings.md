# 设置与应用管理

## 关于与开源许可

“我的 → 关于”展示客户端版本与平台，并提供“查看许可”入口。许可详情在应用内独立阅读页按组件分别展示仓库 `THIRD_PARTY_NOTICES.md` 的声明全文：项目许可、源码移植及其许可全文各自成卡，依赖表中的每个组件组单独展示名称、许可与用途，专项许可说明独立成卡。支持离线滚动阅读、选择与复制文字；页面返回按钮和系统返回均回到关于页。声明保留原文，不随界面语言翻译，入口与说明支持中、英、日三种语言。

Android 构建通过 `generateLicenseAssets` 将仓库的 canonical 声明文件打包到 assets，不维护 Android 专属副本。仓库声明更新后重新构建即可同步到应用。该页面显示现有仓库声明，不替代第三方依赖许可清单的维护。

许可阅读页仅在“关于”栏目可见时处理系统返回；切到其他设置栏目后，不拦截当前栏目的返回。再次切回“关于”仍保留许可阅读状态。

“我的 → 宿主设置”提供环境变量、时区和主机名；“我的 → 应用”提供当前 Android 客户端版本、系统应用设置与可用原生功能。既有账户/连接/外观/诊断页继续使用。桌面窗口、Shell 包和外部 .roapp 权限不复制到手机。

从宿主设置进入服务器 HTTPS 后，页面返回与系统返回回到宿主设置，宽屏详情区也提供返回入口。切换到其他设置栏目后，返回回到“更多”目录，不保留已离开的 HTTPS 子页栈。

诊断自检保留结果标识与参数，按当前语言显示；切换语言后无需重新请求服务器即可翻译已有结果。生成诊断报告时使用当时的语言，已生成的报告作为该次导出的快照保留。

诊断报告弹窗仅在诊断栏目可见时显示，隐藏栏目不会遮挡其他设置；返回后继续查看同一份报告与自检结果，不自动重新读取服务器。切换登录即清空旧自检和报告，即使当时诊断栏目隐藏，返回也不显示旧身份的报告。

连接记录优先显示完整服务器与账户身份。可用宽度不足时，切换连接、忘记密码和删除操作放在身份信息下方；布局断点随字体缩放调整，避免大字体下操作区挤压待操作的目标。

账户安全页的连接凭据、提权凭据与调试凭据记录采用相同布局规则，窄屏时删除操作位于身份信息下方，记录失效提示仍与身份一起完整显示。

账户安全页重新显示或恢复前台时重新读取凭据与静音提醒列表；隐藏或退到后台撤销关闭指纹、清空凭据和删除单条凭据的旧确认，再次操作须重新确认。平台信息只在当前栏目可见且处于前台时解析。

指纹主开关整行提供一个开关操作与当前状态，右侧开关仅呈现状态；说明随字体大小换行。关闭仍须确认清理凭据，确认失败保留重试入口。

高对比度与静音提醒设置同样使用整行开关，文字和右侧标记共享一个操作节点。出站代理的开关整行可点，忙碌或不允许修改时整行禁用。

连接记录页同样在隐藏、退到后台或切换登录后撤销忘记密码和删除记录的旧确认，重新显示时重读连接列表。单条调试凭据删除固定到打开确认时的服务器与账号，后来被其他身份替换的记录不会被该确认清空。

连接记录页忘记密码或删除的本地存储操作失败时保留原确认与目标，在确认框内显示脱敏失败提示，允许重试或取消；只有操作成功才关闭确认，不显示原始异常内容。

账户安全页关闭指纹、清空凭据和单条删除也只在本地操作成功后关闭确认；失败后重读记录并在确认内提示部分变更可能已生效，允许完成清理或取消。偏好已经关闭但清理失败时仍保留本次确认的重试入口。其他本机设置操作失败显示脱敏反馈，不显示成功提示。

## 宿主设置

每次读取、预览和变更的错误反馈按独立请求标识显示。关闭提示后再次请求，即使相同错误立即返回且中间没有界面重绘，也重新显示本次失败；关闭提示不恢复旧事实或提交资格。

| 项目 | 当前行为 |
| --- | --- |
| 时区 | 读取远端当前 ID、完整支持 ID 列表、内容 revision、provider 与观察时间。当前值按“时区 ID、UTC 偏移、生效方式、服务器读取时间”成组展示：偏移按远端上报时刻计算，读取时间按手机本地时区格式化，ID 不再要求用户自己换算。时区 ID 字段实时校验并在非空时提供清除入口：ID 不在远端支持列表内时字段直接标错并说明预览不可用，而不是只留下一个禁用的按钮。空查询不做搜索，只列出常用项（远端当前 ID、本机时区、零偏移 ID；去重，且限于远端支持的 ID）；有输入时按“精确 ID → 前缀 → 城市段 → 包含”排序筛选，最多 12 项，超出时提示仅显示前 12 项。建议列表限高后内部滚动，每个 ID 带 UTC 偏移，并标记远端当前值与手机本机时区；不再把预览与应用按钮挤出屏幕。字段下方的“从完整列表中选择”打开独立选择弹窗：按 IANA 地区分组列出远端全部支持的 ID（空组不显示，无 `/` 或不认识的地区前缀归入“其他”），弹窗内搜索与字段筛选同排序但不受 12 项上限限制，每行同样带 UTC 偏移与“服务器当前/本机”标记，选中即回填字段。只能预览当前远端支持的 ID。没有设置宿主时钟或同步手机时区的按钮。 |
| 主机名 | 展示生效名称与待生效名称，按远端上报的长度限制校验单个标签。Windows 的更名可能等待宿主重启；页面展示其生效规则，不自动请求重启。 |
| 环境变量 | Linux 仅 HostMachine；Windows 同时展示用户变量与系统变量两个可独立滚动的列表，分别读取 HostMachine 与当前认证用户映射的 HostUser；每组提供新建、编辑、删除。授权失败按组展示，不隐藏已成功读取的另一组。先查 target，不从手机猜 SID/UID。进入环境变量、切换作用域或刷新时直接请求完整值；权限不足立即弹出统一提权窗口，可通过指纹等解锁已保存的管理员密码。授权成功后立即显示所有变量的完整值；验证失败或取消后显示“需要授权”及“再次申请权限”按钮。显示名称、原始/展开值、警告、观察时间及作用域，不限制为 100 项。 |
| 环境编辑 | Linux 进入时显示变量名称与完整值，点击 PATH 或其他变量进入独立编辑弹窗；Windows 先选中列表中的变量，再进入同一编辑弹窗；已有变量名称只读，新建可填写名称，普通变量使用多行原始值文本框。删除有独立确认流程。一次预览一个变量；Set 的空字符串与 Delete 分开。Windows 可选“展开值中的环境变量引用”（ExpandString，例如 `%USERPROFILE%` 替换为用户目录），Linux 仅 String。名称、Unicode、值长度、UTF-8 预算与高影响名称按共享规则门控；高影响变更沿用最终预览/提交确认，不再增加额外确认勾选框。Linux 与 Windows PATH 共用分项列表与选中项编辑框，按远端 pathSeparator 拆分与重组（Linux 为 `:`，Windows 为 `;`），Linux 名称匹配区分大小写；窄屏操作按钮位于列表下方，宽屏位于右侧。新建、删除、上移、下移均更新完整值，上下移动后保持选中原条目并滚动至可见位置，重复值与空项保留。编辑弹窗保留取消/预览按钮，预览确认后提交，应用或回滚结束后重新读取当前平台的变量列表。替换完整值，不执行 shell 展开，不进行隐式 PATH 合并。 |

三类宿主设置的事实行统一把生效方式写成“生效方式：<生效值>”，观察时间统一按手机本地时区格式化后展示，不再直接显示协议时间戳原文。时区建议的常用项、排序规则、UTC 偏移标签与选择弹窗的地区分组与全量筛选集中在 `HostTimeZoneChoices`，由独立 JVM 测试覆盖。

预览提交当前 revision 与一次性 idempotencyKey；服务端生成带精确目标、差异、生效时间、所需 capability、authorizationTarget 和五分钟期限的计划。环境变量预览仅显示配置存在性，不显示值。用户确认后仅发送原 planId；Server 在授权和内容 revision 再校验后执行。

回滚先读取原操作，核对 observedRevision，并使用原 ID/版本；外部变更不被覆盖。应用和回滚均沿用当前精确目标授权，只在明确的授权拒绝后重试原计划一次，不对传输失败自动重放。应用或回滚结束后，客户端在同一次忙碌期内直接重新读取当前 kind 的事实行并回填字段（不再清空事实行等用户手动刷新）：写入成功后的重新读取失败按读取问题提示，不误报为写入结果未知；操作本身的状态仍以“变更记录”里的操作记录为准。

Settings 错误响应现在包含稳定 problemCode 扩展；Android 不解析 title 作为契约代码。HTTP 枚举按生产共享选项使用 camelCase；Android 不加入 PascalCase 或旧字段回退。

## 操作恢复与页面生命周期

收到成功写入回执后，后续主机信息刷新异常显示读取错误；不会把已收到的写入回执重新分类为结果未知。仍未收到写入回执时，意外异常按结果未知处理并保留核实门禁。

应用前在 noBackupFilesDir 持久保存 serviceId/account、kind、原 planId、target、期限与 unresolved 标记。不保存环境值、差异内容、密码或令牌；最多 100 个跨登录引用，页面展示最近 20 项。相同宿主/账号再次登录可查询原操作；别的账号不显示该引用。

操作回执丢失、取消、离页、进程回收不清除原提交标记。存在未确定操作时，新的宿主设置变更被阻断。查询校验 ID、target 和 settingId；仅 Applied/Failed/RolledBack 的权威终态解除门禁，Unknown/RecoveryRequired/PartiallyApplied 保持阻断。

没有自动修复或假成功按钮。Server 在跨进程锁内将过期 Prepared 计划持久转为 Failed/settings.plan_expired；延迟 apply 随后只能读取 Failed，不会写宿主。手机时钟不能单独证明计划已经过期或解除门禁。

页面仅在 RESUMED 发起读取；离页/后台取消请求、清除揭示值和草稿，旧登录回执不更新新页面。初次普通读取不弹环境授权；用户点击“授权读取”后才请求，读取后直接显示所有变量值。预览和回滚确认面板有固定按钮与有界滚动，手机/平板共用内容。返回丢弃未提交草稿需确认；当前实现不提供跨进程草稿恢复。

设置工作区切换到其他栏目或 HTTPS 子页同样视为离页：宿主设置撤销前台读取，清理揭示值、未提交草稿与临时确认；隐藏栏目不显示弹窗。再次选中宿主设置时重新读取当前类别，已提交操作的恢复引用仍由持久记录保留。

## 应用管理范围

当前客户端显示真实 BuildConfig 版本与 Android packageName。系统设置入口仅发送固定 ACTION_APPLICATION_DETAILS_SETTINGS + 当前应用包；Android 决定权限、存储清除和卸载。清除 Android 存储会丢失连接与凭据，不删除远端宿主或桌面包数据。页面不自行卸载应用或清空保险箱。

内置功能随签名客户端更新，没有独立包版本/权限决策/卸载。原生目录仅链接已交付功能，按当前 Server capability 决定可用项，并在点击时复核原登录会话；capability 不等于授权。远端容器/修订/运行时仍在各领域页面管理。外部 .roapp 的安装、权限、私有数据、更新与移除由目标桌面处理，当前 Android 没有第三方运行时或其 app-settings 数据目录；详见 [移动包方案](../design/ApplicationPackages.Design.md)。

变更记录仅展示当前设置类别的最近 20 项；没有记录时隐藏标题。跨类别未确定操作仍统一阻止新提交，保留查询与回滚能力。

刷新开始时撤销旧的可编辑快照；读取失败或取消后须再次读取成功才能预览。应用或回滚被取消时，页面显示结果未知并同步仓库记录的原操作 ID，允许查询该操作，禁止直接再次提交；取消继续传播。离页或失效登录不发布取消反馈。

有未保存编辑时，返回与“服务器 HTTPS”入口均先确认放弃；确认后前往用户原先选择的目标。取消保留草稿并清除待执行跳转，后台/离页使旧确认失效；重复确认不得重复导航。

## 使用记忆

“我的 → 账户与安全 → 使用记忆”可清除当前服务器下当前登录账户的使用默认值；未登录时清除本机未登录上下文的选择位置。已保存的登录、SSH 和提权密码不受影响。

`UsageMemoryStore` 在设备私有 SharedPreferences 保存最后一次成功提权的管理员用户名，以及各用途最后确认的文件选择位置。管理员用户名按稳定 serviceId 和用户名称隔离，宿主与文件提权共享；只在服务器确认 elevated 后更新，取消、拒绝或传输失败不覆盖。提权对话框可编辑用户名，已填用户名时优先聚焦密码；用户名记忆不依赖开启指纹保险箱，密码保存仍遵守原有显式授权和生物识别规则。

选择位置按账户、用途和本地/远程分开；远程位置另外按 workspaceId 隔离，SSH 包选择按 hostId 区分。明确填写的初始路径优先于记忆；确认文件时记住父目录，确认目录时记住所选目录，浏览和取消不更新。远程恢复使用拒绝自动提权的 provider；记忆目录失效或无权限时回到根位置。账户/会话切换后的延迟结果不回填，清除后的旧交互不重新写入记忆。

本地选择器沿用 Android Storage Access Framework。文档提供程序的 document ID 是不透明标识，不能像磁盘路径一样推导父目录；因此保存最后确认的文档或目录 URI，通过 `DocumentsContract.EXTRA_INITIAL_URI` 提示系统恢复选择位置，不申请额外目录权限。

实际目录展示与失效提示由系统/文档提供程序处理。覆盖上传、包/证书/密钥/Compose 导入、配对图片和诊断导出。规则依据 [Android 文档](https://developer.android.com/training/data-storage/shared/documents-files)。

重启后恢复使用记忆，不随 Workspace 同步；应用已禁用 Android 自动备份，因此不会通过系统备份迁移到其他设备。读取损坏或保存失败不阻断当前操作。测试与未关闭设备检查见 [验证要求](../development/Verification.md)。

## 终端外观契约

Workspace 终端设置包含 `scrollbackLines`（0–100000 整数）、`cursorStyle`（block/underline/bar）和 `cursorBlink`（布尔）。Android 解析当前契约，并在修改字体或配色时原样保留这些字段；当前手机终端界面不提供这些桌面渲染偏好的编辑控件。设备级桌面终端边距及注册表布局使用登录客户端的 Device 范围，不影响手机布局。契约验证覆盖字段必需性、类型、数值范围、配色修改后的字段保留和 HTTP 往返。

## 账户安全危险确认

关闭指纹并清理凭据、清空全部凭据和删除单条记录的确认均使用独立的一次性令牌。执行前核对当前页面仍附着、栏目可见、Activity 实际处于 RESUMED、当前控制器和登录身份未变；隐藏、后台、关闭及重新打开后，旧确认回调不能执行。一次确认在清理开始前消费，重复回调不能清除后来保存的凭据。部分失败保留原清理意图并显示脱敏原因，但重试使用新确认令牌，旧回调不能作为重试。普通使用记忆清理与提醒恢复也只接受当前可见前台页面的操作。

登录归属检查在点击时直接查询账户安全控制器的当前会话，不仅依赖上一帧 Compose 参数。即使真实登录已变化、页面尚未重绘，旧确认也不得清理凭据或清除新身份的使用记忆。

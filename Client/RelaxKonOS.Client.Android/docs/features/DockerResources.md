# Android Docker 资源管理

提交前实际状态复核忽略容器相对运行时长、镜像相对年龄及集合返回顺序，避免仅时间流逝阻止提交；资源身份、名称、镜像、运行状态、详情所有权、挂载和引用变化仍要求重新核对。

## 1. 列表与详情

Docker 工作区保留用户选中的栏目和 Compose 目标，配置变化或已保存的界面状态恢复不会重新套用初始概览。新的入口栏目或 Stack 请求仍切换到对应目标。

按 `server.docker` 和当前 serviceId/账户读取 Server 的容器、镜像、网络和卷。Engine 不可用时集合保持未查询，不显示为成功空列表；任一集合读取失败不形成可写快照。观察者可以读取，不显示写入按钮。

容器详情保留创建时间、命令、工作目录、重启策略、端口、挂载、网络、环境和标签。短列表 ID 与完整 inspect ID 核对十六进制前缀。选中运行中容器时每三秒读取 CPU、内存、网络与磁盘统计；日志按需读取末 200 条，合并容器 stdout/stderr；Server 有限尾部及 512 字符行裁剪明确显示截断。关闭 Docker 工作区、注销或切账号取消本机读取并清除显示，不改变远端容器；栏目隐藏和后台行为见下文。环境、命令、标签及日志须显式显示；创建草稿仅保留在当前页面内存。

容器列表与详情对 created、running、paused、restarting、removing、exited、dead 显示中英日本地化状态；未知值标为未知并保留原值。服务端额外状态说明原样保留，完全重复状态码的说明不重复显示；镜像、名称和远端输出不作为本地化文本解析。

网络详情含连接容器和共享 Protocol 当前必需的 `labels`；卷详情保留标签、挂载点及运行/停止容器引用。标签判定使用 `relaxkonos.*` 和 `com.docker.compose.*` 保留前缀：资源写入停止，已有 Compose 项目返回 Stack，匹配应用归属和部署 capability 时返回应用页；未知保留标签也保持只读。独立创建不允许伪造这些标签。镜像当前没有 inspect/引用契约，删除影响由明确提示和 Docker 实际拒绝结果呈现，不伪造镜像引用表。

容器统计只在对应栏目可见、Activity 位于前台且没有编辑或确认时自动观察。等待结束后再次核对原登录、原容器 ID、读取代次和前台资格；新读取使旧间隔失效，相同统计响应仍继续按间隔读取。暂停和恢复直接更新观察标记，不依赖中间发生重绘；恢复后继续原容器的读取。读取失败暂停自动观察，已开始的读取可完成，不触发任何资源写入。

## 2. 写入任务流

资源变更确认绑定原登录、列表事实、详情目标和操作，每次确认只能消费一次。刷新、切换目标、暂停、隐藏、离页或关闭后旧回调失效；同账号重新登录后的相同资源也不能复用旧确认。旧关闭按钮或外部关闭回调不能撤下重新打开的确认，生命周期撤销仅影响原登录的确认。切换强制停止/删除选项生成新确认，旧选项回调不能修改新确认或复活已关闭确认。提交前模型再次核对当前登录与原事实/目标；仓储仍按远端实际状态完成预检。

每次打开资源创建或重命名编辑器都有独立身份。字段、关闭与审查回调核对当前编辑、原登录和前台代次；审查另核对明确点击时的草稿快照。关闭或丢弃后，旧字段与旧审查不能影响新草稿；修改输入后需使用当前审查入口，旧按钮不能确认旧内容。暂停、隐藏再恢复保留内存草稿，旧字段、开启、关闭及审查回调失效，当前入口仍可继续编辑和提交。

放弃确认固定原草稿、编辑身份和原导航，只能消费一次。旧继续编辑、放弃或外部关闭回调不能消费后来重新打开的决定；明确放弃才清除原草稿并执行原导航。变更忙碌或变更确认期间，旧编辑回调不能修改输入或创建其他决定。进程回收仍不恢复草稿及正文。

- 容器创建完整发送名称/镜像/逐行参数、端口、环境、挂载、网络、重启策略、标签以及 CPU/内存字节/PID/日志驱动与选项。客户端与 Server 当前界限一致；空可选字段保留 Docker 默认值。仅创建，不自动启动。
- 容器支持重命名、启动、停止、重启、暂停、恢复和删除。重命名只 PUT 名称，不隐式重建。暂停/恢复依据已读状态；停止可明确选择零宽限时间，删除可明确选择强制移除运行容器。每次执行有冻结目标确认。
- 镜像支持拉取及按完整 Engine ID 删除；使用当前账户镜像源和 Server 的既有出站消费路径。`sha256:` 加 64 个十六进制字符直接进入 Server 删除校验。
- 网络支持驱动/名称创建、详情和删除；builtin bridge/host/none 及已有容器引用禁止页面删除。Server Engine 仍决定实际删除结果。
- 卷支持名称/驱动/标签创建和删除。运行或停止容器引用都阻止删除；删除永久移除卷数据。Server 引用读取失败返回 503 并禁止继续 rm。

600dp 以上列表和详情/编辑两栏，窄屏纵向排列；表单保留 IME 空间。同页切换资源类型、刷新、选择另一资源和返回先确认丢弃草稿。Docker 工作区切换栏目保留草稿，隐藏栏目或退到后台撤销尚未提交的执行及放弃确认，并重新遮盖敏感详情；返回后须重新审阅确认，不执行旧跳转。英文、简体中文与日文资源同步维护。

失败反馈只在对应资源栏目可见时显示；隐藏期间到达的失败不遮挡其他栏目，返回后仍可查看原因。关闭提示不会恢复旧事实或写入资格，须显式刷新核实。

## 3. 事实复核与未知结果

`DockerMutationGate` 串行化原生引擎/镜像源、独立资源以及 Compose 部署/生命周期提交。存在同步未知标记、Docker 安装原请求未核实，或公共安装活动查询失败/存在活动任务时，禁止新的写入。Docker 安装页面提交也使用同一锁并复核资源/控制未知标记。

执行前读取全部列表和目标详情，比对操作人刚确认的事实；每次 401 拒绝后的认证重试再次比对。列表或所有权/引用/状态变化返回事实冲突。当前 REST 没有原子 revision/CAS；预读不能代替服务端原子并发控制和真实宿主验收。

同步资源结果直接使用 `success/problemCode/logLines/logTruncated`，没有任务 ID、取消或幂等键。请求发送前记录本机 `docker-resources.bin` 未知标记，只有 serviceId/账户/action/既有目标/本机 UUID；不保存创建名称、命令、环境、挂载、镜像请求或正文。失败、断线和成功后事实回读失败均保留标记；再次读取不会重放。只有成功且可达集合回读后自动清除，或用户核对可达事实并显式采纳后解除阻断。采纳不宣称原请求成功。

运维中心聚合原标记并返回本页；引擎/镜像源未知记录仍返回 [引擎管理](DockerEngine.md)。Compose 保留既有持久操作、原 ID 查询和取消路径，见 [Docker 与 Compose](DockerCompose.md)。

当前会话读取或提交被取消后，撤下旧事实、目标详情、统计、日志及旧操作结果，保留待核实写入标记。显式刷新可恢复事实，但不自动解除未知写入门禁。采用事实直接呈现该次核实结果，不额外读取以掩盖失败。

资源写入回执、一次后置核验和本地恢复记录分别处理。页面直接采用仓库返回的该次事实，不追加读取；成功回执先关闭已提交的创建/编辑草稿，再处理事实和记录故障。核验异常或当前协程仍有效时的核验取消不丢失操作结果及日志；后置事实不可用时保留原标记和禁写状态，本地清理失败另行提示，不重放原写入。

只读刷新、其读取取消及显式采用当前事实不会清除已知操作回执。开始新的写入前撤下上一笔结果，选择另一资源时按当前选择清理原详情。记录页按宿主回执分别展示成功/失败，并将待核实门禁另行说明；存在标记不代表已收到的成功回执变成未知。重复立即失败使用新的反馈事件，关闭旧提示不会压住本次失败。

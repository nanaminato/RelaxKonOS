# Squid HTTP 代理网关

管理页的 Squid 应用控制已连接 Linux 系统模式服务器的 HTTP/CONNECT 入口。入口要求登录描述符声明 `server.gateway-proxy`，与 Mihomo 应用分开。服务器报告支持包管理时，可在概览页确认安装或卸载发行版 Squid 软件包。

## 配置与服务

概览页显示运行状态、开机启动、期望与发布修订、磁盘配置匹配状态及恢复提示。主页面保留状态、入口摘要和账号列表；点击编辑配置、编辑访问模式或账号条目，在可滚动弹窗内修改。表单支持监听 IP、端口、远程客户端开关、来源 CIDR、域名允许/拒绝列表，以及可选的 HTTP parent 主机与端口。列表每行一项，支持逗号分隔；上游主机留空代表直连。来源网段和域名语义以共享 [Squid 文档](../../../../docs/proxy/squid.md) 为准。

首次读取使用服务器最后提交的结构化配置；尚无记录时使用 loopback 默认值。刷新仅更新服务器事实，不覆盖正在编辑的表单。“载入已保存配置”显式替换表单，有修改时先确认。离开页面或关闭编辑前提示丢弃未提交修改。配置弹窗内可预览、校验和应用；诊断也保留在配置页。关闭配置弹窗保留当前本地草稿，不自动提交，关闭账号弹窗清空密码；应用完整配置前显示替换与接管确认。应用不会自动启动已停止服务。

提供 start、stop、restart、reload、enable、disable。恢复标记存在时禁止应用和启动、重启、重载、启用，只保留停止、禁用和独立校验。非受管配置必须由用户勾选接管；不会合并已有 include、认证、缓存或其他手写指令。观察者只读，控制者且服务器允许特权操作时提供写入操作，最终授权由服务器检查。

## 操作与会话

应用和服务动作使用唯一 `Idempotency-Key`，202 表示已排队，记录页轮询操作直到终态。请求正文、原请求键和已取得的操作 ID 按服务器、账户与工作区保存在 Android 的 no-backup 私有目录，使用 Android Keystore AES-GCM 加密并将会话文件身份绑定为认证数据。账号密码不以明文写入该目录；无法解密时阻止新变更，不自动删除或重发。传输失败或进程重启后显示待确认操作，由用户选择继续；重试复用原正文和原请求键，不生成新变更。明确的排队前拒绝和已确认终态清除待确认记录。等待超过轮询窗口后仍保留记录，继续查询不会重新创建操作。

会话切换取消旧任务并清空旧表单和状态，旧结果不能更新新会话。不同账户或服务器的待确认记录隔离。离开屏幕停止轮询，已提交的服务器操作继续执行。未提交表单不跨进程保存。

## 边界与验证要求

磁盘摘要匹配上次发布记录只说明文件一致，不证明 Squid 运行时加载或端到端 HTTP/CONNECT 已成功。主机恢复按共享文档执行；Android 不删除恢复标记。日志、TLS 解密、透明代理、磁盘缓存及防火墙联动不在此应用能力内。

验证应覆盖真实 Linux Server/Helper 上的预览、原生诊断、完整替换确认、受管/非受管配置、停止状态发布、六种服务动作、恢复阻断、观察者权限、断网后原键重试、进程重建恢复记录、会话切换及窄屏/平板与三语布局。实现和文档不代表这些 Android 验证已执行。

## 软件包与访问控制

状态必需字段 `packageManagementSupported` 与 `supported` 独立：只有服务器支持、状态已知、无恢复标记且有控制和特权权限时才提供包管理。未安装时可安装，已安装时可卸载，二者先确认，再使用相同操作台账与原键恢复流程。安装采用服务器固定发行版仓库和 Squid 包；发行版脚本可能启动默认服务，完成后应检查状态并预览配置。卸载停止并禁用服务，使用 remove，保留配置、账号文件与服务端草稿，不执行 purge 或 autoremove。不提供版本选择、跨版本更新、同版本修复、回滚或发布源管理；包所有权与完整受管生命周期仍受 MR-06 边界限制。

访问控制页选择 `ipWhitelist`、`password`、`passwordAndIpWhitelist`，提供独立代理账号列表、创建、重置密码、启用／禁用及删除确认。用户名为 1–64 位字母数字、点、下划线或连字符，首字符为字母数字；密码 8–128 位且不含控制字符。密码输入隐藏，提交后清空，不跨进程保存表单。需要密码的草稿或已保存配置会保护最后一个已启用账号；无可用账号时阻止发布密码模式。服务器仍执行最终授权、校验和事务保护。Basic 认证不会加密代理链路上的密码，界面提示使用可信网络或安全隧道。

验证要求还包括三个访问模式、账号 CRUD 与最后账号保护、原键重试与加密待确认记录恢复、软件包能力门禁、安装／卸载确认与配置保留。Android 编译和单元测试不代表这些真实 Linux 主机及 Android 设备流程已验收。

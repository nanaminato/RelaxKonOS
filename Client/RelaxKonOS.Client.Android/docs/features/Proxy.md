# Mihomo 代理管理器

权威运行时状态为未安装时显示一条安装引导，隐藏归档完整性、控制器不可用和节点区的重复诊断；订阅与配置仍可查看。安装入口使用“安装 Mihomo”，历史任务查询收在“恢复之前的操作”后。现有任务、未知写入和安装回执不因未安装空状态被隐藏；已安装但校验失败仍展示诊断。

对应 BP06-M1/M2，入口为“管理 → Mihomo 代理管理器”，按 `server.proxy` 能力显示。观察者只读取；宿主变更要求管理权限。此页管理服务器运行时和网络，手机不运行 Mihomo，也不提供手机 VPN。

## 运行时和任务

安装、升级、修复、回滚与卸载使用公共 Installations 数据层及确认/提权流程。安装支持宿主下载固定可信版本、服务器归档限时引用、手机 SAF 选包后受控上传；包与哈希由服务端校验。升级和修复从宿主下载，回滚通过 Repair 的 rollback 标记读取前一版本。表单检查可信版本，不把任意路径传入安装请求。变更可能停止代理并中断管理连接，确认后提交。

Start/Stop/Restart 使用 Proxy 操作账本。只显示从宿主读取的任务状态，不用提交成功推断运行时健康。Proxy 操作没有取消端点；安装任务仅在最新宿主状态允许时提供取消。离页停止页面观察，宿主任务继续执行；重新进入查询本地索引中的原任务 ID。索引与请求标记按宿主和账户隔离，注销、换宿主或身份后旧响应不能覆盖新会话。

首个响应丢失时，Proxy 队列请求保留原键、动作和目标 ID，显式重试先读取宿主事实再使用原键，不自动重发。接收 ID 后先持久化索引，再查询状态；查询失败仍可按该 ID 恢复。安装使用既有原键/ID 恢复机制，无法证明未知请求归属时须确认确切原 ID。

## 配置、订阅和节点

配置列表可创建、重命名、删除非活动配置、激活已存 YAML，名称更新携带 ExpectedRevision。页面提供完整新 YAML 的校验/应用表单；服务端不提供普通配置 YAML 读取，所以此表单不预填原文。草稿仅在内存保留，关闭有未保存确认。配置加载健康后才更新活动标记；校验失败保留活动配置，重载失败尝试回滚，无法恢复时返回恢复问题码。

订阅来源由用户输入，支持宿主直连或宿主系统代理下载；后者按下载能力启用。来源 URL 在服务端加密，列表不返回来源 URL；本地请求标记不保存 URL、YAML 或节点名称。导入、单项/全量刷新及激活通过当前 API，活动订阅刷新由服务端重新应用配置。

控制器可达时读取 Rule/Global/Direct、代理组与当前节点。仅 Selector 组可手动选择，选择请求和延迟请求分别编码 Unicode/空格/斜线等不透明名称。延迟测试从宿主使用 5 秒超时访问 `https://www.gstatic.com/generate_204`，显示毫秒或超时，不作为手机联网质量。

同步写入无任务 ID/幂等键。响应未知时持久化不含秘密的动作类型/目标标记并锁定新写入；普通刷新不自动清除标记。用户检查宿主事实后显式接受当前状态，选择/路由还须成功读取对应控制器状态。接受当前事实不宣称原 YAML 或导入请求已成功。

## 布局与验证

手机配置列表与详情切换；可用宽度至少 600dp 时显示配置列表/详情双栏。表单滚动并避让 IME，中文/英文/日文文案同批维护。安装与代理操作接入运维中心；Proxy 任务不能显示无效取消入口。

## 宿主网络与诊断

宿主网络页读取完整 Mihomo 设置、TUN 状态与持久恢复标记。TUN 启用按平台支持、控制器可达、管理路径安全、活动配置与无遗留标记门控；启用/关闭走原键 Proxy 操作，服务端观察真实远端地址并保存管理路径保护快照。紧急关闭不依赖控制器健康或普通写入已核实，可另存独立恢复键，同时保留先前未知请求；恢复响应丢失后可用原键再次请求，不要求概览先恢复健康。页面会展示原任务 ID/待核实，不把断线当作 TUN 已关闭。

系统代理按 Windows 宿主门控。设置编辑覆盖混合端口、监听地址、LAN、DNS、IPv6、统一延迟、不安全订阅来源、日志级别、TUN stack/device/MTU/自动路由/严格路由/接口检测/DNS Hijack，以及 Windows PAC 自动检测/代理守护/间隔/默认与自定义绕过。更新完整当前对象；修改其他字段保留 TUN 会话由服务端负责，设置保存不会隐式启用 TUN。同步响应未知时须读取当前设置再接受事实。

诊断读取流量速率/累计/内存、连接/DNS 状态与最近 100 条服务端有界脱敏日志；页面在宿主网络页可见、控制器可达且上次样本可核实时每 3 秒采样，离页或读取失败即停止自动观察。连接按能力显示，最多展示 200 项并标记截断；关闭连接需要确认。日志与 DNS 按引擎能力门控。GeoData 由服务器文件选择器选择服务账户可读文件，服务端校验暂存，仅返回配置标记与字节数。上述行为全部作用于宿主，手机不提供 VPN。

受管出站来源与 Docker/下载消费仍由独立宿主出站设置拥有，见 [宿主出站代理](OutboundProxy.md)。真实宿主联网、设备交互与安装验收独立记录于 [Verification](../status/Verification.md)。

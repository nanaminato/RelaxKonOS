# 帮助与使用引导

登录页可打开全屏帮助，首页和“更多”也有帮助入口。原生 Compose 内容随客户端提供英文、中文、日文；手机/平板使用同一滚动页面，支持大字体换行，不依赖桌面窗口或 help:// 包运行时。

帮助涵盖 Server 连接、SSH 主机密钥与凭据保险箱、Windows 设备配对、运行时安装、应用部署、操作恢复和外部服务访问。

服务器中心通过已核验的 SSH 会话执行安装、升级、修复与卸载，支持三种安装来源。操作成功需同时核实原操作回执和宿主健康状态。离页观察、上传恢复、登录回填与回退界面仍有覆盖限制，见 [服务器中心](ServerCenter.md)。登录后可进入已实现的运行时管理器。

登录前只展示引导和现有服务器中心入口。登录后，任务说明/按钮使用 `MobileFeatureCatalog`；仅链接已实现且当前 capability 支持的原生路由，点击时复核登录与能力。手机切到正确顶层导航再打开任务；平板“更多”中的设置链接更新详情 pane，管理链接离开“更多”进入对应领域。不会自动发起安装、修改或提权。

已有帮助来自 `examples/HelpCenter/content/` 的三语 Docker 安装/移除文档，页面通过固定项目仓库地址在外部浏览器打开。此链接是现有指南源，不创建第二份详细移动文档；仓库访问可能需要浏览器账号。桌面步骤需要用户在相应桌面/宿主执行，不能据此认定 Android 支持桌面扩展，也不代替服务器中心的独立安装核实。外部浏览器不接收客户端 Authorization/Cookie/密码，沿用 [服务访问](ServiceAccess.md) 的隔离规则。

应用管理与帮助共用功能目录。目录决定入口是否可用，服务端逐项检查操作授权。当前没有额外欢迎应用、注册表应用或内置浏览器。

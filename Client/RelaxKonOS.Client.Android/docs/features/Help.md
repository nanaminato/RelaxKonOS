# 帮助与使用引导（BP23）

登录页可打开全屏帮助，首页和“更多”也有帮助入口。原生 Compose 内容随客户端提供英文、中文、日文；手机/平板使用同一滚动页面，支持大字体换行，不依赖桌面窗口或 help:// 包运行时。

内容说明已有 Server 的连接、SSH 固定主机密钥与保险箱、Windows 设备配对、运行时安装与应用部署区别、回执丢失的原操作恢复，以及外部服务访问和 SSH 转发停止。明确指出手机服务器中心尚缺 Server 首次安装/修复/卸载，不将 AD01 草稿选择当安装成功。安装 Server 的用户先使用宿主部署流程；登录后进入已交付运行时管理器。

登录前只展示引导和现有服务器中心入口。登录后，任务说明/按钮使用 `MobileFeatureCatalog`；仅链接已实现且当前 capability 支持的原生路由，点击时复核登录与能力。手机切到正确顶层导航再打开任务；平板“更多”中的设置链接更新详情 pane，管理链接离开“更多”进入对应领域。不会自动发起安装、修改或提权。

已有帮助来自 `examples/HelpCenter/content/` 的三语 Docker 安装/移除文档，页面通过固定项目仓库地址在外部浏览器打开。此链接是现有指南源，不创建第二份详细移动文档；仓库访问可能需要浏览器账号。桌面步骤需要用户在相应桌面/宿主执行，不能据此认定 Android 支持桌面扩展或首次安装。外部浏览器不接收客户端 Authorization/Cookie/密码，沿用 [服务访问](ServiceAccess.md) 的隔离规则。

应用管理与帮助共用已交付功能目录，目录只决定路由可用性，远端端点仍负责每项动作的授权。当前没有额外欢迎应用、注册表应用或内置浏览器。

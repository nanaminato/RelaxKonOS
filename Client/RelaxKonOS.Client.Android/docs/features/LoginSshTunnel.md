# 登录页 SSH 隧道

登录页在服务器地址下提供“通过 SSH 隧道连接”。服务器地址指 SSH 主机自身的 `localhost` 或 `127.0.0.1` HTTP(S) 服务，例如 `http://127.0.0.1:5000`，当前不支持反向代理子路径或跳板机。这个复选框表示**当前所选身份的传输方式**，不是会余留的独立开关：从连接管理选择直连或设备密钥记录时它被关掉，选择 SSH 记录时被打开；否则一次设备密钥登录会带着上一次的隧道去发请求，落在一个装不下该密钥的服务身份上。

登录页使用独立的纵向滚动视口，品牌、设置入口与登录表单一起滚动。展开 SSH 配置后可滑动到连接按钮；视口为系统安全区域和输入法保留空间，键盘弹出后仍能滚动访问表单。

配置 SSH 主机、端口（默认 22）、SSH 用户名，以及密码或粘贴的 PEM/OpenSSH 私钥与可选口令。SSH 身份验证与 RelaxKonOS 账号分别填写、分别保存。首次或主机密钥发生变化时必须核对指纹；没有接受指纹时不会进入 SSH 身份验证或发送 Server 登录凭据。

配置中可勾选“SSH 使用与 Server 相同的用户名和密码”，仅适用于密码认证。启用后隐藏独立 SSH 凭据输入及保存开关，使用下方 Server 保存开关。共用密码仅写入连接保险箱，登录成功后保存只验证一次指纹；下次连接先解锁该密码一次，在同一连接操作中用于 SSH 和 Server，不再进入 SSH 保险箱或重复解锁。手动密码优先，取消指纹授权不发起连接；没有可用的共用密码时提示填写。测试连接也可使用同一保险箱，但不会保存共用密码或登录 Server。临时认证数组在使用后清零，保险箱密码不会回填到表单。

共用模式作为非敏感配置随隧道记录保存并在选择时恢复，不参与端点身份哈希；独立模式仍使用各自保险箱和保存开关。设备本地 `login-tunnels.bin` 使用版本 2 格式，不读取旧格式；首次升级后需重新填写旧的隧道配置，原保险箱凭据仍按稳定身份保存。

隧道复选框与其文字垂直居中，换行文字也按整体高度对齐；整行可点击并使用单一 Checkbox 语义，连接期间禁用。

主页连接卡片显示可读连接来源：普通隧道显示 `SSH 主机:端口 → 远端服务 URL`，受管连接显示宿主名称，直连显示服务器 URL。缺少本机连接配置时显示“远程服务器”，不展示内部服务身份哈希或本地临时转发端口。

“测试连接”检查 SSH 握手和远端登录端点，完成后释放测试隧道。已验证的 SSH 凭据仅在登录页的当前内存会话内暂存，使随后点击“连接”无需重复输入；页面释放时清零。只有勾选安全保存后才写入独立的 SSH 保险箱，保存失败会提示并继续连接。

“连接”自动建立本机 `127.0.0.1` 上的随机端口转发，然后沿用登录决策表解锁或使用 Server 密码。保存的连接可在“连接管理”中一键选择并连接。配置保存在 `noBackupFilesDir/login-tunnels.bin`，不含密码、私钥或本地监听端口。登录成功后隧道转交给应用会话，退出或会话失效时释放；进程结束后重新登录会重新建立隧道。

普通 SSH 登录隧道的稳定身份是 `ssh-tunnel:` 加规范化 SSH 主机、端口、SSH 用户和远端 URL 的 SHA-256。改变这些端点资料会产生不同身份；改变本地随机端口不会。它是本机连接配置身份，不声明受管安装 ID，也不会与服务器中心的受管安装身份合并。账号保险箱继续按 `(serviceId, identifier)` 关联。

HTTPS 保留主机名、有效期和证书链验证。由于请求访问 `127.0.0.1`，证书须包含相应 IP SAN；不能忽略名称不匹配。显式确认的证书指纹按稳定隧道身份保存，临时端口仅在当前隧道生命周期内映射到这个信任域，关闭后解除映射。SSH 加密保护下的 HTTP 回环服务无需配置 HTTPS 证书。

自动后台恢复 SSH 连接、跳板机和私钥文件选择器不在当前实现范围内；连接中断后重新登录建立隧道。设备休眠与移动网络切换的实机检查见 `docs/status/Verification.md`。

## Windows 个人安装的设备授权

Windows 10/11 个人安装由当前 Windows 账户拥有；该账户可在本机完成设备授权，即使它不是 Windows 管理员。Android 使用本机所有者生成的十分钟有效、一次性授权码登记 Android Keystore 公钥，并用 P-256 / SHA256withECDSA DER 签名登录。配对后关联所有者的同一 RelaxKonOS 账户和工作区，不需要 Windows 密码或额外 Windows 账户。

配对地址必须是 Android 可访问的 LAN 地址，不能是桌面电脑的回环地址；跨设备使用 HTTPS 并按已有证书信任流程校验证书。个人安装需要选择 LAN 监听并在安装维护阶段授权防火墙配置。授权码不改变网络可达性。

个人安装的日常特权操作由已安装的所有者专用助手执行，不在手机上请求 Windows UAC；显式管理员终端运行身份为 LocalSystem。撤销 Android 设备会阻止其已有访问令牌、刷新令牌和后续密钥登录，并断开该设备的现有 Hub 连接；其他设备和密码登录会话不受这次设备撤销影响。Windows Server 继续使用系统模式认证，不开放这一本机设备授权流程。

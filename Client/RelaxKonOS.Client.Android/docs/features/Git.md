# Android Git 编辑、构建与发布

> 当前功能说明，对应 AD06-M1–M3。源码构建与受限编辑已接入；运行环境、设备检查和自动化覆盖缺口见 [当前状态](../status/Progress.md) 与 [验收清单](../status/Verification.md)。

## 1. 仓库编辑

“管理 → Git”按 `server.git` 门控，可注册服务器已有工作树、查看分支/工作区状态、编辑已存在的非符号链接 UTF-8 文件（最多 256 KiB）、预览行差异、提交指定文件并推送当前分支。

保存携带精确字节 SHA-256 基线，服务端以目标用户独占文件校验，不匹配返回 409，不静默覆盖。草稿只存在当前页面内存，按会话/仓库/文件隔离，失败保留草稿。保存、提交、推送与部署分别确认；提交使用请求路径限定，不连带提交其他暂存变更，推送不 force。共享 Git 规则见 [Git 客户端](../../../../docs/applications/RelaxKonOS.GitClient.md)。

## 2. 固定提交构建

仓库 URL → 加密凭据引用 → 分支/标签 → 上下文和 Dockerfile → 解析并确认完整 SHA → 持久构建任务 → 查看有界日志/取消 → 成功镜像 → 显式交给 [Image 应用部署](ApplicationDeployments.md)。编辑后发布需先提交和推送，再解析远端引用，不能暗中纳入未提交内容。

Ubuntu 使用独立 rootless BuildKit remote builder，提交与执行时核对容器用户、无特权/宿主 bind/附加 capability、网络、CPU/内存/PID 配额；不满足条件拒绝，不使用默认 Docker builder。准备与配置见 [Ubuntu 构建环境](../development/GitBuild.Ubuntu.md)。Git LFS、私有子模块和完整 IDE 不在当前支持范围。

## 3. 执行与产物边界

仓库 token 是按账号隔离的服务器加密引用，不进入 URL、日志或普通草稿。构建任务幂等、可取消/超时；重启将活动任务标为中断，不自动重跑。构建失败不替换运行中的应用。

成功记录真实镜像 tag/ID；发布预检核对用户、成功状态与本机镜像身份，修订记录构建 ID、仓库、引用、SHA 和构建定义。创建容器按镜像 ID，回滚复用原修订产物与配置，不重新构建旧分支，也不撤销数据迁移。

静态站点/其他构建模板、更新比较与按修订引用安全回收产物仍见 [后续计划](../plans/Deployment.md)。Git 基础分支、暂存、历史与冲突工作流补齐见 BP10/BP11。

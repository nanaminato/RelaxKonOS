# Android Docker 与 Compose

## 1. 能力与资源归属

“管理 → Docker”按 `server.docker` 门控，读取 Engine、容器、镜像、卷、网络和 Stack，提供容器/Stack 生命周期与日志、卷详情与受控删除。宿主自定义/受管出站代理入口共用 [设置页面](OutboundProxy.md)；引擎安装/生命周期与账户镜像源管理已由 BP09-M1 接入，见 [引擎与镜像源](DockerEngine.md)；容器详情/统计/完整创建/重命名/生命周期、镜像拉取/删除和网络/卷动作由 BP09-M2 接入，见 [Docker 资源](DockerResources.md)。

资源详情读取所有权标签；应用部署资源返回应用详情，Compose 资源返回 Stack，保留归属标签未知的资源只读，独立资源不自动纳管。共享行为见 [Docker 管理设计](../../../../docs/applications/RelaxKonOS.DockerManager.md)。

## 2. Compose 准入与预览

Compose 编辑器保留重绘期间的名称和 YAML；系统返回、页面返回与取消在存在修改时统一确认放弃，取消确认继续编辑。键盘出现时底部预览与部署操作避让 IME。预览或提交期间禁止改字段，响应不解释为已修改草稿的结果。部署只有收到成功提交回执才关闭编辑器；预览或提交被拒绝时在编辑器内显示原因并保留草稿。

退到后台撤销旧删除确认和放弃草稿确认；恢复后保留编辑器名称与 YAML，再次删除或放弃需要重新操作。Compose 栏目隐藏时撤销尚未提交的删除确认。

资源刷新绑定当前登录与请求代次，切换登录取消旧刷新；结束或取消后释放加载状态。单项读取异常显示脱敏失败且继续读取其他列表，取消刷新撤销旧快照，允许显式刷新恢复。

取消后列表显示读取失败而非持续加载；恢复连接后通过刷新重新取得项目。运行时状态读取失败不会隐藏同次刷新中成功读取的 Compose 项目列表。

预览取消或读取异常时清除旧预览、显示脱敏反馈并释放编辑器忙碌状态，保留名称与 YAML，允许重新预览。预览失败不触发部署。

点击部署后的前置预览若取消或异常，同样恢复编辑器并保留草稿；此前置读取失败不发送部署请求，也不关闭编辑器。

协议提供 `GET /api/v1.0/docker/stack-operations/by-request`，携带原 `Idempotency-Key` 请求头，按当前认证操作者查询已记录的操作，不发起或重放变更。404 仅表示当前账本没有该请求；原请求可能仍在处理，较旧终态记录也可能已被保留上限移除，不能据此判定从未提交。

Compose 仓库在首次发出部署或项目动作前持久保存请求身份，不保存 YAML、令牌或凭据。回执丢失、取消或服务端异常保留待核实记录，并通过共享 Docker 门禁阻止新变更；落盘失败不发送请求。只读精确查询取得匹配项目和动作的操作后，先持久记入操作索引再清除待核实记录。未找到或连接失败保留记录。

项目列表与保留的编辑器草稿均显示待核实项目及动作，提供“核实原请求”只读操作。提交取消或异常后恢复页面操作，部署、重启与删除在待核实期间禁用；仍可编辑草稿和预览。查询失败保留记录与门禁，不能以普通刷新解除；查询成功显示原操作状态与 ID，即使原项目已从列表消失也能查看核实结果。记录读取异常时阻止新的 Compose 变更，并显示脱敏反馈。

本地导入在后台线程读取严格 UTF-8 文件，上限与服务器一致为 1 MiB；超限或无效编码拒绝，不截断、不替换字节后提交。导入回调、预览后的部署与异步结果核对当前登录身份，切换登录清空原编辑和确认状态。

受限导入不接受 `build`、特权、devices、外部资源、宿主 bind mount 或 Docker socket。未设置变量在准入阶段拒绝，不能让 Compose 默默替换为空串。

预览返回 `definitionVersion`、服务、卷与网络；部署必须回传同一版本，不能对未确认的 YAML 执行。部署及生命周期提交接入与引擎/独立资源共用的 DockerMutationGate；同步未知写入或 Docker 安装待核实/活动/不可读时阻止新提交。列表进入详情读取 Stack 操作历史，有活动操作时每秒查询，上限五分钟；离页不停止远端操作。

## 3. 持久操作与恢复

提交端点返回 `202` 和操作记录，由协调器执行互斥、取消、状态分类和重启核实。账本是权威结果，幂等重放返回原操作；重启观察实际服务后标记 `interrupted`，不重跑部署。

结果依据实际容器观察：命令成功但服务未达目标，或命令失败但容器残留，均为 `partialFailed`。界面提供停止/重新部署等明确决策；恢复旧定义不代表原子回滚或撤销数据迁移。取消只是请求，只有工作线程停止后才写终态。

诊断逐行脱敏，单行 512 字符、末 120 行，截断明确提示。账本最多保留 200 条操作/1000 条审计，先淘汰终态，活动操作不裁剪。运行中和已停止的容器引用均阻止删除卷；删除 Stack 保留命名卷，无引用后才可删除。
